# 产品型号及功能清单写作知识库

> 单一文档类型 | 受众：商务 / 销售 | 密级：可公开 | 形态：Excel

---

## 核心原则

1. **矩阵直观**：横向型号、纵向功能、单元格用 ✅/✗/选配 标记
2. **完整覆盖**：所有型号 × 所有功能模块全部填写，不留空
3. **可对比**：相邻型号差异要明显，便于销售引导升级
4. **同步真实**：禁止把"未来要做"的功能填为支持

## 标记规范

| 标记 | 含义 |
|------|------|
| ✅ | 标配支持 |
| ✗ | 不支持 |
| 选配 | 需额外购买 / 授权 |
| 路线图 | 不填入正式表格，单独维护内部路线图 |
