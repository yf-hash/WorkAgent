# 偏离表"无偏离"同义改写技能

> 五原则改写 — 原意守恒，句式彻底差异化

## 核心定位

对技术偏离表中的"无偏离"应答项进行同义改写，原意不变、句式彻底差异化，满足查重规避需求。

**仅适用于"无偏离"应答项**，正偏离/负偏离条款不在改写范围内。

---

## 五条核心原则

| 原则 | 说明 |
|------|------|
| **1. 核心含义守恒** | 仅调整表达形式，技术符合性结论完全一致，不改变任何实质承诺 |
| **2. 固定前缀+句式差异化** | 所有应答以"我司产品"开头；调整语序、替换同义术语、转换论证顺序 |
| **3. 量化指标不变** | 参数数值、规格标准、性能阈值与原文完全一致，不得增减 |
| **4. 层级全覆盖** | 对段落内每个次级层级分别改写，整体保持连贯 |
| **5. 适度扩充** | 可增加1句辅助说明（如"相关参数可提供权威检测报告佐证"），不添加话术，不出现第三方测试肯定性内容 |

---

## 改写策略库

### 句式变换策略

| 策略 | 原文示例 | 改写示例 |
|------|----------|----------|
| 语序调整 | "支持A功能，满足B要求" | "针对B要求，我司产品提供A功能支持" |
| 同义术语替换 | "完全满足" | "全面响应" / "完整覆盖" / "充分符合" |
| 主被动转换 | "系统支持X" | "X功能由系统提供" |
| 论证顺序转换 | 结论→依据 | 依据→结论 |
| 条件句改写 | "在X条件下，支持Y" | "针对Y需求，我司产品在X条件下可完整实现" |

### 禁用表达

- 不得出现"无偏离"三字（改写目的即规避此类重复）
- 不得添加"显著"、"卓越"、"业界领先"等话术
- 不得引用第三方测试机构的肯定性表述（如"经XX检测机构认证，性能优于行业标准"）
- 不得改变任何量化数值

## 质量自检清单

改写完成后逐条核查：

- [ ] 所有应答以"我司产品"开头
- [ ] 量化数值与原文完全一致（逐一比对）
- [ ] 核心技术符合性结论未改变
- [ ] 无话术、无第三方肯定性表述
- [ ] 每个次级层级均已改写，无遗漏
- [ ] 改写后文本与原文相似度 < 40%（目标）
