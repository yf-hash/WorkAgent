## 二、售前特有的交叉引用规则

### 规则 R1：痛点闭环
从 01 提取所有痛点 → 检查 03 有响应 → 检查 04-poc 中必测项覆盖

### 规则 R2：定制点闭环
从 02 § 定制清单 → 检查 04-poc 中"必测" → 检查 06 § 定制估算

### 规则 R3：合规闭环
从 01 § 合规约束 → 检查 03 § 部署 & § 8 安全 有回应 → 检查 04-rfp 应答

### 规则 R4：RFP 满足率
从 04-rfp 提取满足率 → 满足率 < 80% → ⚠️ 警告（中标概率降低）

### 规则 R5：估算规模一致性
从 01 § 客户规模 → 检查 05-config-estimate 中服务器 / 许可数量 匹配

### 规则 R6：时间线合理
M1 < M2 < M3 < M4 < M5 < M6，且总时长跨度合理

## 三、售前场景版本号规则

### MAJOR（重大变更）
- 客户合规要求变化（如新增关基 / 密评要求）
- 客户规模数字大幅变化（10 倍以上）
- RFP 全面重发
- 部署模式变化（私有化 → 混合）

### MINOR（新增）
- 新增一个模块 / 场景
- 新增一份专项方案（如加 impl / rfp）
- 客户新增痛点

### PATCH（微调）
- 文案 / 措辞调整
- 估算数字微调
- 校验发现的小问题修复
- RFP 应答句式优化

## 四、变更触发下游重跑规则

售前项目最常见的场景：客户临时改需求 / 变约束。

| 变更点 | 影响到哪 | 触发重跑 |
|---|---|---|
| 客户新痛点 | 全下游 | M2 → M3 → M4 → M5 → M6 |
| 客户合规变化（新增等保 / 国产化） | 方案 + 应答 | M3 → M4 → M5 → M6 |
| 客户规模变化（用户 / 设备数） | 方案 + 估算 | M4 → M6 |
| 部署模式变化 | 方案 + 估算 | M4 → M6 |
| RFP 新版本 | 应答表 | M5.3 → M6 |
| 客户特殊要求（新增） | 方案 + 应答 | M3 → M4 → M5.3 |
| 竞品报价压力 | 估算调整 | M6 |
| POC 结果反馈 | 方案调整 | M3 → M4 → M5.2/M6 |

**使用**：
```
/sa-pipeline ./output/sa-pipeline/xxx/ --from M4
```

## 五、脱敏规范（对外版本）

### 必须脱敏的内容

| 位置 | 脱敏项 |
|---|---|
| 各文档 | 客户联系人真实姓名（除非授权） |
| 05-config-estimate.md § 商务提醒 | 客户预算、竞品报价、内部策略 |
| review-notes.md | 内部评审意见 |
| 04-rfp-strategy.md | 应答策略 |
| M2 § 假设项（我方视角） | 部分内部分析 |

### 必须保留的内容
- 项目名 + 客户行业（可粗化 "某制造业客户"）
- 技术架构 / 方案内容
- 应答条款 / 偏离表（如涉招标）

### 脱敏工具
- 手工替换（推荐，敏感）
- 用 `--export word --sanitize` 走脱敏管道（未来支持）

## 七、目录命名规则

### {client} 命名
- 优先客户官方简称
- 长度 ≤ 20 字符
- 政企 / 敏感客户可用代号（"某 X 银行"）
- 英文项目名可用小写连字符

### 完整目录名格式
```
{client}-{project}-{yyyymmdd}
```
示例：
- `远大制造-mes-替换-20260827`
- `某城商行-移动办公-20260830`
- `mfg-mes-20260827`（英文简）

## 八、导出规范

### Markdown 打包（--export markdown）
- 保留全部目录结构
- 打包为 `{project}-方案包.zip`
- 附带 README.md 作为入口
- 图表用相对路径链接

### Word 导出（--export word）
- 依赖客户机器安装 pandoc
- 合并成一份连续文档
- 图表转为 PNG 内嵌
- 生成两版：
  - `{project}-方案包-完整版.docx`（对内）
  - `{project}-方案包-脱敏版.docx`（对客）

### 导出章节顺序
1. 封面（客户 / 项目 / 版本 / 日期）
2. 客户调研与痛点分析（M2）
3. 方案定位与竞争分析（M3）
4. 总体解决方案（M4，主体）
5. POC 测试方案（M5.1）
6. 实施方案（M5.2）
7. RFP 应答与偏离表（M5.3）
8. 配置估算清单（M6.1）
9. 附件：宣讲 PPT 大纲（M6.2）
10. 变更历史（CHANGELOG）

## 九、常见归档失败

| 症状 | 修复 |
|---|---|
| M4 无 architecture.mmd | 回 M4 补 |
| M5 全部缺失 | 视场景决定：投标必补 M5.3；POC 必补 M5.1 |
| M2 假设项在 M3-M6 无响应 | 显式添加"接受此假设"或"新增待确认" |
| 校验状态"需重写" | 强制不允许归档 |
| 目录名含中文导致导出失败 | 建议改为英文 |
