# sa-presentation-draft — 宣讲材料底稿工具箱

> 本 skill 被 `/sa-quote` 命令调用。

## 一、PPT 结构 8 章模板

标准客户方案汇报 PPT（45 分钟版本）：

| # | 章节 | 页数 | 目的 |
|---|---|---|---|
| 封面 | 项目名 + LOGO + 时间 | 1 | 建立正式感 |
| 议程 | 目录 | 1 | 让客户知道听什么 |
| 1 | 项目背景与我方理解 | 2 | 建立信任：我们做过功课 |
| 2 | 客户核心痛点 | 2 | 让客户产生共鸣 |
| 3 | 我方总体方案 | 4 | 讲清方案是什么 |
| 4 | 关键差异化能力 | 3 | 讲清为什么选我 |
| 5 | 部署与集成 | 2 | 讲清可落地 |
| 6 | 实施计划 | 2 | 讲清 3 月能上线 |
| 7 | POC 建议 | 1 | 引导下一步 |
| 8 | 后续步骤 | 1 | 明确 next action |
| 结尾 | 感谢 + Q&A + 联系 | 1 | 结束 |

**总页数**：18-20 页（不含封面结尾则 16-18 页）。

## 二、每页文案要点原则

### 一页三段式
```
【标题】明确的一句话
【核心要点】3-5 个 bullet
【补充说明】1 段话（可选）
```

### 每页要点最多 5 个 bullet
- 少字多图 / 少字多表
- 每个 bullet ≤ 15 字
- 避免堆砌

### 数据 / 案例背书
- 优势项必须有数据（"提升 15%"）
- 差异化必须有案例（"XX 客户实测"）
- 承诺必须有兜底（"若不达标承担违约"）

## 三、8 章文案要点库

### 第 1 章：项目背景与我方理解
**关键动作**：不要泛泛描述行业趋势，直接讲你对**这个客户**的理解。

**页面模板**：
- 页 1：客户业务现状 → 挑战 → 目标（图形化）
- 页 2：我们的调研过程 + 关键洞察

### 第 2 章：客户核心痛点
**关键动作**：Top 3 痛点深度描述。

**痛点表述公式**：
```
【痛点 X】{一句话痛点}
现状：{客户现在怎么做}
影响：{频率 + 数字影响}
```

### 第 3 章：我方总体方案（重点章）
- 页 1：方案一句话 + 三大能力
- 页 2：业务架构图（Mermaid 或图形）
- 页 3：技术架构图
- 页 4：与客户现有 IT 的关系

**关键**：讲差异化能力，避免陷入功能罗列。

### 第 4 章：关键差异化能力
每页讲一个差异化能力（3 页 = 3 个差异化）。

**结构**：
```
【能力名】一句话
效果：{数据 / 客户案例}
对客户价值：{对痛点的响应}
```

### 第 5 章：部署与集成
- 页 1：部署架构（客户 IDC + 双活）
- 页 2：与 SAP / LDAP / 设备 集成关系

### 第 6 章：实施计划
- 页 1：6 阶段 Gantt 图
- 页 2：里程碑 + 客户参与度

### 第 7 章：POC 建议
- 一页：POC 目标 + 周期 + 关键验证点 + 客户方需要的支持

### 第 8 章：后续步骤
- 一页：下一步动作 + 客户方需要的支持 + 联系人

## 四、汇报话术规范

### 开场（2 分钟）
- 感谢时间
- 强调"我们做过深入调研"
- 说明汇报结构 + 时间

### 讲客户痛点（重点，5 分钟）
- 引用**具体调研到的场景**（非泛泛）
- 用客户的话 / 数字
- 铺垫下一章的方案

### 讲差异化能力（关键，8 分钟）
- 每个能力：能力 + 案例数据 + 对客户价值
- 避免技术细节堆砌

### 讲实施与 POC（5 分钟）
- 强调**时间承诺**
- 明确**客户方需要的配合**
- 具体化 POC 计划

### 讲下一步（3 分钟）
- 明确 next action
- 明确联系人 + 时间

## 五、Q&A 常见问题库

### 竞争类
Q: 你们比 {竞品 X} 好在哪？
A: 三个维度对比：{维度 1、2、3}。您想深入哪个？

Q: {竞品 Y} 更便宜怎么办？
A: 我方性价比综合看 —— 除了价格还要看交付风险 / 后续升级成本。

### 时间类
Q: 3 个月上线现实吗？
A: 现实，三个前提：{前提 1、2、3}。我们承诺书面里程碑。

Q: 你们有类似项目案例吗？
A: 有 XX 家类似客户，其中 X 家可以提供联系人对接（会后我们提供）。

### 技术类
Q: 与我们现有 {系统 Z} 的集成有风险吗？
A: 有集成复杂度，但可控。已有 X 家使用 {系统 Z} 的客户成功案例。POC 会重点验证。

Q: 定制会影响后续升级吗？
A: 定制通过扩展点实现，不改核心。后续版本升级不受影响，5 年内免费小版本升级。

### 合规类
Q: 你们能满足等保三级 / 国产化吗？
A: 能。国产化率 100%（附组件清单）。等保测评我方负责协助。

### 商务类
Q: 报价什么时候能给？
A: 商务已在准备，POC 通过后 3 个工作日内给出正式报价。

Q: 付款方式能不能灵活？
A: 商务会详谈，我们对政企 / 金融客户有多种付款方案。

## 六、宣讲反模式

- ❌ 陷入功能罗列（客户听不懂 / 听不下去）
- ❌ 承诺不能兑现的时间 / 效果
- ❌ 攻击竞品（专业性差）
- ❌ 用"最"、"唯一"（客户会较真）
- ❌ 汇报超时（客户注意力有限）
- ❌ 页面文字太多（客户读不进去）
- ❌ 没有客户 LOGO / 具体名字（显得不用心）

## 七、按客户角色定制建议

### 汇报给 CIO
- 强调技术架构 + 国产化 + 合规
- 少讲界面，多讲能力

### 汇报给业务负责人
- 强调痛点解决 + 效率提升
- 多讲流程，少讲技术

### 汇报给采购 / 商务
- 强调交付时间 + 服务承诺 + 价格性价比
- 引用类似客户案例

### 汇报给一把手（董事长 / CEO）
- 一句话价值主张
- 战略对齐（数字化 / 信创 / 转型）
- 3 分钟决策要点
