# sa-quote-estimate — 配置估算工具箱

> 本 skill 被 `/sa-quote` 命令调用。

## 🚨 首要原则

**所有估算产出物顶部必须显式标注**：

```
⚠️ 报价底稿 - 非正式报价，最终以商务方案为准
```

## 一、服务器规格计算规则

### 应用节点

按微服务数量 + 并发 + 副本数：

| 规模 | 每服务副本 | 单副本规格 |
|---|---|---|
| 小（< 100 用户） | 1 | 4 vCPU / 16 GB / 200 GB SSD |
| 中（100-1000） | 2 | 8 vCPU / 32 GB / 500 GB SSD |
| 大（> 1000） | 3+ | 8-16 vCPU / 32-64 GB / 500 GB - 1 TB SSD |

### 数据节点

**关系库（OceanBase / GaussDB / TiDB）**：
| 数据量 | 集群规模 | 单节点规格 |
|---|---|---|
| < 500 GB | 1 主 1 从 | 8 vCPU / 32 GB / 1 TB SSD |
| 500 GB - 5 TB | 3 副本 | 16 vCPU / 128 GB / 4 TB SSD |
| > 5 TB | 3+ 副本 + 分库 | 32 vCPU / 256 GB / 8 TB SSD |

**时序库（InfluxDB / IoTDB）**（如果有设备接入）：
| 设备数 | 单节点规格 | 数量 |
|---|---|---|
| < 1000 | 4 vCPU / 16 GB / 500 GB SSD | 1 |
| 1000-10000 | 8 vCPU / 32 GB / 2 TB SSD | 2 |
| > 10000 | 16 vCPU / 64 GB / 4 TB SSD | 3+ |

**缓存（Redis）**：
- 一般配 3 台（1 主 2 从），4 vCPU / 16 GB / 100 GB SSD

### 其他节点

- **大屏**：4 vCPU / 16 GB / 200 GB SSD
- **监控**：8 vCPU / 32 GB / 2 TB SSD
- **镜像仓（Harbor）**：4 vCPU / 16 GB / 1 TB SSD

## 二、软件许可类型规范

| 类型 | 说明 | 适用 |
|---|---|---|
| 按并发用户数 | 同时在线用户 | 一般应用 |
| 按注册用户数 | 系统注册用户总数 | SaaS |
| 按 CPU 核数 | 部署服务器 CPU 核 | 数据库、中间件 |
| 按接入设备数 | 接入的设备数量 | IoT / 制造 |
| 按数据量 | GB / TB | 存储型产品 |
| 按套件 | 打包销售 | 大项目 |

**给出许可时必须包含**：
- 类型
- 数量（含依据）
- 备注（如"客户规模 500 用户，按 500 并发"）

## 三、定制工作量分级（重申）

**只给范围，不给具体人天**（具体由实施团队评估）：

| 级别 | 判定 | 参考人天范围 |
|---|---|---|
| 🟢 低 | 配置项 / 参数调整 / 小组件 | ≤ 5 |
| 🟡 中 | 一个模块的功能扩展 / 一个新接口 | 5-30 |
| 🔴 高 | 多模块联动 / 大型集成 / 新算法 | > 30 |

估算表用"低 / 中 / 高"表示，可加范围括号。

## 四、服务人天参考值

| 服务类别 | 参考人天（3 月项目 / 中等规模） |
|---|---|
| 项目管理 | 40-60（PM 全周期） |
| 部署服务 | 15-25 |
| 集成服务 | 20-40（依集成复杂度） |
| 数据迁移 | 15-30 |
| 培训服务 | 10-20（管理员 + 一线） |
| 上线支持 | 10-20 |
| 售后（1 年） | 50-80（含 7×24 + 现场应急） |

**总计**：中等 3 月项目约 150-250 服务人天。

## 五、商务提醒规范

估算清单末尾可以放"商务提醒"章节，供内部参考，**不出现在客户版**：

```
## 7. 商务提醒（内部）

- 建议客户预算：{X - Y 万元}
- 客户实际预算：{待商务确认 / 明确告知的档位}
- 竞品价格档：{竞品 A} vs {竞品 B}
- 建议报价策略：{策略描述}
- 特殊风险：{如客户预算严重不足 / 竞品降价}
```

## 六、常见错误

| 错误 | 后果 | 修正 |
|---|---|---|
| 估算给客户当报价 | 商务翻脸 | 强制"底稿"声明 |
| 定制给具体人天 | 被当承诺 | 改为"高 / 中 / 低"范围 |
| 服务人天漏售后 | 报价不完整 | 强制包含 7 类 |
| 服务器规格拍脑袋 | 上线后不够用 | 用规则表 |
| 许可数量与规模不匹配 | 客户超用 | 用客户规模作为依据 |

## 七、按行业特化

### 政企 / 央企
- 加国产化组件清单（明确写清麒麟 / 统信 / OceanBase 等）
- 加等保测评费用（如需要）
- 服务器数量偏保守（≥ 3 副本）

### 金融
- 加两地三中心配置
- RPO/RTO 硬性要求
- 服务人天含合规审计支持

### 互联网 SaaS
- 云资源估算（AWS / 阿里云 规格）
- 按用户数 or 按 API 调用数

### 制造业
- 加设备接入许可
- 加时序库
- 加 OT 网络专项配置
