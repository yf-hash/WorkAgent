# 产品彩页写作知识库

> 单一文档类型 | 受众：展会观众 / 客户拜访 | 密级：可公开 | 篇幅：≤2 页

---

## 核心原则

1. **第一秒抓眼球**：标题区必须在 1 秒内传递"是什么 / 解决谁的什么问题"
2. **数据胜过形容词**：用"日均防护 1000 万次"代替"高性能防护"
3. **视觉优先**：60% 视觉 + 40% 文字
4. **可读距离**：A4 版式正文 ≥10pt，标题 ≥18pt

---

## 版式模板

### A4 双面版

```
正面（吸引）：
┌─────────────────────────┐
│  [产品 Logo]   [公司 Logo] │
│                          │
│  ★ 一句话定位 ★          │
│  （≤20 字大标题）         │
│                          │
│  [核心场景图 / 架构示意]   │
│                          │
│  ★ 三大亮点 ★            │
│  ◆ 亮点 1（≤15 字）       │
│  ◆ 亮点 2（≤15 字）       │
│  ◆ 亮点 3（≤15 字）       │
└─────────────────────────┘

背面（信任）：
┌─────────────────────────┐
│  核心能力一览             │
│  ┌──┬──┬──┐             │
│  │ ✓│ ✓│ ✓│             │
│  └──┴──┴──┘             │
│                          │
│  数据指标 / 资质认证      │
│  · [指标 1]              │
│  · [认证 logo 墙]         │
│                          │
│  典型客户 Logo 墙        │
│                          │
│  联系方式 + 二维码        │
└─────────────────────────┘
```

### 三折页版

```
封面 | 内页（功能/亮点） | 封底
打开后内页连续展示，建议中折页放架构图或场景图
```

---

## 内容元素清单

| 元素 | 必备 | 内容要求 |
|------|------|---------|
| 产品名 + Logo | 必备 | 字号最大，居上 |
| 一句话定位 | 必备 | ≤20 字，含目标客户 + 价值 |
| 三大亮点 | 必备 | 每个 ≤15 字，可视化图标 |
| 核心数据 | 必备 | 至少 3 个数字（性能 / 案例数 / 认证数） |
| 场景/架构图 | 必备 | 中心位置，视觉重心 |
| 资质认证 | 推荐 | Logo 墙，展示 ISO/等保/国密等 |
| 典型客户 | 推荐 | Logo 墙，需客户授权 |
| 联系方式 + 二维码 | 必备 | 含官网 / 电话 / 微信公众号 |
