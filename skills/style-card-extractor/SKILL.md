# Style Card Extractor — 风格卡片提炼

> 单一职责：把 1-5 篇参考文章 → 风格卡片。
> 不做：创作（→ `style-writer-reviewer`）、技术调查（→ `style-refine` 或 `@research-analyst`）

## 流程

### Step 1：逐篇抓取与解析

用 WebFetch 抓取每篇文章全文，提取：标题、段落结构、小标题分布、开头/结尾模式、字数、平均段落长度。

### Step 2：7 维度结构分析

| 维度 | 分析内容 |
|------|----------|
| 开篇模式 | 如何抓住读者（问题/故事/数据/观点） |
| 论证结构 | 总分总 / 问题-解决 / 时间线 / 对比 |
| 段落节奏 | 长短句比例、段落字数分布 |
| 过渡方式 | 章节间如何衔接 |
| 结尾策略 | 总结/行动号召/开放式提问 |
| 语言风格 | 口语化程度、人称使用、情感浓度 |
| 案例密度 | 每千字案例数量、案例类型 |

### Step 3：生成「风格卡片」

```markdown
## 风格卡片（提炼自 N 篇优质文章）

**开篇原则**：[共性开篇策略]
**结构原则**：[共性论证结构]
**节奏原则**：[段落节奏规律]
**语言原则**：[语言风格特征]
**案例原则**：[案例使用规律]
**结尾原则**：[结尾策略]
**禁止事项**：[参见下方 AI 高频词与反模式禁用列表]
```

**禁止事项默认包含以下 AI 高频词（来自 op7418/Humanizer-zh）：**

> 此外、至关重要、深入探讨、强调、持久的、增强、培养、获得、突出（动词用法）、
> 格局（抽象名词）、充满活力的、证明（抽象用法）、宝贵的、织锦（比喻用法）、
> 首先/其次/最后（排比导语）、值得注意的是、不容忽视的是、毋庸置疑

若发现参考文章刻意回避了某些词汇，额外加入禁止列表。

### Step 4：⏸ 暂停等待用户确认

```
展示风格卡片后，请用户：
A. 直接确认（"确认，进入创作"）
B. 修改某项原则后确认
C. 保存到本地（--save-card <路径>）

必须等待用户确认后才进入下游 Skill。
```

## 输出去向

- `style-writer-reviewer`：用风格卡片作为创作基准
- `style-refine`：用风格卡片对已有文章做风格优化
