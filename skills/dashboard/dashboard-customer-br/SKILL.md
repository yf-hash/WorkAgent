# Dashboard Customer BR — 客户业务评审看板

> 单一职责：单客户 BR/QBR 看板模板。
> 不做：流失分析（→ `churn-analysis`）、收入汇总（→ `dashboard-revenue`）

## 看板模板

```
顶部：客户基础信息
  - 客户名 / Logo
  - 合同金额（ARR）
  - 活跃用户数 / 授权数
  - 续约日（距今天数）
  - CSM 负责人

中部：价值履约（核心）
  - 合同承诺 vs 实际履约（功能/SLA/培训/集成各项打勾）
  - 关键模块使用频次（业务线、核心功能 Top 5）
  - ROI 估算（基于客户实际节省 / 增收 / 效率提升）
  - 上次 QBR 行动项进展

底部：
  - 月度活跃曲线（过去 12 个月）
  - 反馈与响应表（工单数 / 平均响应时间 / NPS）
  - 健康度评分（综合：使用率 + ROI + NPS + 续约信号）
  - 续约预测（高/中/低 风险）
```

## 健康度评分模型

```
健康度 = 0.3 × 使用率 + 0.3 × ROI 履约 + 0.2 × NPS + 0.2 × 续约信号

使用率（0-100）：
  - 活跃用户 / 授权数 × 100%
  - 关键模块使用频次

ROI 履约（0-100）：
  - 客户业务指标改善 vs 销售时承诺
  - 100 = 完全达成，< 60 = 承诺过度

NPS（0-100）：
  - 上次 NPS 调研得分映射

续约信号（0-100）：
  - 100 = 已确认续约
  - 80 = 客户主动询问续约条款
  - 60 = 正常合同期
  - 40 = 高层变动 / 缩减预算信号
  - < 30 = 流失高危
```

## QBR 输出模板

```markdown
# [客户名] QBR — [季度]

## 一句话健康度
[绿/黄/红] [一句话总结]

## 上季度成果
- ARR：$X（vs 合同 $Y）
- 活跃用户：N（vs 授权 M）
- 关键 ROI 实现：[列举 2-3 项]

## 关键模块使用
[使用率 Top 5 模块 + 趋势]

## 上次 QBR 行动项
- [✓] 完成项
- [⏳] 进行中
- [❌] 未启动 + 原因

## 本季度推荐 Next Steps
1. [价值扩展机会]
2. [风险缓解]
3. [续约准备]

## 续约展望
- 续约日：[日期，距今 X 天]
- 续约风险：高 / 中 / 低
- 风险因素：[列举]
- 缓解计划：[列举]
```

## 告警建议

```
P0：续约前 90 天健康度 < 60 分
P0：高层变动 / 主要 Champion 离职
P1：连续 2 个月活跃率下降 > 10%
P2：NPS 比上次下降 > 10 分
```
