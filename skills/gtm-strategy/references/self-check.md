# 十九、AI 输出质量自检表

> 来自 `skills/gtm-strategy/SKILL.md` 的次要章节，按需 Read。


> AI 通过本 Skill 输出 GTM 产物时，必须满足以下自检项。
> 任何一项不满足，应当返工或在输出末尾标注"需用户补充"。

```
□ 阶段定位明确（清楚指出当前阶段 + 下一阶段入口条件）
□ 产物可执行（每条建议有①具体动作 ②责任角色 ③时间节点 ④完成判断标准）
□ 数字可衡量（不是"提升效率"而是"减少 30% 处理时间"）
□ 行业感知（若给定 --industry，话术 / 案例 / 合规要求体现行业特征）
□ 受众适配（若给定 --audience，详略和口吻匹配，CEO 要战略、销售要话术）
□ 不套模板（ICP / 痛点 / 价值主张基于用户产品和行业推演，不是通用文案）
□ 风险透明（明确指出关键假设和需要验证的核心假设）
□ 阶段闸门（输出末尾附 Exit Criteria 检查表）
□ 下一步指引（推荐下一步执行的 /xxx 命令或继续追问）
```
