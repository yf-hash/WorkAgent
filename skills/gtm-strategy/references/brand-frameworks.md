# 十二、品牌定位与营销框架

> 来自 `skills/gtm-strategy/SKILL.md` 的次要章节，按需 Read。


> 参考：[niranjanbala/brand-marketing-frameworks](https://github.com/niranjanbala/brand-marketing-frameworks)
> 品牌定位是 GTM 战略的基础——在执行 GTM 之前，必须先明确品牌在目标客户心智中的位置。

### 品牌定位声明

```
模板：
「对于 [目标受众]，[品牌名] 是 [参照框架/品类]，
 它提供 [核心利益]，因为 [支撑理由]。
 不同于 [竞争对手]，我们 [差异化优势]。」

示例（AI写作工具）：
「对于需要高频输出内容的中文创作者，WorkAgent 是一款
 风格驱动的 AI 写作平台，它能让内容保持真实人声，
 因为我们融合了五套去AI痕迹方法论。
 不同于通用 AI 工具，我们专注于中文内容的"活人感"。」
```

### 品牌 DNA 五要素

```markdown
1. 核心价值（Core Values）：品牌坚守的根本信念
   → 在 GTM 信息架构中体现为"为什么我们存在"

2. 品牌个性（Brand Personality）：如果品牌是一个人，他是谁？
   → 决定 GTM 内容的语气和风格

3. 品牌承诺（Brand Promise）：对客户的核心承诺
   → 转化为 GTM 的核心价值主张

4. 品牌故事（Brand Story）：为什么存在，从哪里来
   → 用于 PR 稿、About 页面、融资 Deck

5. 视觉识别（Visual Identity）：颜色/字体/图形语言
   → 确保 GTM 所有触点视觉一致性
```

### 品牌-GTM 对齐检查

```markdown
GTM 执行前，确认以下品牌-GTM 对齐项：

□ 落地页标题是否体现品牌承诺？
□ 广告文案语气是否符合品牌个性？
□ 销售话术是否与品牌定位声明一致？
□ 内容营销主题是否强化品牌核心价值？
□ 定价策略是否与品牌定位（高端/亲民）匹配？
□ 渠道选择是否与目标受众的媒体习惯匹配？
```

### 品牌生态系统与 GTM 渠道映射

```markdown
## 品牌生态 → GTM 渠道对应

核心产品/服务
  → 产品官网、Demo、免费试用（PLG入口）

合作伙伴生态
  → 渠道销售、Marketplace上架、集成合作（ECG）

社区生态
  → 开发者社区、用户论坛、Discord/Slack群组

内容生态
  → 博客/白皮书（MLG）、KOL合作、UGC激励

竞争生态
  → 竞品对比页、迁移工具、Battle Card（SLG）
```

### 营销信息架构（Messaging Framework）

```markdown
## 三层信息架构

Layer 1：核心信息（对所有受众）
  → 一句话价值主张（电梯演讲版）
  → 用于：官网首屏、广告标题、PR稿导语

Layer 2：角色信息（针对不同 Persona）
  → 技术决策者：强调安全/集成/可扩展性
  → 业务决策者：强调 ROI/效率/竞争优势
  → 最终用户：强调易用性/节省时间/体验

Layer 3：场景信息（针对具体使用场景）
  → 用于：功能页面、案例研究、销售演示
  → 每个场景对应一个具体痛点和解决方案
```
