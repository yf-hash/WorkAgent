# 十五、行业垂直 GTM 差异

> 来自 `skills/gtm-strategy/SKILL.md` 的次要章节，按需 Read。


> 同样的 B2B 产品，在不同行业的 GTM 打法可以完全不同。
> 关键变量：**采购方式 / 决策周期 / 关键决策人 / 合规要求 / 部署方式 / 计费模型**。

### 金融行业（Finance）

| 维度 | 特征 |
|------|------|
| 采购方式 | 招投标（央行 / 大行）+ 商务洽谈（股份制 / 城商行） |
| 决策周期 | 6-18 个月 |
| 关键决策人 | 行长 / 科技部总经理 / 业务部门总 / 风险部门总 |
| 合规要求 | 等保三级、监管报送、数据本地化、信创、金融云 |
| 部署方式 | 私有化（大行）/ 金融云（中小行） |
| 计费模型 | 项目制 + 年度服务费 |
| GTM 关键 | 标杆案例 + 监管合规清单 + 行长论坛 + 金融科技峰会 |

### 制造行业（Manufacturing）

| 维度 | 特征 |
|------|------|
| 采购方式 | 总经办 / IT 部门拍板 + 生产线试点 |
| 决策周期 | 3-9 个月 |
| 关键决策人 | 总经理 / CIO / 生产总监 / 工艺工程师 |
| 合规要求 | OT 安全、ISO 9001、数据互通（PLC / MES / ERP） |
| 部署方式 | 本地 / 私有化 / 边缘 + 云协同 |
| 计费模型 | 按生产线 / 按设备数 / 项目制 |
| GTM 关键 | 现场化部署能力 + 工程团队 + 行业 know-how + 灯塔工厂案例 |

### 医疗行业（Healthcare）

| 维度 | 特征 |
|------|------|
| 采购方式 | 院长会议 + 科室主任试点 + 招投标 |
| 决策周期 | 6-24 个月 |
| 关键决策人 | 院长 / 信息中心主任 / 科室主任 / 临床医生 |
| 合规要求 | 等保三级、医疗数据合规、HIS / EMR 集成、卫健委白名单 |
| 部署方式 | 院内私有化 + 部分云 |
| 计费模型 | 项目制 + 维保费 |
| GTM 关键 | 三甲医院标杆 + 学术论文 + 院长论坛 + 临床场景验证 |

### 政府 / 央国企（Government）

| 维度 | 特征 |
|------|------|
| 采购方式 | 招投标 / 集采 / 框架协议 |
| 决策周期 | 6-18 个月（财政预算节奏） |
| 关键决策人 | 局长 / 信息中心主任 / 业务司局 / 集采办 |
| 合规要求 | 信创、国产化、等保三级、政务云、密评 |
| 部署方式 | 政务云 / 私有化 / 国产化适配 |
| 计费模型 | 项目制 + 年度运维 |
| GTM 关键 | 国产化资质 + 集采名录 + 行业协会 + 部委试点 |

### 能源行业（Energy）

| 维度 | 特征 |
|------|------|
| 采购方式 | 央企集采 + 多公司协同 + 招投标 |
| 决策周期 | 9-24 个月 |
| 关键决策人 | 集团 CIO / 二级公司总经理 / 信息部 |
| 合规要求 | 国资委监管、央企信创、安全生产 |
| 部署方式 | 集团云 + 二级公司本地 |
| 计费模型 | 集团框架 + 二级公司分单 |
| GTM 关键 | 集团总部突破 → 二级公司复制 + 央企标杆 |

### 零售 / 教育（补充）

| 行业 | 关键差异 |
|------|---------|
| 零售（Retail） | SaaS 渠道 / 区域代理 / 加盟商生态、季节性预算、按门店计费 |
| 教育（Education） | 教育部白名单、寒暑假节奏、高校 vs K12 完全不同、按学校 / 班级计费 |
