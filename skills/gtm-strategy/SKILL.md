# GTM Strategy — 上市战略知识库

> 知识整合自：SlideModel、Userpilot、SiteCentre、Slideworks（McKinsey/BCG/Bain咨询框架）、  
> ProductPlan、GTM Alliance、SalesMotion、Copy.ai、Asana、人人都是产品经理、知乎、运营派  
> **核心理念**：GTM 是连接 PMF（产品市场匹配）与规模化增长的桥梁，是一条持续演进的策略线，不是一次性事件。

---

## 一、GTM 的定义与适用时机

### 定义
GTM（Go-to-Market）是将特定产品成功推向目标市场的战术执行框架，覆盖从市场准入到规模化增长的全链路：
- **Reach**：通过市场营销触达潜在客户
- **Win**：通过销售转化完成成交
- **Retain & Grow**：通过客户成功实现留存与扩张

### 触发时机（Ansoff 矩阵对应）
| 场景 | 产品 | 市场 | GTM 需要程度 |
|------|------|------|------------|
| 市场渗透 | 现有 | 现有 | 低（优化即可） |
| 产品延伸 | 新增 | 现有 | 中（营销计划） |
| 市场扩张 | 现有 | 新进 | 高（完整 GTM） |
| 多元扩张 | 新增 | 新进 | 极高（最全面 GTM） |

### GTM vs. 普通营销计划
| 维度 | 营销计划 | GTM 战略 |
|------|---------|---------|
| 范围 | 市场推广活动 | 覆盖全部客户触点 |
| 时间 | 持续运营 | 围绕产品生命周期 |
| 跨部门协作 | 以营销为主 | 产品/销售/市场/客成全部参与 |
| 核心问题 | 如何推广？ | 卖什么/怎么卖/卖给谁/去哪卖？ |

## 二、GTM 增长模型五选一

> **关键原则**：早期专注一个主模型，验证后再叠加。

### MLG — 营销驱动增长（Marketing-Led Growth）
```
核心逻辑：通过内容、SEO、广告占领认知高地，让客户主动找来
适用场景：需要建立专业可信度，决策周期较长的产品
典型动作：内容营销 + SEO + 行业媒体 + 公关 + 品牌广告
B2B 案例：HubSpot、Salesforce 早期
B2C 案例：小红书种草、美妆品牌测评矩阵、电商信息流投放
标志指标：自然流量占比、内容带来的线索量/销售量、品牌搜索量增速
```

### SLG — 销售驱动增长（Sales-Led Growth）
```
核心逻辑：销售团队对重点客户/渠道实施深度攻坚
适用场景：高客单价、长决策周期、复杂决策链
典型动作（企业）：SDR/BDR 外拓 + AE 深度跟进 + 高管对接 + POC 验证
典型动作（消费）：KA 渠道团队 + 商超导购赋能 + 分销商管理 + 样板间推广
B2B 案例：SAP、Oracle、Workday
消费品案例：宝洁 KA 渠道精耕、白酒品牌宴席场景攻坚
标志指标：（企业）MRR/ARR、ACV、赢率；（消费）渠道覆盖率、终端动销率
```

### PLG — 产品驱动增长（Product-Led Growth）
```
核心逻辑：产品体验本身驱动用户自发传播和扩散
适用场景：低使用门槛、具有协作/社交属性或工具型功能
典型动作：免费计划/试用 + 产品内引导 + 口碑推荐 + 病毒裂变机制
B2B 案例：Slack、Figma、Notion、Dropbox
C端案例：拼多多（社交裂变）、Keep（打卡分享）、Wordle（天然病毒性）、TikTok（算法推荐+UGC）
标志指标：激活率、PQL（产品合格线索）、NPS、D7 留存、K-factor（病毒系数）
GTM 时间线：90天快速迭代
```

### ECG — 生态驱动增长（Ecosystem-Led Growth）
```
核心逻辑：通过 API 集成和伙伴嵌入，借助合作伙伴生态实现分发
适用场景：平台型产品，具有模块化、可集成特性
典型动作：开放 API + 伙伴计划 + Marketplace 上架 + 集成生态建设
B2B 案例：Atlassian（2020年 63% 营收来自渠道，S&M 成本比率最低）
消费案例：微信小程序生态、支付宝生活号、苹果 App Store 开发者生态
标志指标：合作伙伴带来的营收占比、集成数量、生态 NPS
```

### CLG — 社区驱动增长（Community-Led Growth）
```
核心逻辑：围绕共同身份、兴趣或目标构建用户社区，社区成为增长飞轮
适用场景：内容/知识/创作者经济、泛社交产品、垂直兴趣产品
典型动作：KOL/KOC 培育 + UGC 机制 + 论坛/群组 + 用户大使计划
案例：LEGO（乐高迷社区）、Peloton（健身社群）、Figma 设计社区、哔哩哔哩 UP 主生态
标志指标：DAU/MAU 比值、UGC 内容量、社区 NPS、成员推荐率
```

## 三、GTM 三阶段执行框架

### 阶段一：预启动（Pre-Launch）—— 奠基
> 时间：启动前 4-8 周

```
1. 市场研究与需求验证
   ├── SWOT 分析
   ├── 竞争矩阵（功能/定价/定位）
   ├── TAM/SAM/SOM 市场规模估算
   └── 验证核心假设：这个问题是真实存在的吗？

2. ICP 定义与客户画像
   ├── 理想客户画像（ICP）：行业/规模/痛点/预算/决策链
   ├── 用户 Persona：角色/目标/阻力/信息获取渠道
   └── 客户旅程地图：感知 → 考虑 → 决策 → 使用 → 推荐

3. 定位与价值主张
   ├── 价值主张公式：
   │   「为 [目标客户]，[产品名] 是一款 [类别]，
   │    它能解决 [核心问题]，带来 [量化收益]，
   │    不同于 [竞品]，我们的优势是 [差异化]。」
   ├── 定位声明（内部对齐用）
   └── 核心信息架构（面向不同角色的差异化话语体系）

4. 定价策略选择
   ├── 成本加成定价：基于成本 + 目标利润率
   ├── 价值定价：基于客户感知价值（1% 价格提升 → 利润提升 2-4x）
   ├── 竞争对标定价：基于竞品价格锚定
   └── 渗透定价：低价快速获客，后期提价

5. 销售模型选择
   ├── 自助服务（Self-Service）：低客单 + 个人/散户
   ├── 线上销售（Inside Sales）：中小企业 + 网页/电话演示
   ├── 现场销售（Field Sales）：大客户 + 复杂方案 + 行业专家
   └── 渠道销售（Channel Sales）：借力合作伙伴网络分销

6. 销售使能准备
   ├── 产品介绍材料（商务 PPT + 技术 PPT）
   ├── 竞品对比手册（销售内部用，保密）
   ├── 常见问题 FAQ
   └── 演示 Demo 脚本
```

### 阶段二：正式启动（Launch）—— 执行
> 时间：启动期 2-4 周

```
1. 产品与团队就绪检验
   ├── 内外部 Beta 测试完成
   ├── 销售/客成团队培训完成
   ├── 客户入驻（Onboarding）流程验证
   └── 支持体系（文档/工单/FAQ）就位

2. 获客渠道激活
   ├── 内容营销（博客/白皮书/案例）发布
   ├── SEO/SEM 启动
   ├── 社交媒体与社区运营
   ├── PR 与行业媒体发稿
   └── Email 序列激活（老客/潜在客户）

3. 需求与线索生成
   ├── 落地页（Landing Page）上线
   ├── 线上/线下活动（Webinar/展会）
   ├── 免费试用/Freemium 入口开放（PLG）
   └── SDR 外拓序列启动（SLG）

4. 反馈收集机制
   ├── 用户行为埋点上线
   ├── NPS/CSAT 调研启动
   └── 销售反馈周报机制建立
```

### 阶段三：优化迭代（Post-Launch）—— 持续增长
> 时间：启动后持续进行

```
1. 客户留存与扩张
   ├── 客户健康度监测（产品使用率/NPS/续约风险）
   ├── 扩展销售（Upsell/Cross-sell）
   ├── 客户成功案例沉淀（Case Study/证言）
   └── 推荐计划（Referral Program）

2. 数据分析与迭代
   ├── 转化漏斗分析（各阶段流失原因）
   ├── CAC/LTV 单元经济模型验证
   ├── 渠道 ROI 对比与预算再分配
   └── GTM Fit 信号识别（留存曲线趋平 / PQL 稳定增长）

3. 竞争监测
   ├── 定期竞品动态追踪
   ├── 定位信息更新
   └── 赢/失单分析（Win/Loss Analysis）
```

## 四、GTM 8 步规划流程

> 综合 Slideworks（麦肯锡/贝恩/BCG框架）+ GTM Alliance + SiteCenter + 运营派

```
Step 1: 明确业务目标
  → 为什么要做这次 GTM？（新产品上市/新市场进入/增长加速/竞品防御）
  → 成功标准是什么？（ARR目标/市场份额/用户数/CAC回收期）

Step 2: 市场细分（Segmentation）
  → B2B 维度：行业/公司规模/地域/技术栈（Firmographic + Technographic）
  → B2C 维度：人口特征/心理特征/行为数据（Demographic + Psychographic）
  → 输出：市场细分矩阵

Step 3: 竞争研究与需求验证
  → 直接竞品 + 间接竞品 + 潜在替代方案
  → 市场需求信号（搜索量/社区讨论/客户访谈）
  → 竞争空白点识别

Step 4: 目标细分市场选择 + 价值主张设计
  → 评估标准：市场规模 × 增长率 × 竞争强度 × 战略匹配度
  → 差异化价值主张（量化：省多少时间/钱/资源）

Step 5: 客户旅程地图
  → 感知（Awareness）：客户如何第一次知道我们？
  → 考虑（Consideration）：客户如何评估我们？
  → 决策（Decision）：客户如何最终选择我们？
  → 使用（Retention）：客户如何持续使用并续约？
  → 推荐（Advocacy）：客户如何成为推广者？

Step 6: 销售策略设计
  → 选择主要销售模型（自助/线上/现场/渠道）
  → 销售流程标准化（SDR → AE → CSM 交接点）
  → 销售材料与使能工具包

Step 7: 营销渠道选择
  → 与目标客户的媒体习惯匹配
  → 渠道组合：付费（SEM/信息流）+ 自有（官网/邮件）+ 赢得（PR/口碑）
  → 内容日历与发布节奏

Step 8: 定价策略 + 成功指标
  → 定价模型（订阅/席位/使用量/混合）
  → GTM KPI 体系（见下方指标框架）
```

## 五、GTM KPI 指标体系

> 一个好的 GTM 指标必须：可量化、与业务目标挂钩、有明确基准、能快速反映变化

### 获客指标
| 指标 | 定义 | 健康基准（SaaS参考） |
|------|------|-------------------|
| CAC | 客户获取成本 | 与 LTV 比 1:3 以上 |
| MQL | 营销合格线索数 | 月环比增速 >10% |
| SQL | 销售合格线索数 | MQL→SQL 转化率 >20% |
| 试用启动率 | 注册→激活比例 | >40%（PLG） |
| 自然流量增速 | 搜索/直接流量增长 | 月环比 >5% |

### 转化指标
| 指标 | 定义 | 健康基准 |
|------|------|---------|
| 漏斗各阶段转化率 | 感知→试用→付费→续约 | 因业务差异较大 |
| 销售周期 | 首次接触→签约天数 | SMB <30天；企业 <90天 |
| 赢率（Win Rate） | 竞争性评估中的胜出率 | >30% 为健康 |
| ACV | 年度合同价值 | 与产品定位匹配 |

### 留存与增长指标
| 指标 | 定义 | 健康基准 |
|------|------|---------|
| NRR | 净收入留存率（含扩展） | >110% 为优秀 |
| GRR | 总收入留存率（仅老客） | >85% |
| LTV:CAC | 客户终身价值/获客成本 | >3:1 |
| NPS | 净推荐值 | >40 为良好 |

## 六、中国市场 GTM 特殊考量

> 来源：人人都是产品经理 + 知乎 + 运营派

### 渠道生态差异
```
To C 渠道优先级：
  微信生态（公众号/视频号/小程序）→ 抖音/快手 → 小红书 → B站 → 微博

To B 渠道优先级：
  企业微信 → 钉钉 → 飞书 → 行业垂直媒体 → 线下展会 → 渠道合作伙伴

私域运营：
  - 社群运营是中国 B2C/B2SMB 独特的 GTM 优势
  - 企业微信客户群 + 内容运营 = 低成本留存机制
```

### 销售文化差异
```
- 关系（Guanxi）是 B2B 决策的重要非正式因素
- 高管层面的背书/站台对大客户决策影响显著
- 招投标（Bidding）是政府/央企/国企主要采购模式
- 渠道商/代理商在传统行业渗透率极高
```

### 定价策略差异
```
- 价格敏感度高于欧美市场
- 免费/低价切入再升级的路径更有效
- 本地化定价（人民币计价 + 本地收款方式）是基本要求
- 行业专属解决方案比通用产品更容易定价溢价
```

## 七、GTM 失败常见陷阱

```
✗ 把 GTM 当作一次性事件，而非持续演进的框架
✗ PMF 未验证就急于 GTM（42% 的创业失败原因是解决了不真实的问题）
✗ 同时使用多个增长模型，缺乏聚焦
✗ 定价过低（感知价值低）或过高（转化摩擦大），忽略价格对利润的杠杆效应
✗ 渠道选择未与目标客户的媒体习惯匹配
✗ 忽略销售使能，导致销售团队无法有效传递价值主张
✗ KPI 缺乏具体数字与时间节点，成为无法衡量的口号
✗ GTM Fit 信号出现后未及时扩大投入（留存曲线趋平 = 扩大信号）
```

## 十一、品牌定位与营销框架（niranjanbala/brand-marketing-frameworks）

> 参考：[niranjanbala/brand-marketing-frameworks](https://github.com/niranjanbala/brand-marketing-frameworks)
> 品牌定位是 GTM 战略的基础——在执行 GTM 之前，必须先明确品牌在目标客户心智中的位置。

### 品牌定位声明

```
模板：
「对于 [目标受众]，[品牌名] 是 [参照框架/品类]，
 它提供 [核心利益]，因为 [支撑理由]。
 不同于 [竞争对手]，我们 [差异化优势]。」

示例（AI写作工具）：
「对于需要高频输出内容的中文创作者，WorkAgent 是一款
 风格驱动的 AI 写作平台，它能让内容保持真实人声，
 因为我们融合了五套去AI痕迹方法论。
 不同于通用 AI 工具，我们专注于中文内容的"活人感"。」
```

### 品牌 DNA 五要素

```markdown
1. 核心价值（Core Values）：品牌坚守的根本信念
   → 在 GTM 信息架构中体现为"为什么我们存在"

2. 品牌个性（Brand Personality）：如果品牌是一个人，他是谁？
   → 决定 GTM 内容的语气和风格

3. 品牌承诺（Brand Promise）：对客户的核心承诺
   → 转化为 GTM 的核心价值主张

4. 品牌故事（Brand Story）：为什么存在，从哪里来
   → 用于 PR 稿、About 页面、融资 Deck

5. 视觉识别（Visual Identity）：颜色/字体/图形语言
   → 确保 GTM 所有触点视觉一致性
```

### 品牌-GTM 对齐检查

```markdown
GTM 执行前，确认以下品牌-GTM 对齐项：

□ 落地页标题是否体现品牌承诺？
□ 广告文案语气是否符合品牌个性？
□ 销售话术是否与品牌定位声明一致？
□ 内容营销主题是否强化品牌核心价值？
□ 定价策略是否与品牌定位（高端/亲民）匹配？
□ 渠道选择是否与目标受众的媒体习惯匹配？
```

### 营销信息架构（Messaging Framework）

```markdown
## 三层信息架构

Layer 1：核心信息（对所有受众）
  → 一句话价值主张（电梯演讲版）
  → 用于：官网首屏、广告标题、PR稿导语

Layer 2：角色信息（针对不同 Persona）
  → 技术决策者：强调安全/集成/可扩展性
  → 业务决策者：强调 ROI/效率/竞争优势
  → 最终用户：强调易用性/节省时间/体验

Layer 3：场景信息（针对具体使用场景）
  → 用于：功能页面、案例研究、销售演示
  → 每个场景对应一个具体痛点和解决方案
```
