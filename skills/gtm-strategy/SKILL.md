# GTM Strategy — B2B 上市战略知识库

> 知识整合自：B2B 产品 Go-To-Market 实战 SOP、SlideModel、Userpilot、SiteCentre、
> Slideworks（McKinsey / BCG / Bain 咨询框架）、ProductPlan、GTM Alliance、SalesMotion、
> Copy.ai、Asana、人人都是产品经理、知乎、运营派。
>
> **核心理念**：
> - **B2B GTM 的本质，不是「做一次发布」**，而是把产品从「能用」推向「有人买、能交付、可复制增长」的全过程；
> - GTM 是连接 PMF 与规模化增长的桥梁，是一条持续演进的策略线，不是一次性事件；
> - 整体可分为 **市场验证 → 产品包装 → 样板客户 → 正式发布 → 规模化销售 → 持续增长** 六个阶段。

---

## 一、B2B GTM 六阶段 SOP（主框架）

> 这是 B2B 产品上市的标准 SOP。无论 SaaS、行业解决方案、平台产品还是服务，都建议按以下六个阶段推进。
> 时间窗以「正式发布周」（T 周）为锚点，前后共约 12 周完整 SOP。

### 阶段 0：GTM 筹备期（T-8 ~ T-6 周）—— 卖给谁、为什么买
> 不要急着做宣传，先回答清楚：产品到底卖给谁、客户为什么现在要买、买了之后解决什么问题。

| 工作项 | 具体动作 | 输出物 |
|--------|---------|--------|
| 明确目标客户 ICP | 定义客户行业、规模、角色、预算、采购路径 | ICP 画像 |
| 明确核心场景 | 找出 3–5 个最容易成交的高价值场景 | 场景清单 |
| 明确客户痛点 | 梳理客户当前成本、风险、效率、合规压力 | 痛点地图 |
| 竞品分析 | 分析同类产品功能、价格、客户、差异点 | 竞品对比表 |
| 价值主张 | 提炼一句话定位和 3 个核心卖点 | 产品定位文案 |

**这一阶段必须回答的 6 个关键问题**
1. 谁最痛？2. 谁有预算？3. 谁有采购权？
4. 谁最容易成为样板客户？5. 我们比竞品强在哪里？6. 客户为什么现在必须行动？

**阶段闸门**：ICP / 场景 / 痛点 / 竞品对比 / 一句话定位 / 核心价值主张全部明确，否则不进入阶段 1。

---

### 阶段 1：产品包装期（T-6 ~ T-4 周）—— 把技术能力包装成可购买的解决方案
> 很多 B2B 产品失败，不是产品能力不强，而是**客户听不懂、销售讲不清、材料不成体系**。

| 工作项 | 具体动作 | 输出物 |
|--------|---------|--------|
| 产品定位包装 | 明确产品是什么、不是什么、解决什么问题 | 产品介绍页 |
| 方案包装 | 按行业 / 场景形成解决方案 | 行业解决方案 PPT |
| 销售材料 | 准备销售可直接使用的材料 | BP、售前 PPT、FAQ |
| 技术材料 | 准备技术评审和客户 CTO 可看的材料 | 白皮书、架构图、部署方案 |
| Demo 准备 | 做一个能快速打动客户的演示流程 | Demo 脚本 |
| 报价设计 | 设计 SaaS / 私有化 / 订阅 / 项目制报价 | 报价单 |

**产品包装的标准结构（所有 B2B 材料都按这个逻辑组织）**：
行业趋势 → 客户痛点 → 解决方案 → 产品架构 → 核心功能 → 典型场景 → 客户价值 → 部署方式 → 成功案例 → 商务模式

**阶段交付物**：产品官网页面 / 产品介绍 PPT / 解决方案 PPT / 技术白皮书 / 产品架构图 / Demo 视频与脚本 / 客户 FAQ / 报价体系 / 合同模板。

---

### 阶段 2：内测与样板客户期（T-4 ~ T-1 周）—— 找到可讲、可复用、可信的案例
> 目标不是大规模销售，而是 **快速验证产品价值，沉淀样板案例**。

| 工作项 | 具体动作 | 输出物 |
|--------|---------|--------|
| 招募种子客户 | 从已有关系、行业客户、合作伙伴中筛选 | 种子客户名单 |
| 设计 POC | 明确 POC 范围、周期、成功标准 | POC 方案 |
| 快速交付 | 用小范围场景验证核心价值 | POC 结果 |
| 收集反馈 | 记录客户问题、需求、反对意见 | 反馈清单 |
| 打磨案例 | 提炼客户价值、数据、前后对比 | 案例素材 |
| 调整产品 | 根据反馈优化功能、话术、定价 | 迭代清单 |

**POC 成功标准（每个 POC 开始前必须定义清楚，否则容易变成无限试用）**
- 验证什么场景？用什么数据？多久完成？
- 谁来验收？什么结果算成功？成功后下一步是什么？

**阶段交付物**：种子客户清单 / POC 标准方案 / POC 验收标准 / 客户反馈记录 / 样板案例初稿 / 产品优化清单 / **销售反对意见库**。

---

### 阶段 3：正式发布期（T 周）—— 触达正确的人，而非全民刷屏
> 目标是制造市场认知，让客户知道你是谁、解决什么问题、为什么值得了解。
> B2B 发布**不追求全民刷屏，更重要的是触达正确的人**。

| 工作项 | 具体动作 | 输出物 |
|--------|---------|--------|
| 发布内容 | 发布产品文章、官网、海报、视频 | 发布物料包 |
| 市场传播 | 微信公众号、媒体、社群、朋友圈、行业群 | 传播计划 |
| 销售跟进 | 同步销售名单，统一话术 | 销售作战表 |
| 渠道联动 | 让合作伙伴同步转发和推荐 | 渠道传播清单 |
| 线索承接 | 建表记录咨询客户、预约 Demo、下载资料 | 线索表 |
| 高管背书 | 创始人、专家、客户证言增强信任 | 背书素材 |

**正式发布的最小物料组合**：1 篇长文 + 1 张产品海报 + 1 个官网页面 + 1 个 3–5 分钟 Demo 视频 + 1 套销售 PPT + 1 份技术白皮书 + 1 份客户 FAQ + 1 个预约 Demo 表单。

---

### 阶段 4：销售转化期（T+1 ~ T+8 周）—— 把声量转成商机与合同
> 发布之后最关键的不是继续发文章，而是 **快速把线索转化成商机、POC、报价和合同**。

| 工作项 | 具体动作 | 输出物 |
|--------|---------|--------|
| 线索分级 | 按客户价值、预算、需求急迫度分级 | A/B/C 客户池 |
| 销售触达 | 电话、微信、会议、拜访 | 跟进记录 |
| 需求诊断 | 识别客户真实场景、痛点、预算、采购流程 | 需求调研表 |
| 售前方案 | 输出针对客户场景的方案 | 定制方案 |
| POC 推进 | 控制周期和验收标准 | POC 报告 |
| 商务报价 | 根据客户规模和部署方式报价 | 报价单 |
| 合同推进 | 法务、采购、付款、交付排期 | 合同与回款计划 |

**线索分级建议**
| 等级 | 特征 | 动作 |
|------|------|------|
| A 类 | 有明确需求、预算、负责人、时间表 | 销售和售前重点跟进 |
| B 类 | 有兴趣但需求不清或预算未定 | 持续教育和场景挖掘 |
| C 类 | 只是了解产品 | 进入市场培育池 |

---

### 阶段 5：规模化增长期（T+8 周以后）—— 从单点突破转向可复制增长

| 工作项 | 具体动作 | 输出物 |
|--------|---------|--------|
| 标准化方案 | 把成功项目沉淀成标准方案 | 标准方案包 |
| 行业复制 | 选择 2–3 个重点行业复制 | 行业打法 |
| 渠道建设 | 找集成商、代理商、生态伙伴 | 渠道政策 |
| 客户成功 | 提升续费、扩容、复购 | 客户成功流程 |
| 产品迭代 | 根据客户反馈优化功能 | Roadmap |
| 数据复盘 | 分析线索、转化、客单价、回款 | GTM 复盘报告 |

**增长阶段核心指标**
| 指标类型 | 重点指标 |
|---------|---------|
| 市场指标 | 官网访问、资料下载、预约 Demo、活动报名 |
| 销售指标 | 线索数、商机数、POC 数、报价数、成交数 |
| 商务指标 | 客单价、合同额、回款额、销售周期 |
| 产品指标 | 激活率、使用频次、功能使用率 |
| 客户成功 | 续费率、扩容率、转介绍率 |

### B2B GTM 标准流程图

```
市场洞察 → ICP 定义 → 场景与痛点梳理 → 竞品与差异化分析 → 产品定位与价值主张
       → 产品包装与销售材料 → 种子客户 / POC → 样板案例沉淀
       → 正式发布 → 销售线索承接 → 商机推进 / 报价 / 合同
       → 客户成功 / 复购 / 行业复制
```

### 每个阶段最容易踩的坑

| 阶段 | 常见问题 | 正确做法 |
|------|---------|---------|
| 市场定义 | 客户太泛，谁都想卖 | 先锁定最痛、最容易成交的客户 |
| 产品包装 | 只讲技术，不讲客户价值 | 用客户痛点组织产品能力 |
| POC | 没有验收标准，越试越久 | POC 前明确范围、周期和成功标准 |
| 发布 | 只做声量，不接线索 | 发布前准备线索承接机制 |
| 销售 | 只讲产品，不问需求 | 先做诊断，再给方案 |
| 增长 | 每个项目都定制 | 把成功案例沉淀为标准打法 |

## 二、GTM 的定义与适用时机

### 定义
GTM（Go-to-Market）是将特定产品成功推向目标市场的战术执行框架，覆盖从市场准入到规模化增长的全链路：
- **Reach**：通过市场营销触达潜在客户
- **Win**：通过销售转化完成成交
- **Retain & Grow**：通过客户成功实现留存与扩张

### 触发时机（Ansoff 矩阵对应）
| 场景 | 产品 | 市场 | GTM 需要程度 |
|------|------|------|------------|
| 市场渗透 | 现有 | 现有 | 低（优化即可） |
| 产品延伸 | 新增 | 现有 | 中（营销计划） |
| 市场扩张 | 现有 | 新进 | 高（完整 GTM） |
| 多元扩张 | 新增 | 新进 | 极高（最全面 GTM） |

### GTM vs. 普通营销计划
| 维度 | 营销计划 | GTM 战略 |
|------|---------|---------|
| 范围 | 市场推广活动 | 覆盖全部客户触点 |
| 时间 | 持续运营 | 围绕产品生命周期 |
| 跨部门协作 | 以营销为主 | 产品/销售/市场/客成全部参与 |
| 核心问题 | 如何推广？ | 卖什么/怎么卖/卖给谁/去哪卖？ |

## 三、GTM 增长模型五选一（可叠加到上面的六阶段 SOP 上）

> **关键原则**：早期专注一个主模型，验证后再叠加。

### MLG — 营销驱动增长（Marketing-Led Growth）
```
核心逻辑：通过内容、SEO、广告占领认知高地，让客户主动找来
适用场景：需要建立专业可信度，决策周期较长的产品
典型动作：内容营销 + SEO + 行业媒体 + 公关 + 品牌广告
B2B 案例：HubSpot、Salesforce 早期
B2C 案例：小红书种草、美妆品牌测评矩阵、电商信息流投放
标志指标：自然流量占比、内容带来的线索量/销售量、品牌搜索量增速
```

### SLG — 销售驱动增长（Sales-Led Growth）
```
核心逻辑：销售团队对重点客户/渠道实施深度攻坚
适用场景：高客单价、长决策周期、复杂决策链
典型动作（企业）：SDR/BDR 外拓 + AE 深度跟进 + 高管对接 + POC 验证
典型动作（消费）：KA 渠道团队 + 商超导购赋能 + 分销商管理 + 样板间推广
B2B 案例：SAP、Oracle、Workday
消费品案例：宝洁 KA 渠道精耕、白酒品牌宴席场景攻坚
标志指标：（企业）MRR/ARR、ACV、赢率；（消费）渠道覆盖率、终端动销率
```

### PLG — 产品驱动增长（Product-Led Growth）
```
核心逻辑：产品体验本身驱动用户自发传播和扩散
适用场景：低使用门槛、具有协作/社交属性或工具型功能
典型动作：免费计划/试用 + 产品内引导 + 口碑推荐 + 病毒裂变机制
B2B 案例：Slack、Figma、Notion、Dropbox
C端案例：拼多多（社交裂变）、Keep（打卡分享）、Wordle（天然病毒性）、TikTok（算法推荐+UGC）
标志指标：激活率、PQL（产品合格线索）、NPS、D7 留存、K-factor（病毒系数）
GTM 时间线：90天快速迭代
```

### ECG — 生态驱动增长（Ecosystem-Led Growth）
```
核心逻辑：通过 API 集成和伙伴嵌入，借助合作伙伴生态实现分发
适用场景：平台型产品，具有模块化、可集成特性
典型动作：开放 API + 伙伴计划 + Marketplace 上架 + 集成生态建设
B2B 案例：Atlassian（2020年 63% 营收来自渠道，S&M 成本比率最低）
消费案例：微信小程序生态、支付宝生活号、苹果 App Store 开发者生态
标志指标：合作伙伴带来的营收占比、集成数量、生态 NPS
```

### CLG — 社区驱动增长（Community-Led Growth）
```
核心逻辑：围绕共同身份、兴趣或目标构建用户社区，社区成为增长飞轮
适用场景：内容/知识/创作者经济、泛社交产品、垂直兴趣产品
典型动作：KOL/KOC 培育 + UGC 机制 + 论坛/群组 + 用户大使计划
案例：LEGO（乐高迷社区）、Peloton（健身社群）、Figma 设计社区、哔哩哔哩 UP 主生态
标志指标：DAU/MAU 比值、UGC 内容量、社区 NPS、成员推荐率
```

## 四、GTM 三阶段执行框架（通用版，与上面的六阶段 SOP 互补）

### 阶段一：预启动（Pre-Launch）—— 奠基
> 时间：启动前 4-8 周

```
1. 市场研究与需求验证
   ├── SWOT 分析
   ├── 竞争矩阵（功能/定价/定位）
   ├── TAM/SAM/SOM 市场规模估算
   └── 验证核心假设：这个问题是真实存在的吗？

2. ICP 定义与客户画像
   ├── 理想客户画像（ICP）：行业/规模/痛点/预算/决策链
   ├── 用户 Persona：角色/目标/阻力/信息获取渠道
   └── 客户旅程地图：感知 → 考虑 → 决策 → 使用 → 推荐

3. 定位与价值主张
   ├── 价值主张公式：
   │   「为 [目标客户]，[产品名] 是一款 [类别]，
   │    它能解决 [核心问题]，带来 [量化收益]，
   │    不同于 [竞品]，我们的优势是 [差异化]。」
   ├── 定位声明（内部对齐用）
   └── 核心信息架构（面向不同角色的差异化话语体系）

4. 定价策略选择
   ├── 成本加成定价：基于成本 + 目标利润率
   ├── 价值定价：基于客户感知价值（1% 价格提升 → 利润提升 2-4x）
   ├── 竞争对标定价：基于竞品价格锚定
   └── 渗透定价：低价快速获客，后期提价

5. 销售模型选择
   ├── 自助服务（Self-Service）：低客单 + 个人/散户
   ├── 线上销售（Inside Sales）：中小企业 + 网页/电话演示
   ├── 现场销售（Field Sales）：大客户 + 复杂方案 + 行业专家
   └── 渠道销售（Channel Sales）：借力合作伙伴网络分销

6. 销售使能准备
   ├── 产品介绍材料（商务 PPT + 技术 PPT）
   ├── 竞品对比手册（销售内部用，保密）
   ├── 常见问题 FAQ
   └── 演示 Demo 脚本
```

### 阶段二：正式启动（Launch）—— 执行
> 时间：启动期 2-4 周

```
1. 产品与团队就绪检验
   ├── 内外部 Beta 测试完成
   ├── 销售/客成团队培训完成
   ├── 客户入驻（Onboarding）流程验证
   └── 支持体系（文档/工单/FAQ）就位

2. 获客渠道激活
   ├── 内容营销（博客/白皮书/案例）发布
   ├── SEO/SEM 启动
   ├── 社交媒体与社区运营
   ├── PR 与行业媒体发稿
   └── Email 序列激活（老客/潜在客户）

3. 需求与线索生成
   ├── 落地页（Landing Page）上线
   ├── 线上/线下活动（Webinar/展会）
   ├── 免费试用/Freemium 入口开放（PLG）
   └── SDR 外拓序列启动（SLG）

4. 反馈收集机制
   ├── 用户行为埋点上线
   ├── NPS/CSAT 调研启动
   └── 销售反馈周报机制建立
```

### 阶段三：优化迭代（Post-Launch）—— 持续增长
> 时间：启动后持续进行

```
1. 客户留存与扩张
   ├── 客户健康度监测（产品使用率/NPS/续约风险）
   ├── 扩展销售（Upsell/Cross-sell）
   ├── 客户成功案例沉淀（Case Study/证言）
   └── 推荐计划（Referral Program）

2. 数据分析与迭代
   ├── 转化漏斗分析（各阶段流失原因）
   ├── CAC/LTV 单元经济模型验证
   ├── 渠道 ROI 对比与预算再分配
   └── GTM Fit 信号识别（留存曲线趋平 / PQL 稳定增长）

3. 竞争监测
   ├── 定期竞品动态追踪
   ├── 定位信息更新
   └── 赢/失单分析（Win/Loss Analysis）
```

## 五、GTM 8 步规划流程（McKinsey/BCG/Bain 框架）

> 综合 Slideworks（麦肯锡/贝恩/BCG框架）+ GTM Alliance + SiteCenter + 运营派

```
Step 1: 明确业务目标
  → 为什么要做这次 GTM？（新产品上市/新市场进入/增长加速/竞品防御）
  → 成功标准是什么？（ARR目标/市场份额/用户数/CAC回收期）

Step 2: 市场细分（Segmentation）
  → B2B 维度：行业/公司规模/地域/技术栈（Firmographic + Technographic）
  → B2C 维度：人口特征/心理特征/行为数据（Demographic + Psychographic）
  → 输出：市场细分矩阵

Step 3: 竞争研究与需求验证
  → 直接竞品 + 间接竞品 + 潜在替代方案
  → 市场需求信号（搜索量/社区讨论/客户访谈）
  → 竞争空白点识别

Step 4: 目标细分市场选择 + 价值主张设计
  → 评估标准：市场规模 × 增长率 × 竞争强度 × 战略匹配度
  → 差异化价值主张（量化：省多少时间/钱/资源）

Step 5: 客户旅程地图
  → 感知（Awareness）：客户如何第一次知道我们？
  → 考虑（Consideration）：客户如何评估我们？
  → 决策（Decision）：客户如何最终选择我们？
  → 使用（Retention）：客户如何持续使用并续约？
  → 推荐（Advocacy）：客户如何成为推广者？

Step 6: 销售策略设计
  → 选择主要销售模型（自助/线上/现场/渠道）
  → 销售流程标准化（SDR → AE → CSM 交接点）
  → 销售材料与使能工具包

Step 7: 营销渠道选择
  → 与目标客户的媒体习惯匹配
  → 渠道组合：付费（SEM/信息流）+ 自有（官网/邮件）+ 赢得（PR/口碑）
  → 内容日历与发布节奏

Step 8: 定价策略 + 成功指标
  → 定价模型（订阅/席位/使用量/混合）
  → GTM KPI 体系（见下方指标框架）
```

## 六、GTM KPI 指标体系

> 一个好的 GTM 指标必须：可量化、与业务目标挂钩、有明确基准、能快速反映变化

### 获客指标
| 指标 | 定义 | 健康基准（SaaS参考） |
|------|------|-------------------|
| CAC | 客户获取成本 | 与 LTV 比 1:3 以上 |
| MQL | 营销合格线索数 | 月环比增速 >10% |
| SQL | 销售合格线索数 | MQL→SQL 转化率 >20% |
| 试用启动率 | 注册→激活比例 | >40%（PLG） |
| 自然流量增速 | 搜索/直接流量增长 | 月环比 >5% |

### 转化指标
| 指标 | 定义 | 健康基准 |
|------|------|---------|
| 漏斗各阶段转化率 | 感知→试用→付费→续约 | 因业务差异较大 |
| 销售周期 | 首次接触→签约天数 | SMB <30天；企业 <90天 |
| 赢率（Win Rate） | 竞争性评估中的胜出率 | >30% 为健康 |
| ACV | 年度合同价值 | 与产品定位匹配 |

### 留存与增长指标
| 指标 | 定义 | 健康基准 |
|------|------|---------|
| NRR | 净收入留存率（含扩展） | >110% 为优秀 |
| GRR | 总收入留存率（仅老客） | >85% |
| LTV:CAC | 客户终身价值/获客成本 | >3:1 |
| NPS | 净推荐值 | >40 为良好 |

## 七、中国市场 GTM 特殊考量

> 来源：人人都是产品经理 + 知乎 + 运营派

### 渠道生态差异
```
To C 渠道优先级：
  微信生态（公众号/视频号/小程序）→ 抖音/快手 → 小红书 → B站 → 微博

To B 渠道优先级：
  企业微信 → 钉钉 → 飞书 → 行业垂直媒体 → 线下展会 → 渠道合作伙伴

私域运营：
  - 社群运营是中国 B2C/B2SMB 独特的 GTM 优势
  - 企业微信客户群 + 内容运营 = 低成本留存机制
```

### 销售文化差异
```
- 关系（Guanxi）是 B2B 决策的重要非正式因素
- 高管层面的背书/站台对大客户决策影响显著
- 招投标（Bidding）是政府/央企/国企主要采购模式
- 渠道商/代理商在传统行业渗透率极高
```

### 定价策略差异
```
- 价格敏感度高于欧美市场
- 免费/低价切入再升级的路径更有效
- 本地化定价（人民币计价 + 本地收款方式）是基本要求
- 行业专属解决方案比通用产品更容易定价溢价
```

## 八、GTM 失败常见陷阱

```
✗ 把 GTM 当作一次性事件，而非持续演进的框架
✗ PMF 未验证就急于 GTM（42% 的创业失败原因是解决了不真实的问题）
✗ 同时使用多个增长模型，缺乏聚焦
✗ 定价过低（感知价值低）或过高（转化摩擦大），忽略价格对利润的杠杆效应
✗ 渠道选择未与目标客户的媒体习惯匹配
✗ 忽略销售使能，导致销售团队无法有效传递价值主张
✗ KPI 缺乏具体数字与时间节点，成为无法衡量的口号
✗ GTM Fit 信号出现后未及时扩大投入（留存曲线趋平 = 扩大信号）
```
