# Marketing Copy — 产品营销推广内容知识库

> 区别于 `article-writer`（公众号长文，"有见识的普通人聊"风格）：
> 本 Skill 服务于**带营销目的的产品推广内容**，目标是促成认知 / 留资 / 转化，
> 不是表达个人观点。语气克制、价值前置、CTA 明确。

## 二、写作铁律（所有文体通用）

### 1. 价值前置
任何文体的前 3 行 / 前 3 秒 / 前 1 屏，必须回答："读者凭什么继续看？"
- 错：「在数字化转型的大背景下……」
- 对：「我们帮一家城商行把异常交易识别延迟从 8 小时压到 2 分钟。」

### 2. 数字 > 形容词
- 错：「大幅提升效率」「显著降低成本」「行业领先」
- 对：「效率提升 4.2 倍」「年节省 230 万」「省级农信前 3」

### 3. 一句话能说清楚的，不写两句
营销内容的每一句都要"做事"：要么传递信息、要么调动情绪、要么推进行动。

### 4. 永远有明确 CTA
- 加微信留资？扫码？点击「了解详情」？预约 Demo？下载白皮书？
- 一篇内容只有一个主 CTA，避免分流。

### 5. 避雷词清单（AI 套话）
不允许出现：
- 「赋能」「全栈」「闭环」「打通」「破局」「迭代升级」
- 「值得注意的是」「综上所述」「不得不说」「在这个 XX 的时代」
- 「首先 / 其次 / 再次」（除非真的在列步骤）
- 「不仅 X，更 X」「让 X 变得更 X」

### 6. ToB / ToC 双语风切换

| 维度 | ToB | ToC |
|------|-----|-----|
| 决策动机 | ROI / 合规 / 效率 / 风险 | 体验 / 情绪 / 身份 / 价格 |
| 证据类型 | 客户 Logo / 数字 / 资质 / 案例 | 真实使用 / KOL / 评分 / UGC |
| 语气 | 专业克制 | 真诚有温度 |
| CTA | 预约 Demo / 联系销售 | 立即购买 / 加群 / 关注 |
| 长度容忍 | 长文有市场 | 越短越好 |

## 三、文体详规

### 文体 1：公众号软文

**结构框架**：
```
1. 钩子（200-300 字）
   - 反常识 / 数据冲击 / 故事场景 / 行业争议
   - 例：「过去半年，我们拒绝了 3 家城商行的合作」

2. 痛点放大（500-800 字）
   - 行业普遍现象 → 具体场景 → 业务后果
   - 用客户的话讲客户的事

3. 方法论 / 解法（800-1200 字）
   - 给出"为什么我们能解决"的逻辑链
   - 不卖产品，卖思路

4. 案例举证（500-800 字）
   - 一个客户故事，不超过 800 字
   - 量化结果优先

5. CTA（100-200 字）
   - 关注公众号 / 私信加微 / 预约 Demo
   - 给出"下一步具体怎么做"
```

**标题套路**：
- 反差型：「不卖给央企的国产化产品，凭什么活下来」
- 数字型：「3 个月让 SOC 误报率降 70%，方法都在这」
- 痛点型：「城商行做合规这件事，可能都做反了」
- 故事型：「央企客户问我们：你们凭什么收 200 万」

### 文体 2：小红书种草

**结构框架**：
```
标题（≤20 字）：emoji + 数字 + 痛点
  例：💡 中小银行做安全运营，3 个雷区别踩

封面：图片 + 9 字以内大字标题
  视觉对比强烈、第一眼能读完

正文（800-1500 字）：
  - 真人开场（"我做了 5 年金融安全……"）
  - 干货分点（用 1️⃣ 2️⃣ 3️⃣ 区分）
  - 个人体验穿插（"我们之前也踩过这个坑"）
  - 关键词 hashtag（#金融安全 #SOC #合规）

结尾：
  - 互动钩子（"还有什么问题评论区聊"）
  - 软性 CTA（"主页有更多干货"）
```

**ToB 类小红书种草**（IT 决策人 / 行业研究员）：
- 不写成 "广告"，写成"踩坑分享 / 行业观察 / 工具评测"
- 案例匿名化，强调方法
- 评论区留资，不在正文

### 文体 3：短视频脚本

**60 秒结构**：
```
0-3 秒  | 钩子：3 选 1
        | A. 数字冲击（"我们让 8 小时变成 2 分钟"）
        | B. 反常识（"做安全的 SOC，第一件事不是买设备"）
        | C. 痛点扎心（"半夜 3 点告警，谁来响应？"）

3-15 秒 | 痛点放大 + 共鸣
        | "你是不是也遇到过……"

15-40 秒| 解法 / 方法论
        | 不讲产品功能，讲解决思路

40-55 秒| 证据 / 案例
        | 一个具体客户、一个具体数字

55-60 秒| CTA
        | "完整方法论关注我，私信「白皮书」获取"
```

**镜头语言提示**：
- 0-3 秒优先用「真人入镜 + 字幕」，避免黑屏 / Logo 开场
- 信息密度高的部分一定要配文字字幕
- 关键数字用动效放大

### 文体 4：官网 / 落地页文案

**Hero 区**（首屏）：
```
H1：一句话说清"是什么 + 给谁 + 解决什么"
   例：「为城商行打造的 AI 安全运营平台 — 让 SOC 误报率降 80%」
   不要写：「领先的 AI 安全平台，赋能企业数字化转型」

副标题：补充关键差异点（≤20 字）

主 CTA：动词 + 价值
  ✅「预约 30 分钟 Demo」「下载白皮书」
  ❌「了解更多」「查看详情」

社会证明：客户 Logo 墙 / 媒体报道 / 资质徽章
```

**Feature 区**（产品价值）：
```
每个 Feature 三件套：
  - 客户视角的 Headline（不是功能名）
    ✅「告警从 1000 条降到 50 条」
    ❌「智能告警归并模块」
  - 1 句话解释
  - 3-5 行 Bullet（具体动作）
```

**SEO 关键词嵌入**：
- H1 / Title 必须含主关键词
- 每 200 字自然出现 1 次主关键词
- 长尾关键词放到 H2 / H3
- alt 属性写完整描述

### 文体 5：邮件营销（EDM）

**标题（决定打开率）**：
- 长度：14-25 字
- 三选一：
  - 利益型：「30% off | 双 11 限时」
  - 好奇型：「为什么 80% 的银行做错了 SOC」
  - 紧迫型：「最后 48 小时 | 白皮书下架前抢看」

**正文结构**：
```
1. 一句话价值（不超过 30 字）
2. 主图（与标题强相关）
3. 三段正文（每段 ≤ 3 行）
4. 主 CTA 按钮（动词 + 价值，颜色突出）
5. 备份 CTA（文字链 / 二维码）
```

### 文体 6：新闻通稿 / PR 稿

**倒金字塔结构**：
```
导语（150 字）：
  - 5W1H 全部讲完
  - 「[公司名]，[时间] [地点] 宣布 [事件] [意义]」

主体（500-800 字）：
  - 引用核心数据 / 客户证言 / 高管金句
  - 第三人称，避免"我们"
  - 每段配引语来源

公司介绍（100-150 字）：
  - 标准 boilerplate

媒体联系（结尾）：
  - 联系人 / 邮箱 / 网站
```

**避雷**：
- 不写「领导关怀」「圆满成功」（除非政府类客户要）
- 不写情绪词（"激动"、"骄傲"）
- 数字必须可查证，否则会被记者 challenge

### 文体 7：客户故事 / 案例稿

**标准结构**（外推用）：
```
1. 一句话定位（标题）
   例：「[XX 银行] 用 [我方产品] 把告警响应时间从 4 小时降到 8 分钟」

2. 客户背景（200 字）
   - 客户规模 / 行业地位 / 业务复杂度

3. 业务挑战（300-400 字）
   - 用客户原话讲（"我们 SOC 团队一周告警量超过 50000 条……"）
   - 列出 3 个具体痛点

4. 解决方案（400-500 字）
   - 不写产品功能名，写"做了什么 → 解决了什么"
   - 配架构图 / 流程图

5. 量化结果（300 字）
   - 至少 3 个数字（效率 / 成本 / 风险）
   - 客户 ROI 测算

6. 客户引语（一段，≥80 字）
   - 真实可署名最佳，匿名也要"该客户某 CISO 表示"

7. 关于客户 / 关于我方（boilerplate）
```

**密级规则**：
- 客户名 / 数字 / 截图 → 必须客户书面授权
- 没授权就匿名化（"国内某头部城商行"）
- 行业头部客户优先

### 文体 8：朋友圈文案

**创始人 / 销售个人 IP**：
```
结构：
  第 1 行：钩子（10 字以内，停下手指）
  第 2-4 行：内容（每行不超过 18 字，避免折叠）
  最后 1 行：CTA（"留言/扫码/私信我"）

避雷：
  - 全文超过 6 行 → 折叠率 > 80%
  - 句首"震惊"「重磅」 → 立刻被识别为广告
  - 一天发超过 3 条 → 必被屏蔽
```

### 文体 9：Demo 脚本

**销售 Demo 30 分钟标准**：
```
0-3 分钟   | 客户场景对齐（不打开产品）
3-8 分钟   | 痛点共鸣（讲行业故事）
8-20 分钟  | 产品演示（围绕客户痛点，不是 Feature 列表）
20-25 分钟 | 客户 ROI 测算（具体数字）
25-30 分钟 | Q&A + Next Step（不留作业，留行动）

每个演示动作：
  - 1 句话说"我现在做什么"
  - 1 句话说"客户场景中这意味着什么"
  - 不超过 90 秒展示一个功能
```

## 四、AI 安全产品营销专属话术（业务相关）

### 1. 信任建立优先

AI 产品在 B 端的核心顾虑：
- 幻觉风险 → 强调 Eval 集 + 通过线 + 人工兜底
- 安全合规 → 强调数据隔离 / 国产化 / 等保资质
- 不可解释 → 强调审计日志 / 可追溯 / 灰度

营销内容的开篇钩子推荐：
- ❌「AI 重塑 XX」「智能化转型」（被动 + 套话）
- ✅「AI 不是用来替代 SOC，是用来让 1 个分析师顶 5 个」（具体 + 立场）

### 2. 不卖技术，卖业务结果

| 错误 | 正确 |
|------|------|
| 「基于大模型的告警归并」 | 「告警从 1000 条降到 50 条」 |
| 「Agent 自动化运营」 | 「半夜 3 点告警有人响应，不再叫醒分析师」 |
| 「RAG 知识库问答」 | 「新员工上岗时间从 3 个月降到 1 周」 |

### 3. 避免行业雷区词

合规敏感词（替换建议）：
- 「100% 准确」 → 「业界领先准确率」（必须有数据）
- 「绝对安全」 → 「通过等保三级认证」
- 「替代人工」 → 「让人工聚焦高价值任务」
- 「自主决策」 → 「Human-in-the-Loop」

## 五、与其他 Skill 的边界

| 选择 | 用前者 | 用后者 |
|------|-------|-------|
| `marketing-copy` vs `article-writer` | 带营销目的的推广内容（CTA 明确）| 公众号长文（个人风格 / 表达观点）|
| `marketing-copy` vs `product-doc-writer` | 对外推广 / 多平台分发 | 内部资料体系（白皮书 / 手册 / 案例库）|
| `marketing-copy` vs `sales-guide-writer` | 给读者看的内容 | 给销售用的内部话术 |
| `marketing-copy --type case` vs `product-doc --type case` | 媒体投放 / 公众号发布版本 | 官网案例库 / 销售口袋资料 |
| `marketing-copy` vs `proposal-generator` | 标准化推广物料 | 一对一客户响应方案 |
