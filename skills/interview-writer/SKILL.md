# 访谈写作技能 v2.0

> Agent Team + 自进化架构 — Writer-Reviewer 互搏驱动知识库进化

## 核心定位

将访谈素材转化为有温度、有见识的公众号长文。不是整理访谈记录，而是提炼访谈精华，重新构建叙事。

**与 khazix-writer 的区别**：khazix-writer 适合观点类文章，interview-writer 专为访谈素材设计，保留受访者声音，重构叙事结构。

---

## 使用方式

```bash
# 直接对话触发
给我写一篇关于 [人物/主题] 的访谈文章，素材如下：[粘贴访谈记录]

# 命令行调用
/interview-writer [访谈素材或主题]

# 带参数调用
/interview-writer --style-card ./style-card.md --target-score 88 --max-rounds 3

# 仅输出初稿（跳过 Reviewer 互搏）
/interview-writer --mode draft
```

## 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--style-card` | 风格卡片路径，覆盖内置访谈风格 | 内置访谈风格 |
| `--target-score` | 目标质量分（四层加权） | 85 |
| `--max-rounds` | Writer-Reviewer 最大互搏轮次 | 3 |
| `--mode` | `full`=完整互搏流程，`draft`=仅输出初稿 | `full` |
| `--save-kb` | 是否将本次模式沉淀到知识库 | `true` |

## 执行流程

### Phase 1：素材解析

1. 提取访谈核心观点（3-5个）
2. 识别最有价值的细节、故事、金句
3. 确定文章核心主题和叙事角度
4. 设计文章框架（开头 / 主体 / 结尾）

输出：素材解析卡（内部使用，不展示给用户）

---

### Phase 2：Writer 初稿

按访谈写作规范创作初稿，Writer 完成后输出自评：

```
[初稿内容]

---
Writer 自评：
- 活人感：X/30 — [理由]
- 情感：X/25 — [理由]
- 信息：X/25 — [理由]
- 结构：X/20 — [理由]
- 综合：X/100
- 最弱层：[层次名] — [具体问题]
```

---

### Phase 3：Reviewer 评审

Reviewer 逐层评审，必须找出最弱层并给出可执行建议：

```
Reviewer 评审报告（第 N 轮）

| 层次 | 得分 | 主要问题 |
|------|------|---------|
| 活人感 | X/30 | [具体问题] |
| 情感   | X/25 | [具体问题] |
| 信息   | X/25 | [具体问题] |
| 结构   | X/20 | [具体问题] |
| 综合   | X/100 | |

最弱层：[层次名]
核心问题：[1-2句话]
修改建议：
1. [具体可执行的建议]
2. [具体可执行的建议]
3. [具体可执行的建议]

是否达标：[是/否] — 目标 [X]，当前 [X]
```

---

### Phase 4：Writer-Reviewer 互搏

```
Writer 初稿 → Reviewer 评审 → Writer 定向修改 → Reviewer 再评 → ...（最多 max-rounds 轮）
```

**互搏规则**：
- Reviewer 每轮必须找出最弱层，不能只说"好"
- Writer 每轮只针对最弱层修改，不做全文重写
- 达到目标分即停，避免过度修改
- 分歧时用具体段落/句子举例，不抽象评价

Writer 修改说明格式：
```
本轮修改说明：
- 针对层次：[最弱层]
- 修改内容：[具体改了什么]
- 预期提升：[X → X 分]
```

### Phase 5：知识库沉淀


## 访谈写作规范

### 四大核心原则

1. **受访者声音优先**：保留受访者真实表达，不过度润色，≥5 处直接引用
2. **细节证明真实**：用具体细节而非抽象描述，让读者"看见"受访者
3. **叙事重构**：不是流水账，而是有主题的故事，访谈是素材不是结构
4. **立场鲜明**：作者有观点，不做中立的记录员

### 禁用词（访谈写作版）

| 禁用表达 | 替换方向 |
|---------|---------|
| 他/她表示 | 直接引用原话，加引号 |
| 据悉 | 具体说明信息来源 |
| 不难看出 | 直接说出结论 |
| 值得注意的是 | 直接说重点 |
| 深度剖析 | 具体分析什么内容 |
| 娓娓道来 | 删掉，直接写内容 |
| 令人印象深刻 | 说出具体是什么打动了你 |
| 坦言 / 坦诚 | 直接引用原话 |

### 开头四种模式

1. **场景还原**：把读者带到访谈现场，用感官细节开场
2. **核心金句**：用受访者最有力的一句话直接开头
3. **问题悬念**：抛出访谈中最核心的问题，制造阅读动力
4. **反差冲突**：受访者身上最有张力的矛盾点，引发好奇

## 质量标准

| 指标 | 标准 |
|------|------|
| 字数 | 4000-8000 字 |
| 综合得分 | ≥85（四层加权） |
| 直接引用 | ≥5 处受访者原话 |
| AI 套话 | 0 |
| 迭代轮次 | ≤3 轮达标 |
