# 产品文档质量审核知识库

> 通用B2B产品文档质量管控标准 | 14项自查清单 | 24类文档完备性

---

## 14项自查清单

### 格式类（7项）

#### F1 ★★★ 【阻断】文件命名规范
**检查**：文件名是否符合格式 `[产品名]+[文档类别名]+版本号`

**合规示例**：
- `数据安全网关产品白皮书_V2.1`
- `智能运维平台【v1.0】产品销售指南_v1.0.docx`
- `零信任访问控制_产品操作手册_v3.0.docx`

**不合规示例**：
- `白皮书终稿.docx`（无产品名、无版本）
- `产品介绍20240301.docx`（用日期代替版本号）
- `产品资料(1).pptx`（无意义命名）
- `new-doc-v2-final-final.docx`（多余后缀）

**自动修复建议**：`[产品名]【[版本号]】[文档类别]_[版本号].[扩展名]`

---

#### F2 ★★★ 【阻断】文档变更页
**检查**：文档是否存在变更记录页，且包含以下字段：

| 必填字段 | 说明 |
|---------|------|
| 版本号 | 如 v1.0、v1.1 |
| 修订时间 | YYYY-MM-DD格式 |
| 编制者 | 真实姓名，非占位符 |
| 审核者 | 真实姓名 |
| 修订内容 | 具体描述改动内容 |

**检查位置**：通常在封面后第1-2页

---

#### F3 ★★ 封面标题
**检查**：文档封面（首页）是否同时包含：
- ✅ 产品全称（非简称或内部代号）
- ✅ 文档类别名（如"产品白皮书"、"产品操作手册"）

**不合格示例**：封面只写"产品文档"（无类别名）；只写产品名没有文档类型

---

#### F4 ★★ 目录一致性
**检查项**：
- [ ] 目录中的标题是否与正文标题一致（字词相同）
- [ ] 目录页码是否与正文页码对应
- [ ] 是否存在内容为空的章节（模板章节未填充）
- [ ] 是否存在直接复制模板文本未修改的情况

**识别模板残留内容**：
- 包含"XX"、"[产品名]"、"（完稿请删除）"、"TODO"等占位符
- 章节内容仅有"（待补充）"或空白

---

#### F5 ★ 法律声明
**检查**：是否存在法律声明页，且版权年份是否更新

**标准格式**（按企业实际填写）：
```
©[起始年]-[当前年份] [公司名称] 保留所有权利
本文件中出现的任何文字叙述、文档格式、插图、照片、方法、过程等内容，除另有特别注明，
版权均属[公司名称]所有，受到有关产权及版权法保护。如需转载，需注明出处。
```

---

#### F6 ★ 格式规范
**检查**（套用模板的文档）：
- [ ] 页眉内容正确（产品名/文档名）
- [ ] 页码格式一致
- [ ] 章节编号层级正确（1 / 1.1 / 1.1.1）
- [ ] 字体统一（符合企业字体规范）
- [ ] 图片/表格有编号和说明

---

#### F7 ★★★ 【阻断】封面配色规范
**检查**：封面标题文字与背景色对比是否清晰可读

**通用规范**：
- ✅ 标题文字颜色与背景色形成强对比（建议对比度 ≥ 4.5:1，符合 WCAG AA）
- ❌ 标题文字与背景色相近，导致可读性差

**检查方法**：目测封面标题是否易读；如有疑虑，用在线对比度工具验证

> **提示**：使用企业VI规范中指定的封面配色方案，不擅自修改底色与字色组合

---

### 内容类（4项）

#### C1 ★★★ 【阻断】产品/公司名称准确性
**检查**：文字和图片中是否存在**已变更/废弃的名称**

**操作方式**：
1. 整理公司/产品历史名称对照表（废弃名 → 现行名）
2. 全文搜索（Ctrl+H）所有废弃名称并替换
3. 检查范围：正文文字 + 图片截图文字 + 表格 + 页眉页脚

**常见场景**：公司更名、产品线重组、品牌升级后遗留的旧名称

---

#### C2 ★★★ 【阻断】内容完整性
**检查**：
- [ ] 是否有重要章节缺失（对照该文档类型的标准结构）
- [ ] 是否有章节内容重复（同一段落出现2次）
- [ ] 是否有章节内容过于简单（单章节少于100字且无图表）
- [ ] 是否有大量复制粘贴痕迹（前后文字风格差异明显）

---

#### C3 ★★★ 【阻断】内容时效性
**检查**：
- [ ] 产品功能描述是否与当前版本一致
- [ ] 文档中的版本号与实际产品版本是否匹配
- [ ] 数据/统计数字是否过期（超过2年的行业数据需更新）
- [ ] 截图是否为当前版本UI

---

#### C4 ★★ 密级标注
**检查**：
- 保密文档是否在封面或页眉明确标注"**内部资料**"或"**禁止外传**"
- 常见保密文档类型：竞品分析 / 技术白皮书 / 招投标参数 / 内部定价表

---

### 上传类（3项）

#### U1 ★★★ 保密文档归档
**检查**：保密文档是否已归档至内部知识库/权限系统（非公开存储位置）

#### U3 ★ 产品介绍页面质量
**检查**：
- [ ] 产品介绍页不少于3张展示图片
- [ ] 图片说明文字完整，不能只有图片无文字
- [ ] 描述文字超过200字，有产品定位和核心功能说明

## 审核输出报告格式

```markdown
# 文档审核报告：[文档名]
**审核日期**：YYYY-MM-DD
**文档类型**：[类型]
**文档版本**：[版本号]

## 审核结果概览
- ❌ 阻断项：X 项（必须修改）
- ⚠️ 建议项：X 项（建议修改）
- ✅ 通过项：X 项

## 阻断项明细（必须修改）
| # | 检查项 | 问题描述 | 修改建议 |
|---|--------|---------|---------|
| 1 | F1命名规范 | 文件名"白皮书终稿.docx"无产品名和版本号 | 重命名为"[产品名]产品白皮书_v1.0.docx" |

## 建议项明细
| # | 检查项 | 问题描述 | 修改建议 |
|---|--------|---------|---------|

## 通过项
F2 ✅, F5 ✅, C1 ✅ ...

## 总结建议
[2-3句话总结主要问题和优先修改顺序]
```

## 快速修复指南

| 问题 | 快速修复 |
|------|---------|
| 文件名不规范 | 按`[产品名]【版本号】[文档类别]_版本号.扩展名`重命名 |
| 无变更记录页 | 在目录前插入标准变更记录表，补填历史版本 |
| 版权年份过期 | 全文替换旧年份为当前年份 |
| 含废弃名称 | Ctrl+H全文替换所有已变更的产品名/公司名 |
| 封面配色不合规 | 按企业VI规范调整封面标题文字颜色，确保对比度达标 |
| 模板占位符残留 | 全文搜索"XX"、"[产品名]"、"TODO"、"待补充"并处理 |
| 法律声明年份未更新 | 替换为当前年份 |
| 无密级标注 | 保密文档封面/页眉添加"内部资料"或"禁止外传"水印/标注 |
