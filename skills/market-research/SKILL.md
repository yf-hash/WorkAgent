# Market Research — 市场研究与竞争情报知识库

## 竞品分析框架

### 竞品收集维度
```markdown
1. 直接竞品：解决相同问题、面向相同用户
2. 间接竞品：解决相同问题、方式不同（如 Excel vs. 专业工具）
3. 潜在进入者：大平台延伸、新技术颠覆者
4. 替代方案：用户不用你的产品时会用什么？
```

## 市场规模估算（TAM/SAM/SOM）

```markdown
## 自上而下（行业报告法）
TAM = 全球市场规模（行业报告引用）
SAM = TAM × 可服务地区比例 × 相关细分占比
SOM = SAM × 可实现市场份额（3-5年目标）

## 自下而上（单位经济法）
TAM = 潜在客户数 × 每客户年均支出
SOM = 可触达客户数 × 转化率 × ARPU

示例（AI 写作工具）：
- 全球内容创作者：5000万
- 可付费比例：10% = 500万
- ARPU：$120/年
- TAM = $6亿
- SAM（英语市场60%）= $3.6亿
- SOM（Year 3，0.5%市场份额）= $180万
```

## 行业趋势分析框架

```markdown
## STEEP 宏观趋势扫描
- Social（社会）：人口结构、工作方式、消费习惯变化
- Technological（技术）：新技术浪潮、平台迁移、API 经济
- Economic（经济）：融资环境、企业 IT 预算、降本趋势
- Environmental（环境）：合规要求、ESG 压力
- Political（政治）：数据监管（GDPR/PIPL）、地缘风险

## 技术 S 曲线定位
当前技术处于哪个阶段？
└─ 萌芽期 → 上升期 → 成熟期 → 衰退期
   判断信号：搜索量增长、融资活跃度、大厂入场
```

## 亚马逊选品研究框架

```markdown
## 选品评估指标
| 指标 | 达标标准 | 查询方式 |
|------|---------|---------|
| 月均销量 | > 300单 | JS/Helium10 |
| 评论数 | Top 3 均值 < 500 | 直接查看 |
| 评分 | > 4.0 | 直接查看 |
| 售价 | $15-$50 | 直接查看 |
| 重量 | < 2 lbs | 详情页 |
| 竞争度 | 中等（JSS 40-70） | Jungle Scout |
| 季节性 | 全年平稳 | Google Trends |

## 选品排除标准（红线）
- 有大品牌（Nike/Apple/3M等）垄断 TOP3
- 产品高度同质化（差异化空间极小）
- 物流复杂（危险品/易碎/超大件）
- 严格合规要求（食品/药品/电子认证）
```

## 开源生态分析框架（OSS 模式）

```markdown
## 健康度指标
| 指标 | 健康信号 | 风险信号 |
|------|---------|---------|
| Star 增速 | 月增 > 500 | 增速放缓 > 6月 |
| Issue 响应 | 平均 < 48h | > 1周无回应 |
| PR 合并率 | > 30% | < 10% |
| 贡献者数 | 核心 > 5 人 | 单人维护 |
| 版本发布 | 月均 1+ 版本 | 3个月无发布 |

## 商业化信号
- Cloud/Enterprise 版本是否存在？
- 有无付费支持/培训？
- 有无知名企业客户背书？
- 有无 VC 融资？
- License 是否限制商用（AGPL/BSL）？
```

## RAG 增强市场研究工作流

```markdown
Step 1: 数据源构建
  → 竞品官网、产品文档、博客文章
  → 用户评论（G2/Capterra）
  → 行业报告摘要
  → Twitter/Reddit 用户讨论

Step 2: 向量化存储
  → 文本分块（512 tokens）
  → 嵌入向量化
  → 结构化元数据（来源/日期/竞品名）

Step 3: 分析查询
  → "竞品A的核心差异化是什么？"
  → "用户最常投诉竞品B的哪些点？"
  → "市场上还没有解决的需求是什么？"

Step 4: 报告生成
  → 综合多源信息
  → 交叉验证关键观点
  → 生成可引用的报告
```

## 市场进入策略

```markdown
## 蓝海策略框架（四步行动框架）
- 消除：哪些行业认为理所当然但实际无价值的因素？
- 减少：哪些因素可以大幅低于行业标准？
- 增加：哪些因素可以大幅高于行业标准？
- 创造：哪些行业从未提供过的因素可以创造？

## 差异化定位
找到竞争者"未服务好"的细分市场：
1. 规模细分：SMB vs. Enterprise vs. 个人
2. 行业细分：垂直 vs. 水平
3. 功能细分：单点精深 vs. 全面覆盖
4. 价格细分：免费/低价/高价值
5. 渠道细分：自助 vs. 销售驱动
```
