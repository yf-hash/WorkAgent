# PM Skills — 产品经理技能知识库

## 核心职能框架

### 发现 (Discovery)
| 框架 | 核心问题 | 输出 |
|------|---------|------|
| JTBD | 用户雇佣产品完成什么任务？ | 工作陈述 (Job Statement) |
| 5 Whys | 问题的根本原因是什么？ | 根因树 |
| Opportunity Solution Tree | 从目标到解法的探索路径是什么？ | OST 图 |
| Problem / Solution Fit | 问题足够大且可解决吗？ | 假设验证矩阵 |

### 定义 (Definition)
| 框架 | 公式/说明 | 适用场景 |
|------|---------|---------|
| RICE | (Reach × Impact × Confidence) ÷ Effort | 多需求横向比较 |
| MoSCoW | Must/Should/Could/Won't | MVP 范围界定 |
| ICE | Impact × Confidence × Ease | 快速优先级 |
| Kano | 必备/期望/惊喜/反向/无差异 | 功能价值分类 |

### 执行 (Delivery)
```markdown
## PRD 评审检查清单
- [ ] 问题陈述清晰，有数据支撑
- [ ] 用户故事完整（As a... I want... So that...）
- [ ] 验收标准可测试（Given/When/Then）
- [ ] 非功能需求已定义（性能/安全/兼容性）
- [ ] 指标已对齐（北极星 + 护栏指标）
- [ ] 风险已评估，有缓解方案
- [ ] 依赖已识别，负责人已确认
```

### 增长 (Growth)
```markdown
## AARRR 指标框架
- Acquisition（获客）：CAC、流量渠道、转化率
- Activation（激活）：Aha Moment 到达率、新用户 D1 完成度
- Retention（留存）：D7/D30/D90 留存率、Churn Rate
- Revenue（变现）：ARPU、LTV、付费转化率
- Referral（推荐）：NPS、K-factor、分享率
```

## 北极星指标设计原则

```markdown
好的北极星指标必须满足：
1. 反映用户获得的核心价值（不是收入）
2. 可量化、可分解、可追踪
3. 与商业目标强相关
4. 团队能影响它

示例：
- Slack: DAU 发送的消息数
- Airbnb: 被预订的夜晚数
- Spotify: 每月收听分钟数
- Notion: 每周协作的团队数
```

## PMF 评估方法

```markdown
Sean Ellis 问卷法：
Q: 如果我们不再提供这个产品，您会有多失望？
- 非常失望 > 40% → 达到 PMF
- 20-40% → 接近 PMF，需迭代
- < 20% → 未达到 PMF

其他信号：
- 用户自发推荐（有机增长 > 付费增长）
- 留存曲线趋于平缓（不持续下降）
- 用户因失去产品感到痛苦
```

## AI 时代 PM 技能演变

```markdown
新增核心能力：
1. Prompt Engineering — 设计 AI 功能的用户交互
2. LLM 产品设计 — 幻觉处理、延迟预期管理、fallback 设计
3. AI 指标体系 — 准确率/有用率/接受率/完成率
4. 数据飞轮设计 — 用户使用数据如何改善模型
5. AI 伦理边界 — 偏见/隐私/可解释性

不变的核心：
- 用户同理心
- 数据驱动决策
- 跨部门影响力
- 清晰的书面表达
```

## 产品发布检查清单

```markdown
## 发布前 (T-1 周)
- [ ] PRD 最终版已确认
- [ ] 技术方案评审完成
- [ ] QA 测试通过（功能 + 回归）
- [ ] 埋点验证 (QA 环境)
- [ ] 文案/UI 走查
- [ ] 客服 FAQ 更新
- [ ] AB 实验配置 (如有)

## 发布当天
- [ ] Feature Flag 逐步放量 (10% → 50% → 100%)
- [ ] 监控看板关注（错误率/性能/关键指标）
- [ ] 客服频道待命

## 发布后 (T+1 周)
- [ ] 数据看板回顾
- [ ] 用户反馈汇总
- [ ] 是否达到预期指标？
- [ ] 下一迭代规划
```

## 向上管理技巧

```markdown
汇报原则：
1. 结论先行（Bottom-line up front, BLUF）
2. 数据支撑（用指标说话，不用感受）
3. 推荐方案（给选项而非问题）
4. 风险透明（提前暴露，带缓解方案）

周报模板：
- 本周完成：[具体成果 + 数据]
- 下周计划：[可量化目标]
- 卡点/风险：[问题 + 求助/已缓解]
```

## 用户故事地图模板

```markdown
# Story Map: [产品/功能名]

## 用户活动 (Activities)
[登录] → [创建内容] → [分享内容] → [查看反馈]

## 用户任务 (Tasks)
登录:
  - 输入账号密码
  - OAuth 第三方登录
  - 忘记密码找回

创建内容:
  - 新建文档
  - 选择模板
  - 编辑与保存

## 用户故事 (Stories) — 按 MVP/V2/V3 分层
MVP:  基础登录、新建空白文档、手动保存
V2:   记住登录、模板库、自动保存
V3:   SSO 集成、AI 辅助写作、版本历史
```
