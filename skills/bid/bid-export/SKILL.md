# Bid Export — 标书 Phase 7 定稿移交

> 单一职责：标书七阶段第 7 阶段（最终定稿 + 移交）。
> 上游：`bid-check` 通过的版本。

## 最终通读检查清单

| 检查项 | 说明 |
|--------|------|
| ★实质性条款 | 所有废标项是否全部响应 |
| 偏离表一致性 | 技术偏离表与方案内容是否完全一致 |
| 商务一致性 | 报价与商务标书是否一致 |
| 签章完整性 | 有无遗漏盖章/签字处 |
| 格式规范 | 字体、页眉页脚、图表编号统一 |

## 文档生成规范

### 命名

```
[项目名称]-技术标书-V1.0-[YYYYMMDD].docx
[项目名称]-技术标书-V1.0-[YYYYMMDD].pdf
[项目名称]-技术偏离表-V1.0-[YYYYMMDD].docx
[项目名称]-商务标书-V1.0-[YYYYMMDD].docx
```

### 正本/副本批量生成

- 正本：原件，加盖鲜章
- 副本：复印件，加盖"副本"章
- 数量按招标方要求（通常 1 正 + 3-5 副）

### 移交包内容

```
[项目名]-投标包/
├── 01-技术标书/
│   ├── 技术标书（最终版）.pdf
│   ├── 技术标书（最终版）.docx
│   └── 技术偏离表（最终版）.docx
├── 02-商务标书/
│   ├── 商务标书（最终版）.docx
│   ├── 报价单.xlsx
│   └── 投标函.docx
├── 03-资质证明/
│   ├── 营业执照.pdf
│   ├── 资质证书集.pdf
│   └── 业绩证明材料.pdf
├── 04-保证金凭证/
│   └── 保证金支付凭证.pdf
└── README.md（移交清单）
```

## 输出物

- `[项目名]-技术标-正本.docx/pdf`
- `[项目名]-投标包.zip`
- `移交清单.md`
