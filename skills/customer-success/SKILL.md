# Customer Success — B 端客户成功知识库

把"卖出去"变成"用得好 + 留得住 + 卖得多"。B 端 PM 的核心战场。

---

# 一、B 端客户成功的"四层价值"

```
Level 1：实施成功（First Value）
  → 客户用上产品并感受到第一次价值

Level 2：业务嵌入（Adoption）
  → 客户日常工作流离不开产品

Level 3：价值证明（Value Realization）
  → 客户能用数字证明 ROI

Level 4：扩展增长（Expansion）
  → 续约 + 扩展销售 + 标杆案例
```

每层都是客户跃迁的关键节点，CSM 的工作就是推动跃迁。

# 二、Onboarding 30/60/90 天

## 2.1 30 天：First Value

```
W1: Kick-off
  - 项目启动会（双方核心 + 周会节奏）
  - 项目章程（成功标准 + RACI + 升级路径）
  - 关键人地图

W2: 基础就绪
  - 账号 / SSO / SCIM 配置
  - 数据迁移演练
  - 安全合规审查

W3: 用户培训
  - 核心用户培训（首批 5-10 人）
  - 真实用例上线
  - 1on1 答疑

W4: First Value 验证
  - 量化首批用例效果
  - Champion 内部宣讲
  - 30 天复盘 + 60 天计划
```

## 2.2 60 天：业务嵌入

```
W5-W8:
  - 全员接入
  - SOP 文档化
  - 数据看板上线
  - 月度健康度复盘启动
```

## 2.3 90 天：价值证明

```
W9-W13:
  - 业务影响量化报告（vs baseline）
  - 客户成功故事采访
  - 季度 QBR
  - 扩展机会评估
```

# 三、客户健康度评分模型

## 3.1 五维度评分

```
| 维度 | 权重 | 数据源 | 含义 |
|------|------|--------|------|
| 使用深度 | 35% | 产品埋点 | 是否真的用 + 用得深 |
| 关键事件 | 20% | CRM | 培训 / SOP / Champion 等 |
| NPS / 满意度 | 15% | 调研 | 主观感受 |
| 业务影响 | 15% | 客户提供 | 是否有量化 ROI |
| 续约信号 | 15% | 销售信息 | 高管支持度 |
```

## 3.2 红黄绿分级

```
🟢 绿（80-100）→ 扩展销售机会
🟡 黄（60-79） → 常规运营
🔴 红（< 60）  → 立即介入 + 升级
```

## 3.3 自动告警规则

```
Critical:
  - 健康度连续 30 天 < 60
  - Champion 离职
  - 高管不接电话 / 邮件 30 天

Warning:
  - 使用深度月环比 -20%
  - NPS 单月下降 > 10
  - 关键功能 30 天未使用
```

# 四、续约预测与 Playbook

## 4.1 续约时间盒

```
T-90 天：健康度复盘 + 续约预测
T-60 天：业务影响报告 + 续约方案
T-30 天：报价正式提交 + 谈判
T-7 天： 合同签署
T-Day： 续约 Kick-off
```

## 4.2 续约方案

```
| 方案 | 何时用 |
|------|------|
| Renew Same | 健康度黄 + 客户预算紧 |
| Renew + Upsell ⭐ | 健康度绿 + 业务扩展机会 |
| Multi-Year | 战略客户 + 锁定竞争 |
| Down-sell | 高风险流失但可救（保留小合同）|
| Decline | 不健康 + 不值得救（少见）|
```

## 4.3 续约谈判要点

```
✅ 提前 90 天启动（不留临时空间）
✅ 业务价值数字先于价格
✅ 多方案而非单一方案（避免 Yes/No）
✅ Champion 提前介入（内部说服）
✅ Multi-Year 折扣（锁定 + 降低管理成本）
```

# 五、Land & Expand 扩展框架

## 5.1 Land（落地）

```
策略：
  - 选最痛的部门 / 用例切入
  - 范围小但价值清晰
  - 6 个月内必出 ROI 报告
```

## 5.2 Expand（扩展）

```
四个维度：
  - More Users（同部门多人）
  - More Use Cases（同部门多场景）
  - More Departments（其他部门）
  - More Products（产品组合包）
```

## 5.3 扩展时机

```
✅ 健康度 ≥ 80
✅ ROI 已量化
✅ Champion 主动推荐
✅ 已有内部 SOP 沉淀

❌ 健康度黄 / 红（先稳住再扩）
❌ 第一次实施 < 6 个月（基础不牢）
```

## 5.4 扩展销售脚本

```
对 IT 决策者：
  "X 部门 ROI 已 5:1，Y 部门有 60% 流程重叠，建议本月调研"

对财务：
  "扩展 ¥X 万年合同 → 业务价值 ¥Y 万 / 年 → ROI Z:1"

对 Champion：
  "你成为公司 [产品] 标杆案例，下季度推荐你向高管汇报"
```

# 六、流失预警与挽留

## 6.1 流失信号

```
强信号（90% 流失风险）：
  - Champion 离职
  - 高管 60 天不响应
  - 主用户群 30 天未登录

中信号：
  - 健康度连续 30 天 < 60
  - NPS 单月下降 > 15
  - 工单激增（投诉类）
  - 价格谈判异常激进
```

## 6.2 挽留 SOP（Win-back）

```
Step 1: 24h 内升级到 VP CS
Step 2: 48h 内召开内部诊断会
Step 3: 72h 内拜访 Champion + Sponsor
Step 4: 1 周内出挽留方案（产品 + 价格 + 服务）
Step 5: 2 周内决策（救 / 放）
```

## 6.3 不可挽留时

```
- 体面退出（不撕破脸）
- 数据导出协助（合规）
- 客户合规审计配合
- 留意"再回来"机会（6-12 个月后）
```

# 七、客户分层运营

## 7.1 三层标准

```
| Tier | 标准 | 服务力度 | CSM 比例 |
|------|------|---------|---------|
| 1 战略 | ARR Top 5% / 标杆 | 专属 CSM | 1:5 |
| 2 重点 | ARR Top 25% | 共享 CSM | 1:20 |
| 3 长尾 | 其余 | Pooled / 自助 | 1:200 |
```

## 7.2 服务差异化

| 服务项 | Tier 1 | Tier 2 | Tier 3 |
|--------|--------|--------|--------|
| QBR | 月度高管 + 季度战略 | 季度 | 邮件季报 |
| 1on1 | 周 | 双周 | 按需 |
| 培训 | 现场专属 | 在线专属 | 公开课 |
| 升级路径 | 直达 VP | CSM 主管 | 工单 |
| SLA | 自定义 | 标准 | 标准 |
| 价格弹性 | 高 | 中 | 低 |

# 八、QBR / EBR 框架

## 8.1 QBR（季度业务回顾）

```
出席：客户 Champion + 我方 CSM + AE
时长：90 分钟
议程：
  1. 上季回顾（数据 + 故事）
  2. 业务影响量化
  3. 路线图同步
  4. 下季计划
  5. 问题 / 风险
```

## 8.2 EBR（高管业务回顾）

```
出席：客户 Sponsor + 我方 VP CS + Sales Director
时长：60 分钟
议程：
  1. 战略对齐
  2. 年度 ROI
  3. 扩展讨论
  4. 关键风险
```

# 九、Customer Advisory Board (CAB)

```
组成：6-12 个 Tier 1/2 客户的 Champion / Sponsor
节奏：半年 1 次
价值：
  - 产品方向输入（先于市场）
  - 客户互相背书（社群效应）
  - 高质量反馈通道
  - 标杆案例积累
```
