# B2B产品销售赋能知识库

> 销售一页禅写作规范 | 场景化销售剧本 | 行业化定制指南

---

## 核心理念

销售指南（销售一页禅）的本质是：**让每位销售在任何场景下都能讲出有说服力的故事，而不是背功能列表**。

写作核心原则：
1. **场景驱动**：从客户的真实业务场景出发，而非产品功能
2. **故事为王**：用真实案例或原型故事触发共鸣
3. **需求反推**：从客户故事中提炼出3-5个深层需求
4. **价值闭环**：每个场景必须有"卖了这个，还能带动什么"

## 销售一页禅完整模板

### 第1章：概述

```markdown
## 1. 概述

### 1.1 [产品名]简介
[产品定位一句话：以XX视角，利用XX技术，解决XX问题，帮助客户实现XX目标]

[背景段落：2-3句话说明产品诞生的背景和市场需求]

[核心能力段落：3个优势点]

### 1.2 优势亮点
| 优势点 | 优势说明 |
|--------|----------|
| [优势1：如"业界唯一具备XX能力"] | [具体说明，附数据支撑] |
| [优势2] | [具体说明] |
| [优势3] | [具体说明] |

### 1.3 产品说明
| 事项 | 说明 |
|------|------|
| 产品形态 | [软件/硬件/SaaS/混合] |
| 产品构成 | [主要模块列表] |
| 项目金额范围 | [XX万~XX万（参考值）] |
| 毛利 | [XX%（内部参考）] |

### 1.4 行业目标客户介绍
- **[客户角色1]**（如：信息安全部/数据中心）：负责XX，核心诉求是XX，预算来源XX
- **[客户角色2]**：负责XX，核心诉求是XX
```

### 第2章：销售场景（核心）

每个场景严格按5要素结构展开：

```markdown
## 2. 销售场景

### 场景一：[场景名称]（如：合规驱动型建设）

**目标客户**：[具体职位/部门，如：信息安全部/合规管理部]

**行业客户的故事**：
[3-5句话描述一个典型客户的真实处境：
- 客户背景（规模/行业地位）
- 遇到了什么事（监管要求/安全事件/内部压力）
- 做了什么尝试（采购了哪些产品/做了哪些改变）
- 还存在什么问题（当前最大的困惑或痛点）]

示例格式："某头部银行，完成等保三级整改后，发现已采购的安全设备实际防御效果难以量化。
每年数千万安全投入，监管检查时无法拿出客观数据证明安全建设的实际价值。"

**案例背后的需求**（提炼3-5个）：
1. [需求1：如"安全投入效果可量化，花了钱要能证明"]
2. [需求2：如"架构变更后及时发现防御失效点"]
3. [需求3：如"运营能力持续提升，而非一次性建设"]
4. [需求4：如"输出合规证明材料，应对监管检查"]

**我们的解决思路**：
- [思路1：产品功能如何解决需求1]
- [思路2：产品功能如何解决需求2]
- [配套方案：如周期性评估+整改+提升的闭环服务]

**其他销售机会**：
1. [连带机会1：如"发现短板后，精准推送对应补强产品"]
2. [连带机会2：如"成为监管方对下属机构周期性检查的工具"]
```

### 第3章：竞争对比

```markdown
## 3. 竞争对比

### 竞品对比矩阵
| 对比项 | [我方产品] | [竞品A] | [竞品B] | [竞品C] |
|--------|-----------|---------|---------|---------|
| [功能1] | ✅ A级优势 | ⚠️ 部分支持 | ❌ 不支持 | ⚠️ |
| [功能2] | ✅ B级优势 | ✅ | ✅ | ❌ |
| [功能3] | ✅ C级 | ✅ | ✅ | ✅ |
| [功能4] | ❌ D级 | ✅ | ✅ | ✅ |

### 我方核心优势（A/B级）
| 优势等级 | 具体优势点 | 证明材料 |
|---------|---------|---------|
| A级（唯一性）| [只有我方具备的能力] | [专利/报告/截图] |
| B级（核心）| [≤3家有的能力] | [评测报告/案例] |

### D级劣势应对话术
| 友商优势点 | 我方现状 | 话术建议 |
|---------|---------|---------|
| [友商有我没有的点] | 暂无此功能 | [转移焦点：强调A级优势/强调ROI/强调服务] |
```

## 销售常见问题（FAQ）写作规范

### 问题分类框架

| 类别 | 问题方向 | 数量建议 |
|------|---------|---------|
| 技术原理 | 核心技术是什么/与传统方案有何不同 | 3-5题 |
| 竞品对比 | 与XX相比有什么优势/如何应对XX | 3-5题 |
| 部署运维 | 环境要求/虚拟化支持/平台兼容性/HA方案 | 3-5题 |
| 授权定价 | 授权方式/报价范围/续费机制 | 2-3题 |
| 服务支持 | 交付周期/SLA承诺/培训体系/驻场要求 | 2-3题 |

### FAQ单题标准格式

```markdown
### Q：[问题标题]（简洁、是客户真实会问的）

**A：**

[第一段：直接回答问题（2-3句话，给明确答案）]

[第二段（可选）：展开说明，补充背景或原理（3-5句话）]

[第三段（可选）：差异化强调，突出我方优势（1-2句话）]

> **话术建议**：[给销售的话语提示，如何在客户问出这个问题时应对]
```

### 高频问题参考库

```
技术类：
Q1: 产品使用了哪些核心技术？
Q2: 如何确保检测/分析结果的准确性？
Q3: 能否与已有平台（SIEM/SOC/ITSM等）集成？

竞品类：
Q4: 与[主要竞品]相比，产品有什么优势？
Q5: 为什么不选择开源方案？

部署类：
Q6: 最低环境要求是什么？
Q7: 支持主流操作系统/数据库吗？（列举客户常用的平台）
Q8: 支持虚拟化/容器化部署吗？
Q9: 支持离线/内网环境部署吗？

授权类：
Q10: 授权方式是按用户数还是按功能模块？
Q11: 报价范围大概在哪个区间？

服务类：
Q12: 实施周期大约需要多长时间？
Q13: 提供哪些技术支持和售后服务？
```

## 行业化定制指南

### 金融行业（fintech）关键词库

| 场景 | 客户诉求 | 产品切入点 |
|------|---------|---------|
| 等保合规 | 合规整改/审计应对 | 提供等保评测证明材料 |
| 风险管理 | 异常行为检测/风控 | 实时告警+数据留存 |
| 渗透测试/红蓝对抗 | 量化防御能力 | POC快速验证，输出报告 |
| 监管检查 | 数据留存/审计日志 | 符合监管机构要求 |

### 政务行业（gov）关键词库

| 场景 | 客户诉求 | 产品切入点 |
|------|---------|---------|
| 关基保护 | 关基条例合规 | 关基防护解决方案 |
| 数据安全合规 | 数据分类分级/出境管控 | 数据安全治理平台 |
| 政务网络安全 | 等保/网络安全法 | 政务专有/私有化部署版 |
| 重大活动保障 | 零事故/快速响应 | 7×24应急响应服务 |

### 制造业（mfg）关键词库

| 场景 | 客户诉求 | 产品切入点 |
|------|---------|---------|
| OT/IT融合安全 | 工控系统防护 | 工控网络安全解决方案 |
| 供应链安全 | 供应商访问管控 | 零信任/特权账号管理 |
| 生产连续性 | 勒索防护/快速恢复 | 端点防护+备份恢复 |

### SaaS/互联网（saas）关键词库

| 场景 | 客户诉求 | 产品切入点 |
|------|---------|---------|
| 多租户安全 | 租户数据隔离 | 访问控制/权限管理 |
| API安全 | 接口滥用/注入攻击 | API安全网关 |
| 合规认证 | ISO 27001/SOC 2 | 安全评估+整改支持 |
