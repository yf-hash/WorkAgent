# Style Writer-Reviewer — 双 Agent 迭代创作

> 单一职责：基于风格卡片 + 素材，Writer-Reviewer 互搏创作直到达标。
> 不做：提炼风格卡片（→ `style-card-extractor`）、技术调查（→ `@research-analyst`）、AI 去痕（→ `humanizer-scan` / `humanizer-soul`）

## 前置输入

- 风格卡片（来自 `style-card-extractor` 或 `--style-card` 加载）
- 可选：技术调查素材（来自 `@research-analyst` 横纵调查）
- 标题 + 框架（可选）

## 三种创作模式

| 模式 | 侧重 | Reviewer 重点诊断 |
|------|------|------------------|
| `quality` | 内容深度、案例数据、逻辑结构 | 内容质量子维度为 P1 优先 |
| `humanize` | 去 AI 味、活人感、灵魂注入 | 风格合规子维度为 P1 优先 |
| `balance` | 两维度均衡推进 | 两维度中最低子维度优先 |

## Writer Agent 规范

```
第 1 轮：严格对照风格卡片的开篇/结构/节奏/语言原则生成初稿
第 N 轮：读取上轮诊断报告，优先修复 P1 高优先级问题，只做定向修改，不盲目重写
每轮输出修改说明：针对层次 / 修改内容 / 预期提升
```

## Reviewer Agent 规范

```
双维度评分 + 精准诊断（必须找到最弱子维度）
检查终止条件，明确给出是否继续迭代的建议
诊断问题必须对应具体段落/句子，不抽象评价
```

## 双维度评分体系

### 维度一：内容质量（50 分）

| 子维度 | 评估标准 | 分值 |
|--------|----------|------|
| 深度与完整性 | 论点充分展开，有背景、分析、结论 | /15 |
| 案例与数据 | 有具体案例支撑，数据真实可信 | /15 |
| 逻辑连贯性 | 段落间逻辑清晰，过渡自然 | /10 |
| 结构完整性 | 有引言、主体、结尾，层次分明 | /10 |

### 维度二：风格合规（50 分）

| 子维度 | 评估标准 | 分值 |
|--------|----------|------|
| 自然度 | 无 AI 高频词，无 24 种 AI 模式残留 | /15 |
| 真实感 | 有个人观点，有真实转折 | /15 |
| 节奏变化 | 句子长短交替，段落有变化 | /10 |
| 风格一致性 | 全文语气统一，符合风格卡片要求 | /10 |

## 诊断报告格式

```markdown
## 第 N 轮诊断报告

### 评分

| 维度 | 子维度 | 本轮 | 上轮 | 变化 |
|------|--------|------|------|------|
| 内容质量 | 深度与完整性 | X/15 | X/15 | +X |
| ... | ... | | | |
| **总分** | | **XX/100** | **XX/100** | **+X** |

### 问题诊断

**P1（必须修复）：**
1. [具体问题，如："此外"出现 5 次] — 影响 -X 分
   - 位置：[段落/章节]
   - 建议：[具体改写方向，使用 proven_solutions 策略 ID]

**P2（建议修复）：**

**P3（可选优化）：**

### 终止判断

- 当前 XX/100 | 目标 XX/100 | 距目标 XX 分
- 本轮提升 +X | 连续趋势：[上升/停滞/递减]
- **建议**：[继续迭代 / 已达标 / 边际收益递减建议停止]
```

## 终止条件（满足任一即停）

- 评分达到目标分数（默认 85）
- 已达最大轮次（默认 3）
- 连续 2 次提升 < 3 分

## proven_solutions 策略库

### 内容质量策略

| ID | 策略 | 适用场景 | 预期提升 |
|----|------|----------|---------|
| CQ-01 | 案例具象化 | 论点缺乏支撑 | 案例分 +3-5 |
| CQ-02 | 数据精确化 | 描述模糊 | 深度分 +2-4 |
| CQ-03 | 认知进化轨迹 | 缺乏历史背景 | 深度分 +3-5 |
| CQ-04 | 反事实推理 | 论证不够有力 | 深度分 +4-6 |
| CQ-05 | 例外情况讨论 | 结论过于绝对 | 完整性 +2-3 |
| CQ-06 | 段落化展开 | 要点式表达 | 结构分 +3-5 |

### 风格合规策略

| ID | 策略 | 适用场景 | 预期提升 |
|----|------|----------|---------|
| SC-01 | 删除 AI 高频词 | 此外/至关重要/格局等高频词过多 | 自然度 +3-5 |
| SC-02 | 打破公式结构 | 排比句/三项列举过多 | 自然度 +2-4 |
| SC-03 | 节奏变化注入 | 句子长度一致 | 节奏分 +3-4 |
| SC-04 | 个人观点植入 | 缺乏真实感，只报告不反应 | 真实感 +3-5 |
| SC-05 | 主动语态转换 | 被动语态过多 | 自然度 +2-3 |
| SC-06 | 真实转折设计 | 逻辑过于完美 | 真实感 +2-4 |
| SC-07 | 删除意义膨胀 | 大量"标志着/见证了/体现了" | 自然度 +2-3 |
| SC-08 | 具体化归因 | "专家认为"等无来源表述 | 信任度 +3-4 |
| SC-09 | 删除宣传语言 | 旅游手册式形容词 | 自然度 +2-3 |
| SC-10 | 去除聊天套语 | "希望对您有帮助"等残留 | 自然度 +2-3 |
| SC-11 | 精简填充短语 | "为了实现这一目标"等 | 精炼度 +2-4 |
| SC-12 | 去除破折号滥用 | 每句多个破折号 | 自然度 +1-2 |
| SC-13 | 具体化结尾 | "未来光明/激动人心"等泛化收尾 | 真实感 +2-3 |

## 后续衔接

- 若启用 `humanize` 模式，本 Skill 已内置基础去痕，但学术深度强化需调用 `humanizer-academic`
