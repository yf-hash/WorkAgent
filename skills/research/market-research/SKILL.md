## 竞品分析框架

### 竞品收集维度
```markdown
1. 直接竞品：解决相同问题、面向相同用户
```

## 市场规模估算（TAM/SAM/SOM）

```markdown
## 自上而下（行业报告法）
TAM = 全球市场规模（行业报告引用）
SAM = TAM × 可服务地区比例 × 相关细分占比
SOM = SAM × 可实现市场份额（3-5年目标）

## 自下而上（单位经济法）
TAM = 潜在客户数 × 每客户年均支出
SOM = 可触达客户数 × 转化率 × ARPU

示例（AI 写作工具）：
- 全球内容创作者：5000万
- 可付费比例：10% = 500万
- ARPU：$120/年
- TAM = $6亿
- SAM（英语市场60%）= $3.6亿
- SOM（Year 3，0.5%市场份额）= $180万
```

## 行业趋势分析框架

```markdown
## STEEP 宏观趋势扫描
- Social（社会）：人口结构、工作方式、消费习惯变化

```

## 亚马逊选品研究框架

```markdown
## 选品评估指标
| 指标 | 达标标准 | 查询方式 |
|------|---------|---------|
| 月均销量 | > 300单 | JS/Helium10 |
| 评论数 | Top 3 均值 < 500 | 直接查看 |
| 评分 | > 4.0 | 直接查看 |
| 售价 | $15-$50 | 直接查看 |

| 竞争度 | 中等（JSS 40-70） | Jungle Scout |
| 季节性 | 全年平稳 | Google Trends |

## 选品排除标准（红线）
- 有大品牌（Nike/Apple/3M等）垄断 TOP3
- 产品高度同质化（差异化空间极小）
- 物流复杂（危险品/易碎/超大件）
- 严格合规要求（食品/药品/电子认证）
```

## RAG 增强市场研究工作流

```markdown
Step 1: 数据源构建
  → 竞品官网、产品文档、博客文章
  → 用户评论（G2/Capterra）
  → 行业报告摘要
  → Twitter/Reddit 用户讨论

Step 2: 向量化存储
  → 文本分块（512 tokens）
  → 嵌入向量化
  → 结构化元数据（来源/日期/竞品名）

Step 3: 分析查询
  → "竞品A的核心差异化是什么？"
  → "用户最常投诉竞品B的哪些点？"
  → "市场上还没有解决的需求是什么？"

Step 4: 报告生成
  → 综合多源信息
  → 交叉验证关键观点
  → 生成可引用的报告
```

## 市场进入策略

```markdown
## 蓝海策略框架（四步行动框架）
- 消除：哪些行业认为理所当然但实际无价值的因素？
- 减少：哪些因素可以大幅低于行业标准？

1. 规模细分：SMB vs. Enterprise vs. 个人
2. 行业细分：垂直 vs. 水平
3. 功能细分：单点精深 vs. 全面覆盖
4. 价格细分：免费/低价/高价值
5. 渠道细分：自助 vs. 销售驱动
```

### 品牌危机管理框架

```markdown
## 危机响应四步骤
1. 承认（Acknowledge）：24小时内公开承认问题
2. 道歉（Apologize）：真诚道歉，不推卸责任
3. 行动（Act）：说明具体补救措施和时间表
4. 跟进（Account）：定期更新进展，重建信任

## 危机严重程度分级
- L1（轻微）：个别用户投诉，内部处理
- L2（中等）：媒体关注，需公开回应
- L3（严重）：大规模负面，需高管出面
- L4（危机）：品牌存亡威胁，需全面危机公关
```

### 营销分析框架速查

```markdown
## SWOT 分析
- Strengths（优势）：内部正面因素
- Weaknesses（劣势）：内部负面因素
- Opportunities（机会）：外部正面因素
- Threats（威胁）：外部负面因素

## PESTLE 宏观环境分析
- Political（政治）：政策/监管/贸易
- Economic（经济）：GDP/通胀/就业
- Social（社会）：人口/文化/生活方式
- Technological（技术）：创新/自动化/数字化
- Legal（法律）：劳工法/知识产权/数据保护
- Environmental（环境）：气候/可持续/ESG

## 4P 营销组合
- Product（产品）：功能/质量/品牌/包装
- Price（价格）：定价策略/折扣/支付方式
- Place（渠道）：分销/覆盖/库存/物流
- Promotion（推广）：广告/公关/促销/人员销售
```

### 定价策略模型

```markdown
## 常用定价模型
| 模型 | 适用场景 | 优缺点 |
|------|---------|--------|
| 成本加成 | 制造业/传统零售 | 简单但忽略市场 |
| 价值定价 | SaaS/高端品牌 | 利润高但需强定位 |
| 竞争对标 | 同质化市场 | 安全但利润受压 |
| 渗透定价 | 新市场进入 | 快速获客但利润低 |
| 撇脂定价 | 创新产品早期 | 高利润但市场小 |
| 订阅定价 | SaaS/内容平台 | 稳定现金流 |
| 使用量定价 | API/云服务 | 低门槛但收入波动 |

## ROI 计算模板
ROI = (收益 - 成本) / 成本 × 100%
营销 ROI = (营销带来的收入增量 - 营销成本) / 营销成本 × 100%
健康基准：营销 ROI > 300%（即每投入1元带来3元以上收入）
```

### A/B 测试框架

```markdown
## A/B 测试标准流程
1. 假设：「改变X将导致Y指标提升Z%」
2. 设计：控制组 vs. 实验组，单变量原则
3. 样本：计算所需样本量（统计显著性 p<0.05）
4. 运行：足够时长（至少1-2周，覆盖完整周期）
5. 分析：统计显著性检验，排除偶然因素
6. 决策：推广胜出方案，记录学习

## 常见测试对象
- 落地页标题/CTA文案
- 邮件主题行
- 定价展示方式
- 注册/购买流程步骤
- 广告创意/受众定向
```
