# PM Upward Management — 向上管理

> 单一职责：向老板/利益方汇报的原则与模板。

## 四大原则（BLUF）

```
1. 结论先行（Bottom-line up front, BLUF）
   开头一句话给结论，再展开论证
   ❌ "经过一周的工作，团队完成了..."
   ✅ "本周关键结论：D7 留存从 23% 提升到 31%，超目标 6 pp。"

2. 数据支撑（用指标说话，不用感受）
   ❌ "用户反响很好"
   ✅ "NPS 从 41 提升到 53，30 天内"

3. 推荐方案（给选项而非问题）
   ❌ "用户付费转化低了 / 怎么办？"
   ✅ "用户付费转化降至 1.8%，建议 A: 调整定价 / B: 加引导，推荐 A"

4. 风险透明（提前暴露，带缓解方案）
   ❌ "可能会延期"（暴露后无方案）
   ✅ "T+5 上线有风险（依赖 X 服务），缓解：备选 Y 路径，回滚阈值 N%"
```

## 周报模板

```markdown
# [姓名] 周报 [日期]

## 本周关键结论（BLUF）
[一句话总结最重要的事 — 比一千字汇报更值钱]

## 本周完成
- [具体成果 + 数据，不只是"做了"]
- [关联到目标：本周该指标提升 X%]

## 下周计划
- [可量化目标，不写"持续优化 XX"]
- [明确产出物 + 时间节点]

## 卡点 / 风险
- [问题描述 + 已尝试方案 + 求助/已缓解]
- 不要"等老板看到再说"
```

## 月报模板（一页式）

```markdown
# [产品名] [月份] 月度回顾

## 关键指标对账（vs OKR）
| 指标 | 目标 | 实际 | 达成率 |
|------|------|------|--------|
| [北极星] | X | Y | Z% |
| [关键 KR] | X | Y | Z% |

## 三件最重要的事
1. [战略性进展 + 数据]
2. [影响 OKR 的关键事件]
3. [对下季度有影响的决策]

## 学到的（前瞻）
- [一个本月学到的关键认知 + 怎么影响后续]

## 下月聚焦
- [Top 1 优先级]
- [Top 2]
- [Top 3]
```

## 风险升级时机

```
什么时候必须升级（不能等）：

🔴 立即升级（24h 内）
- 影响 P0 KPI 的事件（DAU 跌 10%+）
- 安全/合规事故
- 关键依赖方变化（接口下线、合作方撤资）
- 跨部门冲突无法在 PM 层解决

🟡 当周升级（含建议）
- 目标偏离 > 20%
- 关键人员变动
- 重大需求变更
- 预算超支预警

🟢 月报披露
- 长期趋势
- 流程优化建议
- 知识沉淀
```

## 反面教训

```
❌ "我有 5 件事要汇报..."
   → 全列没重点 = 没汇报

❌ "听说用户不喜欢..."
   → 二手信息不可信，先验证

❌ "我觉得..."
   → 数据 + 推断 + 不确定性，三件套不能少

❌ "下周我会努力..."
   → 写出可验证的产出，不要写态度

❌ "出问题了，怎么办？"
   → 至少给 1 个建议方案，不要把问题原封不动抛回去
```
