# AI 文本人性化改写技能

## 核心原则

1. 科学准确性优先：禁止改动事实、数据、公式、术语
2. 忠于原文主旨：只改表达，不改观点
3. 信息完整与逻辑连贯
4. 风格一致性：按指定 tone 全文统一
5. 保持写作规范：不口水、不堆砌套话

## 执行流程

1. 读取输入（文本或文件）
2. 识别 AI 痕迹（内容/语言/风格/交流/学术）
3. 按强度执行改写策略
4. 输出改写文本 + 修改说明 + 五维度评分（50分）

## 核心改写策略

### 基础策略（10条）

- 删除填充短语（如"在当今这个时代"）
- 打破公式结构（减少"首先其次最后"）
- 变化句子节奏（长短句交替）
- 直接陈述，减少过度限定
- 删除可引用式"金句"
- 增加具体细节（数字/时间/地点）
- 打破完美逻辑链，加入真实转折
- 优先主动语态
- 允许适度口语化（casual）
- 加入个人观点（我认为/我觉得）

### 进阶策略（13条）

- 句式和关联词调整
- 主语明确化
- 长句重写或拆分
- 同义词自然替换
- 标点微调
- 精简冗余
- 上下文连贯性检查
- 学术模式：认知分层/进化轨迹/方法论指纹/田野实证/反事实推理/例外讨论

## 强度级别

| 强度 | 处理范围 | 适用场景 |
|------|----------|----------|
| low | 基础策略 | 草稿快速润色 |
| medium | 基础+部分进阶 | 通用文档 |
| high | 基础+进阶全量 | 重要文档 |
| max | 全量+学术高级技术 | 学术严格检测 |

```markdown

- 应用策略：[...]

### 质量评分（50分）
| 维度 | 得分 |
|------|------|
| 直接性 | X/10 |
| 节奏 | X/10 |
| 信任度 | X/10 |
| 真实性 | X/10 |
| 精炼度 | X/10 |
| 总分 | XX/50 |
```
