## 一、六大类指标模板

### 类别 6：外部依赖指标

每个第三方依赖必须回答：
1. **SLA**（供应商公布 / 合同承诺）
2. **QPS 上限**（我们买了多少 / 免费额度）
3. **单价 & 用量预算**
4. **失败降级**（本地兜底 / 换供应商 / 用户提示）
5. **数据流向**（数据出境？敏感信息？）
6. **替换成本**（低 / 中 / 高，含合同锁定期）

## 二、常见业务场景指标参考

### 邮箱验证码
```
长度：6 位数字
有效期：5min（可延长至 10min）
单邮箱频次：1min 1 次
单邮箱日限：10 次/24h
全站防刷：单 IP 1min 5 次
日志保留：90 天
存储：只哈希（SHA-256 + 盐）
失败尝试：5 次后锁定该邮箱 15min
到达率：≥ 95%（供应商 SLA）
```

### 批量导入 Excel
```
单次上限：10 万行
单文件大小：≤ 100MB
支持格式：.xlsx（2013+）/ .csv (UTF-8 / GBK 自动识别)
处理时长：10 万行 ≤ 5 分钟
并发：单用户同时 1 个任务
异步处理：> 1 万行走异步 + 邮件通知
错误报告：详细到行号 + 列 + 错误原因
断点续传：不支持（当前版本）
```

### 登录 & SSO
```
密码策略：8-32 字符，含大写+小写+数字+特殊
密码错误锁定：5 次后锁 15 分钟
SSO 协议：SAML 2.0 / OIDC / OAuth 2.0
SSO 会话：8h Absolute / 2h Idle
Just-In-Time Provisioning：支持
密码强度校验：前端 + 后端双验
```

### AI 对话（LLM）
```
响应延迟：首 token ≤ 2s，全响应 ≤ 15s
成功率：≥ 98%
Token 单价（预估）：¥0.01/1k input, ¥0.03/1k output
月度预算：¥ X 万，超预算自动降级到小模型
失败降级：三方 API 500 → 缓存 + 模板化响应
内容安全：调用前 + 生成后双审
数据出境：明确用户数据是否传到 OpenAI / 国内替换方案
Prompt 注入防护：输入过滤 + 输出白名单
```

### 支付
```
到账时长：即时 / T+1 / T+7
手续费：微信 0.6% / 支付宝 0.6% / Stripe 2.9%+30¢
退款：7 天内原路退回
对账周期：D+1 每日对账
异常处理：> 30 分钟不到账触发人工介入
PCI DSS：必须
```
