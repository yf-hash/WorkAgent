# pm-competitive-benchmark — 多维对标工具箱

> 本 skill 被 `/pm-competitive-benchmark` 命令调用。

## 一、5 维对标框架

任何一份严肃的竞品分析都要至少覆盖 5 个维度：

| 维度 | 关注 | 输出 |
|---|---|---|
| **功能对标** | 各家做/不做什么 | 功能矩阵 |
| **定价对标** | 计费模式 + 单价 + 免费额度 | 定价矩阵 + 单位经济 |
| **生态对标** | 集成 / 平台 / 合作伙伴 | 生态图 |
| **口碑对标** | 用户评价 + 净推荐 | 口碑雷达 |
| **技术架构对标** | 底层 / 部署 / 性能 | 架构对比 |

## 二、功能矩阵（Feature Matrix）

### 矩阵结构

行：功能项；列：竞品名（含我方）；值：覆盖度评级 + 备注

```markdown
| 功能 \ 厂商 | 我方 | Jasper | Copy.ai | ChatGPT | Notion AI |
|---|:---:|:---:|:---:|:---:|:---:|
| 长文生成 | ✅ | ✅ | ✅ | ✅ | ✅ |
| Brand Voice | 🟡 | ✅✅ | ✅ | ❌ | ❌ |
| 中文支持 | ✅✅ | 🟡 | 🟡 | ✅ | ✅ |
| 私有部署 | ✅✅ | ❌ | ❌ | ❌ | ❌ |
| API | ✅ | ✅ | ✅ | ✅ | ❌ |
| Chrome 插件 | ❌ | ✅ | ✅ | ✅ | ❌ |
| 团队协作 | 🟡 | ✅ | ✅ | ❌ | ✅✅ |
```

### 评级规则

| 符号 | 含义 |
|---|---|
| ✅✅ | 强项（明显优势） |
| ✅ | 完全支持 |
| 🟡 | 部分支持（需配置 / 有限制） |
| ❌ | 不支持 |
| ❓ | 未知（未采到情报） |

### 功能分类

按照"客户价值链"组织功能，别把矩阵搞成杂货铺：

```
【获取】搜索 / 发现 / 免费试用
【使用】核心能力 1 / 2 / 3
【集成】API / 插件 / SDK
【协作】权限 / 分享 / 团队
【运营】数据 / 监控 / 报表
【维护】备份 / 迁移 / 支持
```

## 三、定价矩阵（Pricing Matrix）

### 三张图

1. **套餐结构对比**：各家几档、每档价格、每档核心限制
2. **单位经济对比**：按"用户 / 月"或"1 万次调用"这类可比较维度
3. **免费额度对比**：谁提供试用、试用多久、免费额度是否够 evaluate

### 定价对标示例

```markdown
## 定价对标

### 套餐结构
| 厂商 | 免费档 | 入门档 | 专业档 | 企业档 |
|---|---|---|---|---|
| 我方 | 无 | ¥99/月 | ¥299/月 | 联系我们 |
| Jasper | 7 天试用 | $39 | $59 | 定制 |
| Copy.ai | 有（2000 词） | $49 | $99 | 定制 |
| ChatGPT | 有（限量） | $20 | $30 | $60/席位 |

### 按每月 1 万次生成对比（单位经济）
| 厂商 | 折算价（USD） | 单价（美分/次） |
|---|---|---|
| 我方 | 42 | 0.42 |
| Jasper | 79 | 0.79 |
| Copy.ai | 99 | 0.99 |
| ChatGPT API | 40 | 0.40 |

### 关键洞察
- 我方定价 = ChatGPT API + 少量溢价（因提供额外能力）
- 相对 Jasper / Copy.ai 便宜 30-50%
- **打法**：以性价比切入中小客户；企业档突出私有部署差异化
```

## 四、生态对标（Ecosystem）

### 生态维度
- **集成清单**：与哪些主流工具集成（Zapier / Slack / Chrome / Notion）
- **API 开放度**：文档质量 / SDK 语言支持 / Webhook 支持
- **社区规模**：GitHub Star / Discord 人数 / 论坛活跃度
- **合作伙伴**：官方 partner 数量 + 类型（reseller / integrator / OEM）
- **开发者数量**：如披露

### 输出格式
```markdown
| 生态维度 \ 厂商 | 我方 | Jasper | Copy.ai |
|---|:---:|:---:|:---:|
| 主流集成数 | 5 | 30+ | 25+ |
| API 文档 | 良好 | 优秀 | 优秀 |
| SDK 语言 | JS/Py | JS/Py/Go/Ruby | JS/Py |
| 社区（GitHub） | 500★ | 无公开 | 无公开 |
| 官方合作伙伴 | 5 | 200+ | 150+ |
```

## 五、口碑对标（Voice of Customer）

### 数据源
- G2 / Capterra / Product Hunt 评分
- Reddit / HN / V2EX 讨论热度 + 情感极性
- Twitter / X 提及量
- 客户案例数（官网）

### 口碑雷达（六维）

```
        产品质量
           ▲
           |
用户支持◄──┼──►性价比
           |
       易用性◄─┼─►生态丰富
           |
           ▼
        创新度
```

每个维度打分 1-5，形成雷达图。

### 用户吐槽 Top 3（每家）
从社区抓真实抱怨，分类：
- **产品问题**：不稳定、慢、bug
- **定价问题**：贵、涨价、坑
- **服务问题**：客服差、响应慢
- **体验问题**：难用、学习曲线陡

## 六、技术架构对标

不涉及内部机密，只看公开可查：
- **底层模型**：自研 / OpenAI / Anthropic / 开源
- **部署形态**：SaaS only / 私有化选项 / 混合
- **数据主权**：数据出境 / 客户数据用于训练？
- **性能公开数据**：延迟 / QPS / 数据保留

## 七、洞察产出（Insight Framework）

多维对标后，输出以下 5 类洞察：

### 1. 我方绝对优势（Absolute Strengths）
- 3-5 个能力我方 ✅✅ 而竞品 ❌ 或 🟡
- 具体：{能力} — {竞品状态} — {对客户的价值}

### 2. 我方绝对劣势（Absolute Weaknesses）
- 3-5 个能力竞品 ✅✅ 而我方 ❌ 或 🟡
- 具体：{能力} — {竞品状态} — {风险 / 缓解}

### 3. 客户价值链上的差距（Value Gap）
- 哪个环节我方明显弱？哪个环节我方明显强？

### 4. 定价错位（Price Gap）
- 我方定价与竞品的相对位置
- 是否有"价格空档"可以切入

### 5. 未满足的市场需求（Unmet Needs）
- 客户在社区抱怨的"没人做好"的需求
- 我方是否可以做

## 八、洞察输出模板

```markdown
## 竞品对标关键洞察

### 我方绝对优势
1. **私有部署**：所有主要竞品都不支持，我方独有；对金融/政企客户是关键
2. **中文能力**：Jasper/Copy.ai 中文支持有限，我方原生优化
3. **性价比**：我方定价比 Jasper/Copy.ai 便宜 30-50%

### 我方绝对劣势
1. **品牌知名度**：Jasper 100k+ 客户 vs 我方（未披露）；缓解：突出深度客户案例
2. **Brand Voice 训练**：Jasper 有专利级方法，我方无；缓解：路线图规划补齐

### 客户价值链差距
- **获取环节**：竞品有 Chrome 插件降低获取门槛，我方无 → 短期补齐
- **使用环节**：我方生成质量与 Jasper 相当
- **协作环节**：Notion AI 深度融入协作，我方偏工具化 → 长期方向

### 定价错位
- 我方 ¥299 = ChatGPT + 50%，Jasper 的 50%
- 空档：企业级 + 私有化 + 中文 组合，市场无人做

### 未满足需求（客户抱怨来源）
- "都太贵了" → 我方性价比切入
- "生成质量不稳定" → 我方 QA 内嵌
- "私有部署没得选" → 我方独家
```

## 九、反模式

- ❌ 功能矩阵没有覆盖度评级 —— 违规
- ❌ 定价只对比首档 —— 违规
- ❌ 洞察不给"对客户价值" —— 违规
- ❌ 生态 / 口碑维度缺失 —— 违规
- ❌ 说完差距不给缓解方向 —— 违规
- ❌ 用行业分析报告代替第一手采集 —— 违规
