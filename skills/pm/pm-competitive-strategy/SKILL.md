# pm-competitive-strategy — 差异化战略工具箱

> 本 skill 被 `/pm-competitive-benchmark` 命令的战略章节调用。

## 一、Blue Ocean 四象限（消除 / 减少 / 提升 / 创造）

来自蓝海战略经典模型。基于对标结果，回答四问：

| 象限 | 判定 | 举例（AI 写作助手） |
|---|---|---|
| **消除（Eliminate）** | 行业默认做但客户不重视 → 我方不做 | 消除"炫技的 AI 讲解页面" |
| **减少（Reduce）** | 行业过度投入 → 我方少做 | 减少"过度模板库"（客户用 3-5 个） |
| **提升（Raise）** | 客户想要更多但没人做够 → 我方做爆 | 提升"生成质量的稳定性" |
| **创造（Create）** | 从未有人做 → 我方独家 | 创造"品牌语气记忆" |

### 输出格式
```markdown
## Blue Ocean 差异化布局

### 消除
- 减少"华丽的 AI 演示动画"（客户不为此付费）

### 减少
- 从"200 + 模板"减到"20 个精品"（用户复用 3-5 个）

### 提升
- 生成质量稳定性从"经常需要重试"提升到"一次通过率 85%+"
- 客服响应从"48 小时"提升到"< 4 小时"

### 创造
- 品牌语气记忆（Brand Voice Memory）—— 无需重复训练
- 私有部署 + 数据不出境（企业市场独家）
```

## 二、Positioning 定位矩阵（二维象限）

选两个客户最关心的维度，把所有厂商放到象限里。

### 常用维度对
- 价格（低-高）× 能力深度（浅-深）
- 通用性（通用-垂直）× 易用性（难-易）
- 私有化（云-私有）× AI 能力（弱-强）

### 输出示例（假设我方 vs Jasper vs ChatGPT）

```
高价 │  Jasper（企业级）        │
     │                          │
     │                          │  我方（企业级 + 私有化）★
     │                          │
─────┼──────────────────────────┼─────
     │  ChatGPT（大众 SaaS）    │  Copy.ai（中端）
     │                          │
低价 │                          │
     └──────────────────────────┴─────
     通用                       垂直/企业级
```

**关键洞察**：我方位于"高价 + 垂直" 象限，避开 ChatGPT 的价格战 + Jasper 的品牌战。

## 三、应对四象限（针对每个竞品的应对策略）

对每个主要竞品，用二问决策：**我方能否超越？** × **市场是否值得投入？**

|   | 值得投入 | 不值得投入 |
|---|---|---|
| **能超越** | 🟢 **领先（Leader）**<br>大力投入超越 | ⚪ 观望 |
| **不能超越** | 🔴 **侧翼（Flank）**<br>找细分市场绕过 | ⚫ **避战（Avoid）** |

**特殊情况**：
- 🟡 **跟随（Follow）**：竞品远超我方但市场必须存在 → 快速跟随
- 🟣 **合作（Ally）**：竞品与我方不是零和 → 集成 / 合作

### 示例应对
```markdown
## 竞品应对策略

### Jasper（直接竞品，高价 + 强品牌）
- 判定：**侧翼**（我方难超越品牌，但可切细分）
- 策略：
  1. 私有化 + 中文 + 企业市场 —— 避开 Jasper 的英语通用市场
  2. 性价比策略 —— 定价约为 Jasper 的一半
  3. 客户案例聚焦金融 / 政企（Jasper 弱势领域）

### Copy.ai（直接竞品，中价 + 中端）
- 判定：**跟随**（能力接近，需在功能上快速追平）
- 策略：
  1. 补齐 Chrome 插件（Q1）
  2. 提升生成质量稳定性
  3. 定价保持略低（性价比锚点）

### ChatGPT（间接竞品，通用大平台）
- 判定：**避战**（无法在通用性上超越）
- 策略：
  1. 明确定位差异 —— 我方是"垂直深度"而非通用
  2. 在应答话术中强调 —— "ChatGPT 是通用助手，我们是专业工具"
  3. 与 ChatGPT API 兼容（客户可以两个都用）

### Notion AI（间接竞品，工作流嵌入）
- 判定：**合作**（用户群不同，可集成）
- 策略：
  1. 探索 Notion 集成
  2. 定位互补 —— 我们做"生成"，Notion 做"组织"
```

## 四、销售话术库

针对客户对比时最常问的问题，准备结构化话术。

### 通用话术公式
```
承认对方优势（1 句）
→ 突出我方差异化（2-3 句）
→ 匹配客户具体场景（1 句）
→ 引导下一步（1 句）
```

### 竞品 FAQ 模板

```markdown
## 销售话术：面对客户对比

### Q1: 你们比 Jasper 好在哪？
**A**:
Jasper 是很成熟的产品，在英语通用内容生成上确实很强。
我们的差异化在三方面：
  1. **中文原生**：我们的中文生成质量 Jasper 目前跟不上；
  2. **私有部署**：对金融 / 政企 / 出海到某些国家的客户，Jasper 只有 SaaS 是硬约束；
  3. **性价比**：我们价格约为 Jasper 的一半，对预算敏感团队友好。
如果您的场景是中文 / 私有化 / 中大预算，我们比 Jasper 合适。

### Q2: ChatGPT 已经能做，为什么要用你们？
**A**:
ChatGPT 是通用助手，我们是垂直深度工具，差异不是"能不能做"而是"做得好不好"：
  1. **稳定性**：ChatGPT 每次输出风格不同，我们的品牌语气记忆保证一致；
  2. **专用工作流**：我们内嵌 SEO / A/B 测试 / 团队审批，ChatGPT 是白板；
  3. **成本可控**：ChatGPT API 按量计费，我们套餐可预测；
可以两个都用 —— 我们兼容 ChatGPT API 输入。

### Q3: Copy.ai / Writesonic 便宜怎么办？
**A**:
它们价格接近我们，我们的差异在质量的稳定性：
  1. Copy.ai 生成常需 3-5 次重试，我们一次通过率高；
  2. 私有部署 / 中文 / 企业支持，Copy.ai 均弱；
如果只是个人用户，可能它们够用；企业场景我们更合适。

### Q4: 你们没什么大品牌客户吧？
**A**:
承认在客户数量上 Jasper 更多，但我们在深度上有强 case：
  1. XX（金融）—— 私有部署 + 团队 200 人；
  2. YY（制造）—— 中文 + 定制模板；
案例数量少但每个都可提供联系人核实。

### Q5: 我们已经在用 Jasper 了，为什么要换？
**A**:
我们不建议轻易换，除非 Jasper 无法解决您的具体痛点：
  - 如果您有中文场景 + Jasper 不给力 —— 值得换；
  - 如果私有化是新要求 —— 值得换；
  - 如果只是想省 30% 预算 —— 可以试试并行 3 个月对比；
可以先跑一个 POC 对比再决定。
```

## 五、竞品跟踪常态化（Monitor）

### 每月轻量刷新（10 分钟）
- 各竞品 Changelog 最新更新
- 大新闻（融资 / 大客户 / 高管变动）
- 定价变动
- 社区讨论热度

### 每季度全量刷新
- 重新跑 `/pm-competitive --mode full`
- 更新功能矩阵 / 定价 / 洞察
- 更新应对策略

### 关键节点触发
- 客户对比投诉时
- 竞品发布重要新功能时
- 我方即将发大版本前
- 招投标前

## 六、反模式

- ❌ 只说"我们更好" 不承认对方优势 —— 客户不信任
- ❌ 应对策略未按 4 象限分类 —— 违规
- ❌ 话术攻击竞品 —— 专业性差
- ❌ 差异化点 > 5 个 —— 客户记不住，重点稀释
- ❌ 战略与洞察脱节 —— 违规，战略必须基于对标结果
