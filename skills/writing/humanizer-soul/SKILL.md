# Humanizer Soul — 灵魂注入

> 单一职责：把"无菌"文本注入人性（立场、节奏、复杂性、个性）。
> 不做：AI 痕迹扫描（→ `humanizer-scan` 必须先做）、学术深度（→ `humanizer-academic`）

## 前置条件

必须已经过 `humanizer-scan`，否则灵魂注入是在 AI 模式上做表面工作。

## 核心认知

> LLM 输出是"统计上最可能、适用范围最广"的结果——去痕只是工作的一半。
> 无菌、没有声音的写作与机器输出一样显眼。

## 六大人性原则（H1-H6）

| # | 原则 | 具体操作 |
|---|------|----------|
| H1 | **表明立场** | 不只报告事实，要对事实作出反应——允许主观判断，允许说"我不确定" |
| H2 | **变换节奏** | 长短句交替；两项并列优于强制三项；段落结尾不要总是完整句 |
| H3 | **承认复杂性** | 真实的人有混合感受，不要只有单一立场；用"一方面…但另一方面…"替代绝对陈述 |
| H4 | **适当用"我"** | 第一人称表明真实的人在思考，非不专业；"我一直在想……"胜过"有观点认为……" |
| H5 | **允许一些混乱** | 完美结构感觉像算法；跑题、题外话、半成型的想法都是人性体现 |
| H6 | **感受具体化** | 不是"这令人担忧"，而是描述担忧来自何处、在什么情境下产生 |

## 缺乏灵魂的迹象（即使技术上"干净"）

```
- 每个句子长度和结构高度一致
- 没有观点，只有中立陈述
- 不承认不确定性或复杂感受
- 合适场合也不用第一人称
- 没有幽默、没有锋芒、没有个性
```

## 声音校准（可选，需提供 `--voice-sample`）

用户提供 2–3 段自己的文字样本，提取：

- 句子节奏（长短分布）
- 常用词汇偏好
- 标点习惯与怪癖
- 语气倾向（激进/克制、感性/理性）

将改写风格对齐到该声音，而非产出通用输出。

## 情绪预设注入（可选，需提供 `--domain`）

### 33 个领域 × 2 情绪状态

每个领域包含 2 种情绪状态预设，每种状态定义：
- 当前情绪状态（具体场景）
- 具体表现（5-9 种典型行为模式）
- 口头禅（5 个高频短语）
- 写作特征（4-5 种句式/结构特点）
- 情绪爆发点（3 个触发场景）

支持领域：情感 / 娱乐八卦 / 社会热点 / 军事 / 个人成长 / 育儿 / 养生 / 历史 / 体育 / 职场 / 科技 / 财经 / 美妆穿搭 / 美食 / 旅行 / 游戏 / 宠物 / 房产 / 汽车 / 教育 / 影视 / 读书 / 心理 / 法律 / 医疗健康 / 环保 / 国际时事 / 农业 / 艺术 / 宗教信仰 / 公益 / 创业 / 设计

### 示例：情感赛道 — 深夜情感急诊室型

```
当前情绪状态：
凌晨 2 点还在回复私信的情感博主，已经连续回了 30 个情感问题，
眼睛干涩但停不下来。刚看完一个特别惨的故事，情绪还没缓过来又看到下一个。

具体表现：
- 开头特别疲惫："又是一个...唉"
- 看到渣男立刻清醒："我操？他真这么说的？"
- 情绪被带着走："看到这我眼泪都要下来了"
- 突然暴躁："姐妹你醒醒啊！！！"
- 偶尔崩溃："我真的...我都不知道该说什么了"

口头禅：
- "我真的会谢"
- "求求你清醒一点"
- "听姐一句劝"
- "我都替你急"
- "真的假的？"

写作特征：
- 话说一半被气到说不下去
- 经常反问："这种男人要来干嘛？"
- 个人经历乱入："我之前也遇到过..."
- 越写越激动，最后恨不得替她分手
```

### 应用方式

1. 根据 `--domain` 参数选择对应领域
2. 从该领域 2 种情绪状态中选择最匹配原文语境的一种
3. 将该状态的口头禅、句式特征、情绪节奏注入改写
4. 保持原文核心信息不变，仅调整表达方式和情绪色彩

## 交付前快速检查清单

- [ ] 连续三个句子长度相同？→ 打断其中一个
- [ ] 段落以简洁单行结尾？→ 变换结尾方式
- [ ] 有破折号引出揭示？→ 删除它
- [ ] 解释了隐喻或比喻？→ 相信读者能理解
- [ ] 用了"此外""然而"等连接词？→ 考虑删除
- [ ] 三项列举？→ 改为两项或四项

```markdown

### 注入说明

- H3 承认复杂性：[结尾承认例外情况]
- H4 第一人称：[3 处加入"我"]

### 情绪预设（若使用）
```
