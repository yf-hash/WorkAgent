# Humanizer Academic — 学术深度强化

> 单一职责：学术场景的 30 条深度强化指令。
> 不做：通用去痕（→ `humanizer-scan` 先做）、灵魂注入（→ `humanizer-soul`）

## 前置条件

- 已执行 `humanizer-scan`（消除 29 模式）
- 已执行 `humanizer-soul`（人性原则 H1-H6）
- 适用场景：顶刊投稿、学位论文、严格 AI 检测（Turnitin/GPTZero/Originality.ai）

## 30 条高级学术去痕指令（9 大类）

### 类别 1：认知重构（指令 1-2）

| ID | 指令 | 操作 |
|----|------|------|
| A1 | **认知分层改写** | 提取核心论点 → 理论来源 → 现实矛盾 → 创新假设 |
| A2 | **研究演化轨迹嵌入** | 早期研究 → 中期转向 → 近期突破 → 本文创新点 |

### 类别 2：细节增殖（指令 3-4）

| ID | 指令 | 操作 |
|----|------|------|
| A3 | **方法论指纹** | 引用具体学者的改良版本，标注参数权重，Delphi 验证 |
| A4 | **田野实证颗粒** | 3 个月参与式观察，部门级具体发现，与既有文献的分歧点 |

### 类别 3：逻辑跃迁（指令 5-6）

| ID | 指令 | 操作 |
|----|------|------|
| A5 | **反事实推理** | 若政策未实施，指标下降 X%，历史模拟 |
| A6 | **例外情况讨论** | 整体显著但子群 β=-0.12, p=0.08 反向趋势 |

### 类别 4：学术身份具化（指令 7-10）

| ID | 指令 | 操作 |
|----|------|------|
| A7 | **学术人设** | 博士：理论创新风格；青年学者：实践对话风格 |
| A8 | **固定学术表达** | 3-5 个个性化学术短语 |
| A9 | **思考决策痕迹** | "最初考虑 X 方法，但因 Y 限制改用 Z" |
| A10 | **现场分析记录** | "访谈中发现…与预期不符" |

### 类别 5：反检测算法（指令 11-14）

| ID | 指令 | 操作 |
|----|------|------|
| A11 | **高频短语替换** | 综上所述→从研究脉络看；相关研究表明→XX 团队(2023)在 XX 研究中观察到 |
| A12 | **语法复杂度变换** | 简单句/复合句/倒装句混合 |
| A13 | **非对称引用结构** | 经典 40% + 近 2 年 30% + 跨学科 30% |
| A14 | **学术争论引用** | "XX(2022) 认为…但 YY(2023) 反驳…本文倾向…" |

### 类别 6：实证深度（指令 15-18）

| ID | 指令 | 操作 |
|----|------|------|
| A15 | **技术操作细节** | Python Scikit-learn，5-fold CV，17 次迭代 |
| A16 | **田野场景植入** | "在 XX 车间观察到…" |
| A17 | **模态限定** | 强断言→弱断言；绝对→概率 |
| A18 | **实施约束条件** | "在 XX 条件下成立，若 YY 则需调整" |

### 类别 7：格式反特征化（指令 19-22）

| ID | 指令 | 操作 |
|----|------|------|
| A19 | **问题导向标题** | 替换 1.1/1.2 编号 |
| A20 | **研究-行动三级标题** | "XX 现象 → XX 机制 → XX 对策" |
| A21 | **数据表异常标注** | "样本 #47 异常值，已剔除" |
| A22 | **图表设计决策逻辑** | "选择散点图而非柱状图，因为…" |

### 类别 8：学术伦理（指令 23-26）

| ID | 指令 | 操作 |
|----|------|------|
| A23 | **伦理审查证据链** | "已获 XX 伦理委员会批准（编号：XX）" |
| A24 | **AI 工具透明声明** | "使用 ChatGPT 辅助文献整理，所有论点由作者独立完成" |
| A25 | **研究坐标定位** | "本文定位于 XX 理论与 YY 实践的交叉地带" |
| A26 | **关键词方法论创新术语** | 包含 1-2 个本文提出的新术语 |

### 类别 9：终极验证清单（指令 27-30）

| ID | 指令 | 操作 |
|----|------|------|
| A27 | **AI 检测工具预扫** | 连续 5+ 句 SVO >60%，被动 >35%，单一标点 >80% 为高风险 |
| A28 | **学术声纹对比** | TF-IDF，>75% 重叠，<15% 复杂度波动 |
| A29 | **同行 3 分钟可读性测试** | 请同行快速阅读，标注"不像人写的"句子 |
| A30 | **版本迭代追踪** | 保留草稿、SPSS 日志、导师邮件截图 |

## 输出格式

```markdown
## 学术深度强化结果

### 强化后的文本
[完整文本]

### 应用的指令
- A2 研究演化轨迹：第 1 章背景引入早-中-近三段
- A5 反事实推理：第 4 章新增"若未实施"分析
- A11 高频短语替换：替换 12 处
- A15 技术操作细节：方法章补全 SVM 参数和 CV 折数
- A21 数据表异常标注：表 3 加入剔除说明

### AI 检测预估
- SVO 占比：48%（< 60%，OK）
- 被动语态：32%（< 35%，OK）
- 单一标点：64%（< 80%，OK）
- TF-IDF 学术声纹重叠：> 75% ✅

### 同行 3 分钟测试结果（如有）
- 标注的不像人句子：[列举 + 已修改]
```
