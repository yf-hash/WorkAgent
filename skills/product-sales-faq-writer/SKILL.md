# 销售常见问题（FAQ）写作知识库

> 单一文档类型 | 受众：销售 / 售前 | 密级：可公开 | 形态：Word

---

## 核心原则

1. **五大类全覆盖**：技术原理 / 竞品对比 / 部署运维 / 价格授权 / 服务支持，缺一类就不及格
2. **口语化应答**：销售要能直接念出来，长句改短句，去掉书面术语
3. **数据兜底**：能用数字的不用形容词（"日均拦截 1000 万次"，不是"防护能力强"）
4. **避坑话术**：对客户敏感点（隐私 / 合规 / 国产化）准备退路应答

---

## 五大类问题清单

### 一、技术原理类

| 问题类型 | 示例 |
|---------|------|
| 核心技术是什么 | "你们用什么核心技术实现 XX 功能？" |
| 算法是否自研 | "底层算法是自研的还是开源的？" |
| 与传统方案区别 | "和传统的 XX 方案相比有什么本质不同？" |
| 创新点 | "你们的技术创新点在哪里？" |

### 二、竞品对比类

| 问题类型 | 示例 |
|---------|------|
| 直接对比 | "和厂商 X 相比有什么不同？" |
| 价格差异 | "为什么你们比 X 贵 / 便宜？" |
| 客户选择理由 | "已经在用 X 的客户为什么换成你们？" |
| 兼容并存 | "能不能和现有的 X 并存？" |

### 三、部署运维类

| 问题类型 | 示例 |
|---------|------|
| 环境要求 | "硬件 / OS / 数据库 / 网络要求是什么？" |
| 虚拟化 | "是否支持 VMware / KVM / 信创虚拟化？" |
| 平台兼容性 | "是否支持鲲鹏 / 飞腾 / 海光？" |
| 部署模式 | "单机 / 集群 / 容器 / 云原生支持哪些？" |
| 升级 | "升级是否需要停机？数据如何迁移？" |

### 四、价格授权类

| 问题类型 | 示例 |
|---------|------|
| 定价方式 | "按用户 / 按节点 / 按订阅，怎么算？" |
| 报价范围 | "我们这个规模大概多少钱？" |
| 授权方式 | "永久授权还是年费订阅？" |
| 试用 | "能不能先试用？多久？" |
| 商务条款 | "POC / 培训 / 实施费用包含吗？" |

### 五、服务支持类

| 问题类型 | 示例 |
|---------|------|
| 交付周期 | "签约后多久能用上？" |
| SLA | "故障响应承诺是几小时？" |
| 培训 | "提供什么培训？" |
| 升级 | "未来版本升级是否免费？" |
| 售后 | "本地有没有支持团队？" |

## 标准应答结构

```markdown
## [问题分类] [问题简称]

**问题原文**：
> 客户具体怎么问这个问题（口语化）

**标准应答**（100-200 字，可口语表达）：
[销售可直接念出来的应答]

**关键数据 / 证据**：
- 数据 1
- 数据 2
- 引用资料

**进阶应答**（深入提问时使用）：
[更详细的技术或商务回答]

**避坑提示**：
[这个问题容易踩什么坑 / 不该说什么]
```

## 质量要求

| 维度 | 标准 |
|------|------|
| 五大类覆盖 | 必须齐全，每类至少 5 个问题 |
| 总问题数 | 25-40 个 |
| 应答字数 | 主应答 100-200 字 |
| 数据支撑 | 至少 60% 的问题有数据支撑 |
| 时效性 | 每季度复盘更新 |
