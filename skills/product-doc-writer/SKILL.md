# B2B产品资料体系知识库

> 覆盖24类标准文档 | 产品资料生产规范 | 通用B2B模版

---

## 核心原则

1. **规范命名**：`[产品名]【版本号】[文档类别名]_版本号.扩展名`，如 `数据安全网关【v1.0】产品白皮书_v1.0.docx`
2. **密级管理**：竞品分析、技术白皮书、招投标参数为**内部保密**，其余可公开
3. **内容准确**：禁用已变更/废弃的产品名和公司名，发现时必须全文替换
4. **版本追踪**：每份文档必须有修订记录表（版本/时间/编制者/审核者/修订内容）
5. **封面规范**：封面标题文字与背景色对比度须符合企业VI规范，确保可读性

---

## 文档类型规范库

### 一、产品基础资料

#### 1. 产品介绍-商务版（PPT）
**受众**：商务决策层、采购委员会
**核心内容**：
- 封面：产品名称 + 版本 + 公司Logo
- 公司介绍：公司背景、业务定位、核心资质
- 产品概述：一句话定位 + 三大核心价值
- 核心功能：不超过6个主功能，每个配效果截图
- 典型客户：Logo墙 + 3个核心案例
- 联系方式

**质量要求**：商务版侧重"为什么买"，不讲技术细节，聚焦商业价值和ROI

### 二、销售赋能文档

#### 7. 产品销售指南（销售一页禅）（Word，必选，可公开）
**结构模板**（详见 `skills/sales-guide-writer/SKILL.md`）：
1. 概述（产品简介 + 优势亮点 + 产品说明）
2. 销售场景（3-5个场景，每个含：目标客户/故事/需求/解决思路）
3. 竞争对比
4. 行业客户案例
5. 销售价值

---

#### 8. 销售常见问题（Word，必选，可公开）
**问题类型覆盖**：
- 技术原理类（使用了什么核心技术）
- 竞品对比类（与XX相比有什么不同）
- 部署运维类（环境要求/虚拟化/平台兼容性）
- 价格授权类（定价/授权方式/报价范围）
- 服务支持类（交付周期/SLA/培训支持）

**格式要求**：每个FAQ = 问题标题 + 参考答案

---

### 三、产品竞争分析（PPT，**内部保密**）

#### 竞争优势四级分类体系

| 级别 | 名称 | 定义 | 处理策略 |
|------|------|------|---------|
| **A级** | 唯一性优势 | 只有我方一家具备（绝对性敌无我有） | 重点突出，作为核心差异化 |
| **B级** | 核心优势 | ≤3家厂商具备（相对性我有敌无或少） | 主动强调，证明领先地位 |
| **C级** | 一般优势 | 多数厂家均具备 | 基础配置，保障覆盖度 |
| **D级** | 未有优势 | 友商有、我方没有的点 | 提前准备话术，转移焦点 |

**竞品分析结构**：
```
1. 竞品概况（市场地位/主要产品/客户群）
2. 功能对比矩阵（含A/B/C/D标记）
3. 我方优劣势分析（含D级应对话术）
4. 差异化销售策略
5. 竞争应对剧本
```

### 四、招投标资料

#### 招投标参数文档（Excel，**内部保密**）
**完整版结构**：
| 产品名称 | 指标项 | 主模块 | 子模块 | 优势项分类(A/B/C/D) | 功能描述 | 指标变化说明 |
|---------|--------|--------|--------|-------------------|---------|------------|

**模块分类**：
- 总体要求：产品架构、厂商资质
- 产品功能：各核心功能模块
- 非功能性要求：性能要求、安全要求、服务要求

**最佳实践**：建议同时提供**精简版**（核心指标）和**完整版**两份招投标参数文档

---

### 五、解决方案（Word，必选，可公开，最少30页）

**字体规范**（中文场景参考）：
- 1级标题：黑体 三号
- 2-3级标题：黑体 小三
- 4级标题：黑体 四号
- 正文：宋体 小四

**必须章节结构**：
```
1. 概述
   1.1 建设背景（行业现状/挑战/监管要求）
   1.2 建设必要性

2. 建设思路
   2.1 需求分析
   2.2 建设目标
   2.3 建设依据（法规/标准/政策）
   2.4 建设原则

3. 系统解决方案
   3.1 系统架构设计
   3.2 技术实现路径
   3.3 系统功能设计
      3.3.1 [主功能模块1]
         3.3.1.1 [子功能模块]

4. 部署模式
   4.1 典型部署架构
   4.2 硬件配置建议

5. 方案优势
   5.1 技术优势
   5.2 服务优势

6. 建设收益
   6.1 业务收益
   6.2 管理收益
   6.3 合规收益

7. 方案清单
   | 方案组件 | 描述 | 实体类型 | 选型参考 |
```

### 六、交付手册

#### 产品操作手册（Word，必选，可公开）
**结构**：
1. 快速入门（登录/基础配置）
2. 功能操作说明（截图+步骤编号）
3. 常见问题处理

1. 环境准备（OS/数据库/中间件要求）
2. 安装步骤
3. 初始化配置
4. 高可用部署（可选）
5. 升级/回滚操作
6. 运维监控说明

### 七、成功案例（Word，必选，可公开）
**STAR结构**：
- **背景**：客户规模、行业、面临的挑战
- **挑战**：具体痛点、风险事件、合规压力
- **方案**：部署了哪些产品、如何解决问题
- **成果**：量化收益（如：拦截X次攻击/节省X人力/通过XX认证/降低X%成本）

**字数要求**：每个案例800-1500字，含客户证言

---

### 八、测试与兼容

#### 产品测试文档（Word，必选，可公开）
**必要章节**：

## 文档质量自查14项

### 格式类（7项）
| # | 重要度 | 检查项 |
|---|--------|--------|
| F1 | ★★★ | 文件名格式：`[产品名]+[文档类别名]+版本（+时间）` |
| F2 | ★★★ | 文档变更页存在，含：版本/修订项/修订人 |
| F3 | ★★ | 封面标题正确，含产品名和文档类别名 |
| F4 | ★★ | 目录标题页码与正文一致，无空章节，无未修改的模板内容 |
| F5 | ★ | 法律声明存在，版权信息更新为当年（©20XX [公司名称]） |
| F6 | ★ | 页眉/页码/章节编号/字体/行间距/图表样式符合企业模板要求 |
| F7 | ★★★ | 封面配色符合企业VI规范，标题文字与背景色对比清晰可读 |

### 内容类（4项）
| # | 重要度 | 检查项 |
|---|--------|--------|
| C1 | ★★★ | 无过时/已变更的产品名称、公司名称（需对照当前正式名称） |
| C2 | ★★★ | 无重要章节缺失/内容重复/内容过于简单/大量复制粘贴 |
| C3 | ★★★ | 文档内容与当前产品功能版本保持一致，定期更新 |
| C4 | ★★ | 保密文档封面或页眉已标注"内部资料"或"禁止外传" |

### 上传类（3项）
| # | 重要度 | 检查项 |
|---|--------|--------|
| U1 | ★★★ | 保密文档已上传内部系统（非公开渠道） |
| U2 | ★★ | 必选文档完备（新产品可暂不上传成功案例） |
| U3 | ★ | 产品介绍页图文描述完整，不少于3张图片+完整说明文字 |

## 版本管理规范

```
版本号规则：
- v1.0  → 初版
- v1.1  → 小改动（功能补充/局部修订）
- v2.0  → 大版本（架构重构/全面更新）

文档变更页格式：
| 版本 | 修订时间 | 编制者 | 审核者 | 修订内容 |
|------|----------|--------|--------|----------|
| v1.0 | YYYY-MM-DD | [姓名] | [姓名] | 初稿 |
```
