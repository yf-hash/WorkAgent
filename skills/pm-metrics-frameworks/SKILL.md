# PM Metrics Frameworks — 北极星 + AARRR 指标框架

> **单一职责**：产品指标体系设计。分两块内容：一、北极星指标（战略层核心价值）；二、AARRR 五层漏斗（执行层子指标）。两者构成 PM 完整指标视角。
>
> **不做**：看板生成（→ `dashboard-northstar` / `dashboard-aarrr`）、优先级排序（→ `pm-prioritization-frameworks`）。

---

## 一、北极星指标（North Star Metric）

### 1.1 设计原则

```
好的北极星指标必须满足：

1. 反映用户获得的核心价值（不是收入）
2. 可量化、可分解、可追踪
3. 与商业目标强相关
4. 团队能影响它
```

### 1.2 知名公司示例

| 公司 | 北极星指标 | 解读 |
|------|-----------|------|
| Slack | DAU 发送的消息数 | 消息发出 = 真实协作发生 |
| Airbnb | 被预订的夜晚数 | 夜晚 = 房东和房客同时获得价值 |
| Spotify | 每月收听分钟数 | 时长 = 用户被音乐留住 |
| Notion | 每周协作的团队数 | 团队 = 多人协同价值放大 |
| Uber | 完成的乘车次数 | 完成 = 司乘双边都满足 |
| YouTube | 每日观看时长 | 时长 = 内容粘性 |
| Dropbox | 上传文件的活跃用户数 | 上传 = 真实数据托管 |

### 1.3 反面案例（不该作为北极星）

```
❌ 注册用户数：滞后指标，可被刷量
❌ 月收入：财务指标不是价值指标
❌ 页面浏览量：不代表用户得到价值
❌ DAU 数字本身：没有体现"做了什么"
```

### 1.4 北极星 + 护栏指标

```
北极星单独存在会被钻空子：
- "DAU 发送消息数" → 可能群发垃圾信息
- "观看时长"      → 可能推荐成瘾内容

护栏指标防止异化：
- 用户体验护栏：NPS / 卸载率 / 投诉率
- 商业护栏：付费用户增长率 / 单位经济效益
- 健康护栏：消息互动率 / 内容举报率

北极星 + 护栏 = 完整指标系统
```

### 1.5 拆解到输入指标

```
北极星 → 输入指标（Input Metrics）

示例：DAU 发送消息数 = DAU × 人均消息数
  ├── DAU 提升路径：
  │    ├── 新用户激活率
  │    ├── 老用户留存率
  │    └── 唤回成功率
  └── 人均消息数提升路径：
       ├── 团队数 / 用户
       ├── 频道数 / 团队
       └── 消息深度（线程参与）

每个输入指标对应可执行的产品改进项。
```

### 1.6 设计自检清单

- [ ] 这个指标反映"用户获得价值"了吗？
- [ ] 我们的团队/产品能影响它吗？
- [ ] 它能拆成 3-5 个输入指标吗？
- [ ] 有护栏指标防止异化吗？
- [ ] 全公司能用一句话解释它吗？

## 二、AARRR 五层漏斗（海盗指标）

北极星位于 Activation/Retention 交集处（**太靠 Acquisition 容易刷量，太靠 Revenue 容易伤害用户**）。AARRR 是把北极星拆到执行层的标准漏斗。

```
Acquisition（获客）  →  Activation（激活）  →  Retention（留存）
                                                     ↓
                            Referral（推荐）  ←  Revenue（变现）
```

### A1 · Acquisition（获客）

```
关键 KPI：
- CAC（Customer Acquisition Cost）：单个客户获取成本
- 流量渠道占比：自然 / 付费 / 推荐 / SEO 各占比
- 渠道 ROI：(LTV - CAC) / CAC，> 3 为健康
- 注册转化率：访客 → 注册的转化

诊断要点：
- CAC 持续上涨而留存不变 → 渠道质量下降
- 单一渠道 > 60% → 渠道集中风险
- 注册转化 < 5% → 注册流程过重
```

### A2 · Activation（激活）

```
关键 KPI：
- Aha Moment 到达率：新用户达到核心价值瞬间的比例
- 新用户 D1 完成度：首次使用核心功能的比例
- TTV（Time To Value）：注册到 Aha Moment 的时间

Aha Moment 示例：
- Twitter：关注 30 人 + 7 天内登录 ≥ 4 次
- Facebook：10 天内加 7 个好友
- Slack：团队发送 2000 条消息
- Dropbox：1 台设备上传 1 个文件并访问

诊断要点：
- 激活率 < 20% → Onboarding 体验差或 PMF 弱
- TTV > 24 小时 → 引导流程冗长
```

### A3 · Retention（留存）

```
关键 KPI：
- D1/D7/D30/D90 留存率
- DAU/WAU/MAU
- 留存曲线（Cohort）
- Churn Rate：N 期未活跃的流失率

留存曲线类型：
- 死亡曲线：持续下降到 0 → 无 PMF
- L 型曲线：稳定在 N% → 有 PMF
- 微笑曲线：先降后升 → 强 PMF + 唤回成功

诊断要点：
- D7 < D1/2 → 早期流失严重，Onboarding 问题
- 老用户曲线和新用户曲线差距大 → 留存随时间改善
```

### A4 · Revenue（变现）

```
关键 KPI：
- ARPU（每用户平均收入）
- LTV（用户生命周期价值）
- LTV / CAC：> 3 健康，> 5 优秀
- 付费转化率：免费 → 付费
- ARR / MRR：B 端订阅业务核心
- NRR（Net Revenue Retention）：> 100% 表示扩张

诊断要点：
- 付费转化 < 2% → 价值未传递 / 定价错位
- NRR < 100% → 流失超过扩张，业务衰退
- LTV/CAC < 1 → 业务亏损，不可持续
```

### A5 · Referral（推荐）

```
关键 KPI：
- NPS（Net Promoter Score）：推荐者 - 贬损者
- K-factor：每个用户带来的新用户数（> 1 病毒传播）
- 分享率：实际分享 / 看到分享按钮
- 邀请转化：邀请发出 / 邀请人接受

K-factor 公式：
K = i × c
i = 每个用户发出邀请数
c = 每个邀请的转化率

诊断要点：
- NPS < 30 → 用户口碑弱
- K < 0.1 → 几乎无病毒传播
- 分享率 > 10% 但转化 < 5% → 落地页问题
```

### 全漏斗诊断顺序

```
出现问题，自顶向下排查：
1. Acquisition 数量 OK 吗？质量呢？
2. Activation 率正常吗？Aha 路径有断点吗？
3. D1/D7 留存崩了吗？
4. 付费转化正常吗？
5. Referral 出来了吗？

不要跳到下游优化 — 上游漏了，下游再优化也是漏斗变小。
```

## 三、北极星 vs AARRR：如何配套使用

Slack 示例（从北极星 → 五层漏斗的完整映射）：

```
北极星：DAU 发送消息数 ← 高频价值
├── A1 获客：注册团队数
├── A2 激活：发出第一条消息
├── A3 留存：周活团队
├── A4 营收：付费团队
└── A5 推荐：邀请加入团队
```

**协作原则**：北极星是战略层"我们在意什么"，AARRR 是执行层"我们该改哪里"。两者一体：北极星异动时，从 AARRR 漏斗自顶向下找断点。
