# Battle Card — 竞品作战卡知识库

> Battle Card 是销售 / 售前在客户面前遭遇竞争对手时**60 秒可读完**的内部弹药。
> 不是给客户看的，是给我方团队看的。
> 区别于 `market-research`（深度竞品报告，5000+ 字）：Battle Card 是一页纸（≤500 字）。

---

## 一、Battle Card 标准结构（一对手一卡）

```
═══════════════════════════════════════════
[竞争对手公司] | Battle Card v[版本] | [日期]
═══════════════════════════════════════════

🎯 一句话定位（对手的）
  "[对手] 的核心定位是 [X]，主要服务 [客户类型]"
  例："Splunk 的核心定位是日志聚合分析，主要服务大企业 SOC"

⚔️ 我方三大杀手锏（在 [对手] 面前必赢的点）
  1. [杀手锏 1] — 量化对比
  2. [杀手锏 2] — 量化对比
  3. [杀手锏 3] — 量化对比

⚠️ 我方三个雷区（在 [对手] 面前一定要回避或防守）
  1. [雷区 1] — 应对话术
  2. [雷区 2] — 应对话术
  3. [雷区 3] — 应对话术

💰 价格锚点
  [对手] 典型报价：[范围] / [模式]
  我方对位报价：[范围] / [策略]
  谈判要点：[具体怎么谈]

🎤 客户问"为什么不用 [对手]"标准应答
  [一段 30 秒可说完的话术，先肯定对手→再说差异化→最后引导决策维度]

📌 客户问"[对手] 有 X 功能你们有吗"应答
  - 如果有：直接说"有，而且 [更好的角度]"
  - 如果没有：诚实承认 + "这部分通过 [替代方案] 实现，业务效果是 [Y]"
  - 如果在 roadmap：明确时间表 + "在此期间通过 [Z] 解决"

👥 关键人画像
  EB 视角：对手在 [角色] 心目中的形象 = [...]
  TB 视角：技术团队对对手的评价 = [...]
  常见 Champion 反对对手的理由：[...]

🚨 内部使用提示（不要在客户面前说）
  - 对手最近的负面新闻 / 客户流失 / 高管离职
  - 对手已知的合规缺口 / 重大漏洞 / 案例失败
  - 我方已挖到的对手客户原话引用（脱敏）

═══════════════════════════════════════════
```

## 二、应对话术红线

### 2.1 永远不要做
```
❌ 直接贬低对手（"他们就是垃圾"）
   → 客户会觉得我方 unprofessional + 法律风险
❌ 编造对手缺陷（"他们没有 X 功能"，但其实有）
   → 客户对照后我方信誉崩盘
❌ 比较未公开数据（"我们性能是他们 10 倍"）
   → 必须有第三方报告 / 公开 benchmark 引用
❌ 攻击对手客户（"用 [对手] 的客户都吃过亏"）
   → 客户里可能就有
```

### 2.2 标准防御话术框架

```
框架 1：肯定 + 转移（Acknowledge & Pivot）
  "[对手] 在 [X 领域] 确实有积累，特别是 [具体优点]。
   不过对您 [客户具体痛点] 这个问题，我们做了不同选择：
   [我方差异化角度]"

框架 2：维度重构（Reframe Dimensions）
  "如果按 [对手强项] 比较，我们承认 [对手] 在这方面成熟。
   但对您来说，[业务关键维度] 可能更重要 —
   而这个维度上，我们 [我方优势 + 量化]"

框架 3：客户故事（Customer Story）
  "我们最近有一家 [客户行业 + 规模] 客户，最初也在我们和 [对手] 之间纠结。
   最后他们选了我们，主要原因是 [一两个具体场景]。
   现在 [客户量化结果]。如果您愿意，我可以安排和他们交流。"

框架 4：诚实差异（Honest Differentiation）
  "我们和 [对手] 走的是不同路线 — [对手] 偏向 [A 方向]，
   我们偏向 [B 方向]。哪个适合您，取决于您 [关键决策维度]。"
```

## 三、Hot Button 议题处理

Hot Button = 客户最关心、对手宣传最猛的 3-5 个议题。

### 3.1 识别 Hot Button
```
方法：
  1. 客户在对话中反复提到的关键词
  2. 对手官网首屏 / 落地页主打信息
  3. 行业分析报告（Gartner / IDC / 信通院）评估维度
  4. 招标文件中的评分项
```

### 3.2 Hot Button 应对优先级

| 优先级 | 描述 | 应对策略 |
|--------|------|---------|
| 🔴 P0：对手强 + 客户必关心 | 直接威胁 | 必须有正面应答（诚实承认 + 替代方案 + 客户案例）|
| 🟡 P1：对手中 + 客户中关心 | 比较项 | 维度重构话术（换比较维度）|
| 🟢 P2：对手弱 + 客户必关心 | 我方机会 | 主动放大（量化对比 + 客户证据）|

## 四、对手分类作战策略

### 4.1 按对手类型

| 对手类型 | 例子 | 应对核心 |
|---------|------|---------|
| **国际大厂** | Microsoft / Cisco / Splunk | 强调本地化 / 国产化 / 服务深度 / 价格 |
| **国内大厂** | 阿里 / 腾讯 / 华为 | 强调垂直专注 / 灵活定制 / 服务个性化 |
| **垂直领先** | 行业第一玩家 | 强调差异化角度 + 总成本 + 服务创新 |
| **创业公司** | 同我方规模或更小 | 强调团队稳定 / 客户案例数 / 持续投入 |
| **开源方案** | 自建 / 社区版 | 强调 TCO（不止 License）+ 服务 + 风险 |
| **替代品类** | 客户用别的方法解决 | 强调本品类的根本优势 + 升级路径 |

### 4.2 按客户决策心理

| 客户类型 | 心理 | Battle Card 重点 |
|---------|------|----------------|
| 老客户对手 / 不满意 | 想换但怕迁移成本 | 给"无痛迁移"方案 + 历史共存案例 |
| 同行用对手 / 跟风 | 不想踩坑 | 给"我们超越同行"案例 + 同业 Champion 引荐 |
| 试用过对手 / 失败 | 谨慎 | 直接讨论"为什么这次会成功"+ 量化指标 |
| 招标 / 多家竞标 | 看综合 | 强调差异化 + 评分项逐项引导 |

## 五、Battle Card 季度迭代 SOP

```
每季度（每 90 天）：
  1. 收集前线情报
     □ 销售 win/loss 复盘记录
     □ 客户原话引用（"我之前用 X 觉得……"）
     □ 行业群 / 圈内消息
     □ 对手公开动作（新功能 / 新客户 / 高管变动）

  2. 数据更新
     □ 对手最新报价（通过第三方 / 客户透露）
     □ 对手最新功能（官网 + 公众号）
     □ 我方新案例（同行业 / 同规模）
     □ 公开 benchmark / 第三方报告

  3. 内部 review
     □ 销售团队反馈（话术哪条管用 / 哪条没人用）
     □ 售前团队反馈（技术对比哪些被挑战）
     □ 客户成功反馈（已签客户对对手的复盘）

  4. 版本发布
     □ 新版 Battle Card 培训销售（30 分钟）
     □ 内部 Wiki / Notion 更新
     □ 旧版归档（保留时间线）
```

## 六、Battle Card 维护清单（典型 SaaS / B2B）

```
Tier 1 对手（必维护，每季度更新）：
  □ 国际大厂 1-2 家
  □ 国内同类领头 2-3 家
  □ 总计 3-5 张 Battle Card

Tier 2 对手（按需维护，每年更新）：
  □ 区域 / 行业垂直对手
  □ 替代方案（开源 / 自建）
  □ 总计 5-10 张

Tier 3（一次性，遇单制作）：
  □ 客户特定提及的本地厂商 / 集成商
  □ 历史方案延续 / 客户内部部门方案
```

## 七、Battle Card 一页纸示例（脱敏）

```
═══════════════════════════════════════════════════
[对手 X] | Battle Card v2.3 | 2026-Q2
═══════════════════════════════════════════════════

🎯 对手定位
  日志聚合 + SIEM，主打大企业 SOC，国际化背景。

⚔️ 我方三大杀手锏
  1. 国产化：信创全栈认证，对手无（金融/政府刚需）
  2. AI 能力：告警归并 + 智能调查，准确率高 30pp
  3. 服务深度：本地化驻场 + 4 小时响应（对手 24 小时）

⚠️ 我方三个雷区
  1. 大数据规模（PB 级）：对手成熟，我方刚补齐
     → 应对："您当前 [数据规模] 我方完全覆盖。如果未来到 PB
            级，我们已与 [大数据厂] 集成方案验证过。"
  2. 国际客户案例：对手 500+，我方 20+
     → 应对："国内同行业头部 [3 家客户名] 都在用我们。"
  3. 生态完整度：对手插件 1000+，我方 100+
     → 应对："我方 100+ 都是国内主流，您实际用的 [清单]
            都覆盖。海外集成有需要可定制。"

💰 价格锚点
  对手报价：约 80-120 万 / 年（按数据量）
  我方报价：50-80 万 / 年（推荐版） + 免国产化适配费
  谈判要点：对方含强制 3 年合同，我方支持年签灵活

🎤 客户问"为什么不用 [对手]"
  "[对手] 在国际市场确实是头部。对您 [客户行业] 客户来说，
   有两个差异点值得评估：第一是国产化，等保三级和信创认证
   是刚性需求，[对手] 在国内审批周期通常要 6-12 个月。
   第二是服务深度，您 SOC 团队现在 [N] 人，需要的不是工具
   而是 [合作伙伴]。我们可以提供 [具体服务包]。
   要不安排我们的同行业客户 [客户名] 跟您交流一下？"

🚨 内部提示
  - 对手 2025-12 在国内有家城商行项目失败（数据兼容问题）
  - 对手销售在 [行业] 主推捆绑包，可借此拆单
  - 对手 SE 团队规模有限，复杂方案响应慢
═══════════════════════════════════════════════════
```

## 八、与其他 Skill 的边界

| 选择 | 用前者 | 用后者 |
|------|-------|-------|
| `battle-card` vs `market-research` | 一页纸销售弹药 | 几千字深度报告 |
| `battle-card` vs `sales-guide-writer` | 对手专项作战卡 | 销售一页禅（产品总体）|
| `battle-card` vs `win-loss-analysis` | 实时应对（赛前）| 复盘学习（赛后）|
| `battle-card` vs `gtm-strategy` | 销售前线弹药 | 整体上市战略 |
