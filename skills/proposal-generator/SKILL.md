# Proposal Generator — 企业方案撰写知识库

> 整合来源：小红书「工作｜mark一下常用方案模板」系列（6张图）  
> 覆盖三大方案类型，适用于政府/央企/国企/大型企业项目投标与交付场景

---

## 一、三大方案类型速查

| 类型 | 适用阶段 | 核心目的 | 典型篇幅 |
|------|---------|---------|---------|
| 售前解决方案 | 商机响应/投标 | 赢得客户信任，获取订单 | 20-50页 |
| 可行性研究报告 | 立项决策 | 论证项目可行性，支撑决策 | 50-100页 |
| 初步设计方案 | 项目启动前 | 明确技术路线与建设内容 | 80-150页 |

---

## 二、售前解决方案

### 标准目录结构
```
1. 方案概述
   1.1 项目背景
   1.2 建设目标
   1.3 方案亮点（Executive Summary）

2. 需求分析
   2.1 业务需求
   2.2 功能需求
   2.3 非功能需求（性能/安全/可靠性）
   2.4 痛点与挑战

3. 建设方案
   3.1 总体架构设计
   3.2 功能模块说明
   3.3 技术选型与说明
   3.4 与现有系统集成方案

4. 预期成果
   4.1 交付物清单
   4.2 业务价值量化
   4.3 成功案例参考

5. 实施计划
   5.1 项目里程碑
   5.2 实施阶段划分
   5.3 资源投入计划

6. 建设成效
   6.1 预期效益（定量+定性）
   6.2 ROI 分析
   6.3 风险控制措施

7. 报价单
   7.1 产品/服务清单
   7.2 费用明细
   7.3 付款方式建议
```

### 撰写要点
```
- 开篇必须体现"懂客户"：引用客户行业政策/痛点/竞争压力
- 架构图是核心：总体架构 + 功能架构 + 部署架构三图必备
- 量化价值：用数字说话（节省X%人力/提升X%效率/降低X%成本）
- 案例背书：同行业/同规模客户成功案例，增强可信度
- 报价策略：总价突出，明细清晰，可选项分开列
```

## 三、可行性研究报告

### 标准目录结构
```
第一章 项目概述
  1.1 项目背景与必要性
  1.2 项目建设目标
  1.3 建设原则
  1.4 建设依据（政策/标准/规范）

第二章 现状分析与需求分析
  2.1 现状描述
  2.2 存在问题与差距分析
  2.3 业务需求分析
  2.4 功能需求分析
  2.5 非功能需求分析

第三章 建设内容
  3.1 总体建设内容
  3.2 各子系统/模块说明
  3.3 数据资源建设
  3.4 基础设施建设

第四章 技术方案
  4.1 总体技术架构
  4.2 关键技术选型
  4.3 安全保障方案
  4.4 运维保障方案

第五章 项目组织实施方案
  5.1 组织架构
  5.2 实施策略
  5.3 实施计划（甘特图）
  5.4 质量保障措施

第六章 成本预算分析
  6.1 投资估算
  6.2 资金来源
  6.3 成本构成明细

第七章 效益分析
  7.1 经济效益分析
  7.2 社会效益分析
  7.3 投资回收期测算

第八章 风险分析
  8.1 主要风险识别
  8.2 风险应对措施

第九章 结论与建议
  9.1 可行性结论
  9.2 建议事项
```

### 撰写要点
```
- 必要性论证：政策依据 + 现状差距 + 不建设的代价
- 技术可行性：成熟技术优先，新技术需有验证案例
- 经济可行性：量化效益必须有测算依据，不能拍脑袋
- 风险章节：识别3-5个主要风险，每个风险配对应措施
- 结论要明确：直接给出"可行/不可行"判断，不模糊
```

## 四、初步设计方案

### 标准目录结构
```
第一章 项目概况
  1.1 项目背景
  1.2 设计依据
  1.3 设计范围
  1.4 设计原则

第二章 总体设计
  2.1 总体架构设计
  2.2 技术路线选择
  2.3 标准规范体系

第三章 项目设计方案（核心章节）
  3.1 功能架构设计
  3.2 数据架构设计
  3.3 应用架构设计
  3.4 技术架构设计
  3.5 安全架构设计
  3.6 部署架构设计

第四章 建设方案
  4.1 软件建设方案
  4.2 硬件建设方案
  4.3 网络建设方案
  4.4 数据迁移方案

第五章 项目实施方案
  5.1 实施策略
  5.2 实施阶段划分
  5.3 各阶段工作内容
  5.4 实施进度计划

第六章 招标方案
  6.1 招标范围
  6.2 招标方式
  6.3 评标标准

第七章 项目管理方案
  7.1 项目管理组织
  7.2 项目管理流程
  7.3 变更管理
  7.4 质量管理

第八章 人员配置与培训
  8.1 人员配置方案
  8.2 培训计划

第九章 项目实施进度
  9.1 总体进度计划
  9.2 里程碑节点
  9.3 甘特图

第十章 初步设计概算
  10.1 概算编制说明
  10.2 概算汇总表
  10.3 分项概算明细

第十一章 风险及效益分析
  11.1 风险识别与评估
  11.2 风险应对策略
  11.3 预期效益分析
```

### 撰写要点
```
- 架构设计是核心：六大架构（功能/数据/应用/技术/安全/部署）缺一不可
- 概算要有依据：参照市场价/定额标准，分项列清楚
- 招标方案：明确招标范围和评标权重，避免后期争议
- 进度计划：甘特图必备，关键路径要标注
- 人员配置：项目经理/技术负责人/实施工程师角色清晰
```

## 五、通用写作规范

### 文档质量标准
```
结构层面：
  ✓ 目录层级不超过三级（章-节-条）
  ✓ 每章有引言段，说明本章内容和与上下章的关系
  ✓ 图表编号规范（图X-X、表X-X）
  ✓ 关键内容有图示（架构图/流程图/甘特图）

内容层面：
  ✓ 需求有来源（访谈/调研/政策文件）
  ✓ 技术选型有对比（至少2-3个方案对比后选定）
  ✓ 数据有出处（不写"大幅提升"，写"提升30%"）
  ✓ 风险有应对（每个风险对应具体措施）

表达层面：
  ✓ 专业术语统一（全文一致）
  ✓ 避免口语化表达
  ✓ 主动语态为主
  ✓ 段落不超过200字
```

### 常用图表类型
```
架构图：总体架构图、功能架构图、技术架构图、部署架构图
流程图：业务流程图、数据流程图、实施流程图
计划图：甘特图、里程碑图、WBS分解图
分析图：现状对比图、效益分析图、风险矩阵图
表格：需求清单、功能矩阵、报价单、人员配置表
```

## 六、行业定制化要点

### 政府/公共事业
```
- 必须引用：国家政策文件（数字中国/新基建/行业专项规划）
- 强调：合规性、安全性、国产化替代
- 采购方式：政府采购法/招投标法框架
- 效益重点：社会效益 > 经济效益
```

### 金融行业
```
- 必须引用：银保监/证监会相关监管要求
- 强调：数据安全、灾备方案、等保合规
- 效益重点：风控能力提升、合规成本降低
```

### 制造业
```
- 强调：与现有 ERP/MES/SCADA 系统集成
- 效益重点：生产效率、良品率、设备利用率
- 实施重点：不影响生产连续性的上线方案
```

### SaaS/互联网企业
```
- 强调：云原生架构、弹性扩展、DevOps
- 效益重点：研发效率、用户体验、运营成本
- 交付方式：敏捷迭代，分期上线
```
