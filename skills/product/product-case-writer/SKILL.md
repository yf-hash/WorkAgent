# 产品成功案例写作知识库

> 单一文档类型 | 受众：销售场景 / 合规验证 | 密级：可公开（脱敏后） | 篇幅：3-8 页 / 800-1500 字

---

## 核心原则

1. **STAR 结构强制**：背景（Situation）→ 挑战（Task）→ 方案（Action）→ 成果（Result），缺一不可
2. **量化优先**：每个收益点必须可量化，禁用"显著提升"、"大幅改善"等空话
3. **授权审慎**：未授权前默认脱敏，授权范围细化到"是否能公开客户名 / 数据 / 截图"
4. **证言可信**：客户证言要有具体职务（脱敏后用"客户技术负责人"等），禁止编造引语

---

## 标准结构模板（STAR）

```markdown
# [产品名] 在 [客户名 或 行业描述] 的成功实践

**编制日期**：YYYY-MM-DD | **客户授权状态**：[已授权全文 / 已授权脱敏 / 待授权]
**版权**：©[起始年]-[当前年份] [公司名称] 保留所有权利

---

## 一、客户背景（Situation，200-300 字）
- 客户规模（员工数 / 营收 / 用户量等）
- 所属行业及业务定位
- 数字化建设现状
- 与本案例相关的业务背景

## 二、面临挑战（Task，200-300 字）
- 具体业务痛点（要列出 2-4 个）
- 已尝试过的解决方案及失败原因（可选）
- 风险事件 / 合规压力 / 业务影响

## 三、解决方案（Action，300-500 字）
- 部署的 [产品名] 模块清单
- 部署架构图（建议附图）
- 实施周期与关键里程碑
- 关键技术决策（为什么这样做）

## 四、实施成果（Result，200-400 字，**强制量化**）
| 指标维度 | 实施前 | 实施后 | 变化 |
|---------|-------|-------|------|
| [业务指标 1] | X | Y | ↑Z% |
| [业务指标 2] | X | Y | ↑Z% |
| [合规指标] | 未通过 | 通过 XX 认证 | — |

## 五、客户证言（1-2 句话）
> "[具体引述]"
> —— [客户职务，如：客户信息安全负责人]

## 六、后续合作（可选）
- 后续扩展计划
- 推荐方向
```

## 量化收益示例库

| 维度 | 可量化指标 |
|------|----------|
| 安全类 | 拦截 X 次攻击 / 漏洞修复时间从 X 小时降到 Y 分钟 / 通过 XX 等保 / 国密认证 |
| 运维类 | 节省 X 人力 / 故障定位时间从 X 小时降到 Y 分钟 / 自动化覆盖率从 X% 到 Y% |
| 业务类 | 转化率提升 X% / 用户响应时间从 X ms 降到 Y ms / 业务连续性达到 SLA Z% |
| 成本类 | 降低 X% 硬件成本 / 节省 X 万元 / 投资回收期 Y 个月 |
| 合规类 | 通过 [具体认证名] / 满足 [具体法规] / 审计通过率提升 X% |

## 脱敏规范

| 脱敏对象 | 处理方式 |
|---------|---------|
| 客户名称 | "某 [行业] [规模] 客户"，如"某城商行"、"某三甲医院" |
| 业务规模 | 用区间替代精确数字，如"百万级用户"代替"320 万用户" |
| 地理位置 | "华东某省会城市"、"西南地区" |
| 系统名称 | 用类型描述，如"核心交易系统"、"OA 系统" |
| 截图 | 打码品牌 Logo / 真实数据 / 用户信息 |

---

## 命名与密级

- **文件名**（具名）：`[产品名]_[客户名]_成功案例_v1.0.docx`
- **文件名**（脱敏）：`[产品名]_[行业]_成功案例_v1.0.docx`
- **密级**：可公开（脱敏后），未脱敏版标记为"内部资料"
- **授权追踪**：每个案例需配套客户授权书归档

---

## 常见质量问题

| 问题 | 修复 |
|------|------|
| 收益描述空泛（"显著提升"） | 强制要求列出实施前后对比数据表 |
| 缺乏挑战描述，跳到方案 | 补充 Task 段落，至少列 2 个痛点 |
| 客户证言像广告词 | 改为具体场景描述 + 职务，避免"非常满意"类用语 |
| 截图未脱敏 | 打码品牌、数据、用户名 |
| 案例发布无客户授权 | 走客户授权流程或改为完全脱敏 |

## 与相邻文档的区别

| 文档 | 用途 | 篇幅 | 是否可对外发布 |
|------|------|------|--------------|
| **成功案例（本 Skill）** | 销售场景 / 公开宣传 | 3-8 页 | 是（脱敏后） |
| 内部赢单分析 | 内部复盘 / 销售方法论沉淀 | 5-15 页 | 否（由 `/win-loss` 命令产出） |
| 解决方案中的案例 | 方案文档章节，简略版 | 0.5-1 页 | 跟随方案密级 |
| 白皮书中的案例 | 白皮书章节，摘要版 | 0.5-1 页 | 是 |
