# 技术白皮书写作知识库

> 单一文档类型 | 受众：技术专家 / 架构师 | 密级：**内部保密** | 篇幅：≥30 页

---

## 核心原则

1. **深度优先**：与产品白皮书的差异是"为什么这样做"——必须包含算法原理、设计权衡、性能调优
2. **内部保密**：包含未公开的核心实现细节、技术 KPI，未授权不得外发
3. **可复现**：性能数据需注明硬件配置、测试方法、压测工具
4. **同步研发**：技术细节需研发团队核实，禁止臆造架构图

## 质量要求

| 维度 | 标准 |
|------|------|
| 篇幅 | ≥30 页 |
| 图表 | 至少 8 张：分层架构、数据流、关键时序、状态机、性能曲线 |
| 算法 | 至少 2 个核心算法的伪代码或形式化描述 |
| 性能数据 | 必须注明测试环境、压测工具、并发模型 |
| 安全 | 必须含威胁模型章节 |
| 准确性 | 关键技术细节需研发评审签字 |

## 与相邻文档的区别

| 文档 | 受众 | 密级 | 深度 |
|------|------|------|------|
| **技术白皮书（本 Skill）** | 技术专家 / 核心客户研发 | 内部保密 | 算法 + 实现 + 优化 |
| 产品白皮书 | 技术决策层 | 可公开 | 是什么 + 怎么做（不含实现） |
| 产品介绍-技术版 PPT | 技术决策层演讲 | 可公开 | 架构图 + 关键卖点 |
| 部署及配置手册 | 实施工程师 | 可公开 | 安装步骤 + 配置参数 |
