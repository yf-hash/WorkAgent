# Win/Loss Analysis Skill

## 核心目标

把销售的"赢"和"丢"，转化为：
1. **产品反馈**：客户为什么真选 / 不选我们
2. **定价反馈**：价格是不是真原因
3. **营销反馈**：客户从哪里听说我们，认知是不是错位
4. **销售流程反馈**：哪个环节让客户掉头
5. **ICP（理想客户画像）修正**：我们其实在赢哪类客户、输哪类

## 何时做

- **季度必做**：每季度 1 次系统分析
- **重要客户立做**：单 ARR > 50 万的 Deal 无论输赢
- **趋势异常立做**：连续 3 单输给同一竞品 / 3 单输在同一原因

## 样本设计

### 输赢比例

每次分析至少访谈：
- 5-10 个 **Won Deal**（含 2-3 个流失风险高的）
- 5-10 个 **Lost Deal**（含 2-3 个失给同一竞品的）
- 3-5 个 **No Decision**（客户最终没决定 — 这类最被忽视但最关键）

### 时间窗口

Deal 关闭后 **2-6 周内**访谈最有效：
- 太早：客户还在情绪中
- 太晚：客户记忆模糊

## 访谈结构

### 客户访谈（30 分钟，由**独立第三方**做最好）

**为什么独立？** 客户对销售客气，对中立第三方说真话。

```
1. 背景（5 分钟）
   - 您当时在评估什么场景的解决方案？
   - 决策时间线大概多久？
   - 决策小组有谁？谁拍板？

2. 评估过程（10 分钟）
   - 您评估了哪几家厂商？
   - 各家的"first impression" 是什么？
   - 评估的关键维度是什么？哪些是 must-have，哪些是 nice-to-have？

3. 选择 / 不选择我们（10 分钟）
   - 您最终选择了/没选择我们，最关键的原因是什么？（追问 2-3 层）
   - 我们和最终方案的差距在哪里？
   - 如果重新评估，您会怎么决定？

4. 反馈（5 分钟）
   - 我们的销售/产品/价格/支持哪里做得好？
   - 我们做得不好的地方是什么？
   - 您愿意给我们的产品/团队的一句话建议是什么？
```

### 内部销售访谈（20 分钟）

```
1. Deal 时间线（5 分钟）
   - 您是怎么接到这个 Lead 的？
   - 关键里程碑

2. 客户决策动力（5 分钟）
   - 客户的核心驱动是什么？
   - 内部 Champion 是谁？反对者是谁？
   - 预算从哪来？

3. 输 / 赢分析（10 分钟）
   - 您认为输 / 赢的关键原因是什么？
   - 客户当时说的官方理由 vs 您觉得的真实理由
   - 我们少做了什么 / 多做了什么？
```

## 根因聚类（10 大常见原因）

把所有访谈聚类到这 10 类，看分布：

| # | 原因类别 | 典型描述 |
|---|---------|---------|
| 1 | 产品功能不够 | 缺核心功能 / 性能不达标 |
| 2 | 价格 | 贵 / 计价模型不合适 |
| 3 | 集成能力 | 不支持客户已有系统 |
| 4 | 安全合规 | 缺证书 / 私有化弱 |
| 5 | 品牌信任 | 客户没听说过 / 同行没用过 |
| 6 | 销售体验 | 跟进慢 / 没听懂需求 / 没接住反对意见 |
| 7 | 演示 / PoC 体验 | Demo 不打动 / PoC 出问题 |
| 8 | 合同条款 | 不接受我方标准条款 |
| 9 | 内部决策延迟 | 客户内部预算没批 / 决策人变化 |
| 10 | 时机 | 客户当前不紧迫 / 项目延后 |

> 注意区分：**官方理由（客户说的）vs 真实理由（销售判断 + 客户访谈后推断）**。这两个往往不同。

## 关键技巧

### 客户访谈的高质量问题

- ❌ "我们做得好吗？" → 客气话
- ✅ "如果重新评估，您会怎么决定？" → 真实判断
- ❌ "你最看重什么功能？" → Bias
- ✅ "您评估时排除了谁？为什么？" → 真实排序
- ❌ "价格贵吗？" → 总会被说贵
- ✅ "如果我们价格便宜 30%，您会选我们吗？" → 测试价格是不是真原因

### "No Decision" 是金矿

客户最终没决定本身是结果：
- 内部没共识 → 我们没帮 Champion 说服反对者
- 预算不足 → 我们没找到正确预算线
- 时机不对 → 我们没识别客户真实紧迫度

这类客户**未来更可能复活**。建立 No Decision 名单，6 个月后主动复盘。

## 反模式

- ❌ **销售自己分析**：销售为自己的 Deal 辩护
- ❌ **只看输单不看赢单**：你不知道自己为啥赢就不知道怎么复制
- ❌ **只统计不访谈**：CRM 数据是销售填的，反映不了真相
- ❌ **没有 Action Items**：分析报告变成"汇报材料"
- ❌ **不跟踪改进效果**：发了报告就完事 → 下季度同样问题重现
