# Prd Proto — 线框图 + PRD 融合

> 单一职责：生成 PRD 文档中"长什么样、怎么交互"的章节（ASCII 线框图 + 状态标注）。
> 不做：PRD 主文档（→ `prd-standard` 或 `prd-spec-first`）、字段验证规则（→ `prd-standard`）

## 核心理念

```
线框图 回答："长什么样？用户怎么操作？"
PRD    回答："为什么这样做？做到什么程度？怎么验收？"

融合工作流：线框图让 PRD 功能规格更具体；PRD 让线框图设计决策有依据。
```

## 线框图必须覆盖的状态

```
✅ 必须覆盖（每个核心页面）
  1. 默认态   — 有正常数据时的展示
  2. 空态     — 无数据/首次使用时的引导
  3. 加载态   — 数据请求中（骨架屏）
  4. 错误态   — 接口失败/网络异常

✅ 推荐覆盖
  5. 操作反馈态 — 表单提交成功/失败后
  6. 禁用态     — 权限不足/功能不可用时
  7. 移动端     — 如有响应式需求
```

## ASCII 线框图标注规范

```
元素符号：
┌─┐ └─┘ ─── │    容器/卡片/模块边框
[按钮文字]   可点击按钮
{输入内容}   文本输入框（单行）
{多行文本  } 多行文本输入区域
[x] 复选框  Checkbox
(○) 单选框  Radio Button
[下拉▼]    下拉选择器
░░░░░       骨架屏/加载占位
[图片区域]  图片/头像/封面区域

交互标注（写在线框图下方）：
→ [元素] 点击：[发生什么]
→ [元素] 条件显示：[当...时才展示]
→ [字段] 数据来源：[接口/字段名]
→ [文案] 字数上限：[N 字/N 行]
→ [操作] 权限要求：[仅...角色可见]
```

## 标准线框图模板库

### 列表页（带搜索筛选）

```
┌─────────────────────────────────────────────────┐
│  [← 返回]  页面标题            [搜索🔍] [筛选▼]  │
├─────────────────────────────────────────────────┤
│  [全部] [类型 A] [类型 B] [状态:全部▼]            │
│  排序：[最近更新▼]                    共 N 条     │
│  ─────────────────────────────────────────────  │
│  ☐ [记录标题（最多 2 行截断）        ] [状态] [⋮]│
│    副标题/摘要 · 2024-01-01 · 创建人             │
│  ─────────────────────────────────────────────  │
│                    [◀] [1] [2] [3] [...] [▶]   │
└─────────────────────────────────────────────────┘
→ [⋮] 点击：展示下拉菜单（编辑/删除/更多操作）
→ [☐] 点击：多选模式，顶部出现批量操作栏
```

### 创建/编辑弹窗

```
┌────────────────────────────────┐
│  创建[对象名]             [×]  │
│  ─────────────────────────    │
│  名称 *                        │
│  {请输入名称（最多 50 字）  }   │
│                                │
│  描述                          │
│  {请输入描述...             }  │
│  {                     0/200}  │
│                                │
│  类型 *                        │
│  (○) 选项 A  (○) 选项 B       │
│                                │
│  ─────────────────────────    │
│  [取消]              [创建 →]  │
└────────────────────────────────┘
→ [创建 →]：前端验证 → 提交 API → Loading → 成功/失败
→ 成功：关闭弹窗 + Toast"创建成功" + 列表刷新
→ 失败：Toast 错误信息 + 保持弹窗打开
```

### 空态设计规范

```
┌─────────────────────────────────────────────────┐
│              [🎯 主题图标或插图]                  │
│         还没有任何[对象中文名]                   │
│    [对象名]可以帮助你[核心使用价值，15 字内]      │
│           [+ 创建第一个[对象名]]                 │
│  💡 小技巧：[与场景相关的使用建议，20 字内]       │
└─────────────────────────────────────────────────┘
文案原则：积极、引导性（"开始"/"创建"/"探索"）
```

## 线框图元素 → PRD 内容映射

```
线框图元素              PRD 对应内容
──────────────────────────────────────────────
页面/弹窗标题     →  功能模块名称
输入字段 *        →  必填字段 + 字数/格式验证规则
下拉选项          →  枚举值定义 + 允许值范围
按钮              →  用户操作（When）+ 系统响应（Then）
状态标签          →  状态流转定义 + 各状态含义
列表展示字段      →  数据字段 + 排序规则 + 截断规则
空态              →  空状态定义 + 引导策略 + 引导文案
错误提示位置      →  错误类型分类 + 每类错误的展示文案
分页              →  分页规格（每页 N 条/总数/翻页逻辑）
加载骨架屏        →  最大等待时间 + 超时处理
```

## 保真度提升路径

```
阶段 1：低保真（分钟级）— ASCII 草图，验证信息架构和页面流程
阶段 2：中保真（小时级）— ASCII 精细图，含所有状态/文案/组件标注（默认产出）
阶段 3：高保真（天级）  — Penpot / Figma 像素级设计稿
阶段 4：代码原型（周级）— Next.js + Framer Motion 真实交互
```

## 与其他 PRD 模式的衔接

- 线框图产物嵌入 `prd-standard` 的"功能规格"章节
- 嵌入 `prd-spec-first` 的 `design.md` 文件
- 完成后做交互完备性检查可用 `prd-quality-check`
