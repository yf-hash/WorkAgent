# Sunset / Deprecation Playbook

> "做减法比做加法难。做减法做得有尊严，是 PM 的核心修养。"

## 何时考虑下线

| 信号 | 阈值 |
|------|------|
| 月活跃用户 | 连续 6 个月 < N（按产品定 N） |
| 收入贡献 | < 1% 总收入且持续下滑 |
| 维护成本 | > 收入 |
| 技术债 | 阻塞核心产品演进 |
| 战略偏移 | 不再属于核心战略 |
| 合规风险 | 维护不再划算 vs 合规风险 |

**至少 2 个信号同时触发 → 启动下线评估**。

## 下线评估（决策前）

### 1. 利益相关方影响盘点

| 干系人 | 数量 | 影响程度 | 替代方案 |
|--------|------|----------|----------|
| 客户（付费） | | 高 / 中 / 低 | |
| 客户（免费） | | | |
| 内部团队 | | | |
| 合作伙伴 | | | |
| 监管 / 合规 | | | |
| 投资人 / 媒体 | | | |

### 2. 替代方案分析

对每个客户群体，必须给出：
- **替代产品**：自家 / 第三方 / 自建
- **迁移路径**：数据 / 配置 / 工作流
- **迁移成本**：客户付出 / 我们承担
- **替代体验差距**：哪些功能没了

### 3. 合约 / 法务 / 合规审查

- [ ] 合约最早可解约日期
- [ ] 是否需要提前通知（通常 90 天 / 180 天）
- [ ] SLA 是否承诺了长期支持
- [ ] 数据保留义务（金融行业可能 N 年）
- [ ] GDPR / 个保法的数据删除合规

### 4. 财务影响

| 项目 | 当前 | 下线后 |
|------|------|--------|
| 营收 | | -X |
| 成本 | | -Y |
| 净影响 | | Y-X |
| 迁移成本（一次性）| | |
| 客户流失成本 | | |

## 决策矩阵

```
                影响客户多      影响客户少
              ┌──────────────┬──────────────┐
   营收贡献高 │ Stay / 投资    │ Stay 但限缩  │
              │ 提升盈利能力    │              │
              ├──────────────┼──────────────┤
   营收贡献低 │ Migrate（迁移） │ Sunset（下线）│
              │ 把客户搬到新产品│              │
              └──────────────┴──────────────┘
```

## 下线节奏（90/60/30/0 天）

### T-90 天：宣布下线

- 内部沟通先于外部（管理层 → 销售 → CSM → 客户）
- 邮件 + 站内通知 + 客户经理 1:1
- 文案口径要诚实：为什么下线 + 替代方案 + 我们怎么帮你迁移
- 高价值客户（VIP）：CSM 主动联系，1:1 迁移计划
- 新增注册 / 销售：**立即停止**

### T-60 天：迁移工具就绪

- 数据导出工具上线（自助 + 工单两种通道）
- 迁移文档发布
- 客户答疑会（Office Hour 每周 2 次）
- 销售 / CSM 培训完成

### T-30 天：最后冲刺

- 二次提醒邮件
- 未迁移客户名单 → CSM 主动外呼
- 媒体 / 公开声明（如果是公共产品）
- 内部团队转移：研发资源回收，记录技术债

### T-0：正式下线

- API 返回 410 Gone（不是 404）
- UI 显示停服公告 + 替代方案
- 数据留存 N 天（按合规要求）

### T+30 / T+90 / T+180：数据清理

- T+30：暂停账号，保留数据
- T+90：导出客户数据机会窗口结束
- T+180：数据删除（含备份）+ 删除证明发送给客户

## 内部团队转移

- 工程师：明确去向（哪个新项目 / 哪个团队），不留悬念
- 文档归档：技术文档迁移到只读知识库
- 客户数据归档：合规要求保留多久就保留多久，存储到冷存储
- 复盘：T+30 做 Post-Mortem（什么时候应该更早决定？哪些信号被忽略？）

## 反模式（不要做）

- ❌ **静悄悄下线**：客户某天发现服务不可用 → 信任崩塌
- ❌ **甩锅式公告**："因业务调整" → 客户最讨厌的话术
- ❌ **不提供迁移路径**：等于把客户送给竞品
- ❌ **不提前与客户成功 / 销售沟通**：他们最后一秒知道，无法做客户挽留
- ❌ **过早删除数据**：客户因此投诉甚至诉讼
- ❌ **节奏太急**：90 天底线，重大产品 180 天
