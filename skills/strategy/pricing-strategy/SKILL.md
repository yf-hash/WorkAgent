# Pricing Strategy — 定价策略知识库

把"价格定多少"从拍脑袋变成基于价值、用户、竞争和数据的科学决策。

---

# 一、定价的"五维框架"

任何定价决策都需要回答这五个问题：

```
1. 用户感知价值多少？      → Value-based
2. 我们的成本是多少？       → Cost-based
3. 竞争对手定多少？         → Competition-based
4. 用户什么心理价位？       → Psychological / PSM
5. 不同情境定多少？         → Dynamic / Context-based
```

健康的定价 ≠ 用一种方法，而是五维交叉验证。

---

# 二、五大定价方法对比

| 方法 | 思路 | 适合 | 风险 |
|------|------|------|------|
| **成本加成** | 成本 + 利润率 | 制造业、初期 | 低估价值、不利润最大化 |
| **竞争对标** | 比竞品贵 X% / 便宜 Y% | 同质化市场 | 沦为价格战 |
| **价值定价** | 按用户感知价值定 | SaaS / 创新产品 | 难量化价值 |
| **心理定价** | $99 比 $100 感觉低很多 | C 端 | 显眼时反而不信 |
| **动态定价** | 按时间/库存/用户类型变 | 出行 / 电商 | 用户感觉被歧视 |

# 三、SaaS 套餐结构

## 3.1 Freemium（免费 + 高级）

```
免费层：
  ✅ 提供长期可用的核心价值
  ✅ 限制：用量 / 协作人数 / 高级功能

付费层：
  - Pro / Team / Enterprise

经典案例：Notion / Slack / Figma / Dropbox
```

**风险**：免费用户成本 vs 付费转化率 平衡

## 3.2 Free Trial（限时免费）

```
- 7 / 14 / 30 天免费
- 信用卡可选 / 必填
- 到期自动转付费 vs 主动选择

经典案例：Adobe / Salesforce / Linear
```

**Free Trial vs Freemium 选择**：

| 因素 | Freemium | Free Trial |
|------|----------|------------|
| 价值需要时间感知 | ✅ | ❌ |
| 价值立竿见影 | ❌ | ✅ |
| 网络效应 | ✅ | ❌ |
| 单用户即可获得价值 | ✅ | ✅ |
| Onboarding 复杂 | ❌ | ✅ |

## 3.3 阶梯套餐（Tiered）

```
经典三档：Starter / Pro / Enterprise

设计原则：
  - 中间档最值钱（"Decoy 效应"）
  - 价格差距 2-3x（不能 1.2x，差异感弱）
  - 上档解锁"团队级"或"企业级"能力
```

中档锚定示例：
```
Starter   $9/月    ← 个人
Pro      $29/月    ← 团队，热门 ⭐
Business $99/月    ← 企业，包含全部
```

## 3.4 用量计费（Usage-based）

```
按用量收费：
  - API 调用次数（OpenAI / Twilio）
  - 存储空间（AWS S3）
  - 触达人数（Mailchimp）

混合模式：
  - 包月 + 超量加价
  - 容量阶梯（50K / 200K / 1M）
```

**适合 AI 产品**：成本与用量强相关，用量计费更合理。

## 3.5 一次性付费 + 升级费

```
软件买断：
  - 主版本一次付费
  - 升级到下个主版本再付（或 Update Pass）

经典案例：Sketch / 早期 Affinity / 大量游戏
```

# 四、Van Westendorp PSM（价格敏感度测量）

## 4.1 四个问题

向至少 100-300 名目标用户问：

```
1. At what price would this be a BARGAIN?       (太便宜 / 怀疑质量)
2. At what price would this be CHEAP?           (划算)
3. At what price would this be EXPENSIVE?       (开始犹豫)
4. At what price would this be TOO EXPENSIVE?   (绝对不买)
```

## 4.2 四个交点

```
PMC（最低可接受）    = "Too cheap" 与 "Expensive" 交点
PME（最高可接受）    = "Too expensive" 与 "Cheap" 交点
OPP（最优定价点）    = "Too cheap" 与 "Too expensive" 交点
IDP（最佳价值点）    = "Cheap" 与 "Expensive" 交点

可接受价格区间：[PMC, PME]
推荐定价：OPP 或 IDP（看策略）
```

## 4.3 适合 / 不适合

```
✅ 适合：成熟市场、用户对类似产品有预期
❌ 不适合：完全创新产品（用户无参照系）
```

# 五、Conjoint Analysis（联合分析）

## 5.1 原理

让用户在多个组合中选择，反推每个属性的"权重"：

```
组合 A：基础版 + 5 用户 + 月付 $29
组合 B：高级版 + 3 用户 + 月付 $49
组合 C：基础版 + 10 用户 + 年付 $19/月

→ 哪个最有可能买？
```

通过统计模型（Logit / Choice-based）算出每个特性的边际价值。

## 5.2 工具

```
- Sawtooth Software（专业 Conjoint）
- Qualtrics
- 简化版：Maze / Typeform 自建问卷
```

# 六、心理定价技巧

| 技巧 | 例 | 适合 |
|------|----|----|
| 9 字尾 | $19 vs $20 | C 端、电商 |
| 整数定价 | $20 / $50 | 高端、专业 |
| 锚定效应 | 先看 $99，再看 $29 | 三档套餐设计 |
| 数字小写 | $1,200 写 1200 vs $1.2k | 高客单 |
| 价格对比 | "比一杯咖啡还便宜" | 月费转日费 |
| 失去敏感 | "免费试用，到期可取消" | Onboarding |
| 捆绑组合 | 一份 $39，三份 $89 | SKU 多 |

# 七、定价 A/B 测试

## 7.1 关键挑战

```
⚠️ 不能用同一用户测试两种价格（Equal Pricing 是底线）
⚠️ 老用户涨价容易愤怒，需"老用户保留原价"（Grandfathering）
⚠️ 法务可能限制（某些地区禁止价格歧视）
```

## 7.2 可接受的 A/B 模式

```
1. 新用户分流（按注册日期）
2. 不同地区定价（地理）
3. 付费墙触发位置 A/B
4. 套餐结构 A/B（套餐组合不同）
5. 折扣 A/B（满减 vs 折扣）
6. 文案 A/B（"立即购买" vs "免费试用 14 天"）
```

# 八、涨价策略（Price Increase）

## 8.1 涨价信号

```
✅ NPS 提升、付费用户留存高
✅ 用户主动表达"愿意更付"
✅ 竞品调价、行业整体上涨
✅ 新功能 / 价值提升
✅ 单位经济（CAC vs LTV）压力
```

## 8.2 涨价 SOP

```
T-30：内部决策（涨价幅度 / 影响用户群）
T-21：通知邮件（提前 30 天）
T-14：客服培训
T-7：博客 / 帮助中心更新
T-Day：执行
T+30：监测流失 + 客诉
```

## 8.3 减少抗拒的策略

```
1. 老用户 Grandfathering（保留原价 N 个月或永久）
2. 同时推出新功能 / 新套餐（让用户选择"升级"而非"涨价"）
3. 透明沟通价值变化（量化"为什么涨"）
4. 提供锁定折扣（年付提前锁定）
```

# 九、降价 / 打折机制

## 9.1 折扣类型

| 类型 | 例 | 适合 |
|------|----|----|
| 限时折扣 | 48h 7 折 | 节日 / 促活 |
| 数量折扣 | 买 10 送 2 | 提升客单 |
| 学生 / 非营利 | 50% off | 拓展市场 |
| 年付折扣 | 月 $29 → 年 $290（17% off） | 锁定收入 |
| 推荐返现 | 邀请好友送 $10 | 病毒传播 |
| Win-back | 流失用户 30% off | 召回 |

## 9.2 折扣陷阱

```
❌ 长期折扣 → 用户认为"原价是骗人的"
❌ 折扣后涨价回去 → 客诉激增
❌ 全网撒网 → 把老用户也变低价
```

# 十、单位经济模型（Unit Economics）

```
LTV (Customer Lifetime Value)：
  = 平均月 ARPU × 平均生命周期（月）× 毛利率

CAC (Customer Acquisition Cost)：
  = 总销售营销支出 / 新用户数

健康线：
  LTV / CAC ≥ 3       ← 可持续
  LTV / CAC ≥ 5       ← 健康
  LTV / CAC < 1       ← 亏损扩张

回收周期 (Payback Period)：
  CAC / 月 ARPU 毛利
  应 < 12 个月（消费类）/ < 18 个月（B2B）
```

# 十一、企业级合同定价

```
特点：
  - 一年起 Annual Contract
  - 按用户数 / 公司规模分级
  - 商务谈判空间（牌价 → 实际成交）
  - 包含 SLA / 培训 / 集成服务

谈判技巧：
  - 多年合同换更深折扣（3 年 = -30%）
  - 用户数承诺换折扣（>100 用户 = -20%）
  - 案例授权换折扣（成为标杆案例 = -10%）
  - 永远不主动报最低价（留谈判空间）
```
