# Product Report — 产品报告写作知识库

把"写报告"从形式主义变成可复用的沟通模板。

---

# 一、报告写作的"三个原则"

```
1. 结论先行（Top-down）
   → 30 秒能读完核心；细节在后
   → 不要从背景开始讲 5 段才到结论

2. 受众驱动
   → 高管：数字 + 战略 + 决策点
   → 团队：协作 + 阻塞 + 下一步
   → 客户：价值履约 + 路线图
   → 董事会：商业 + 财务 + 长期方向

3. 行动可追踪
   → 每个汇报周期对应可跟踪的状态
   → 上次报告的 Action 必须在本次跟踪
```

---

# 二、按受众调整内容

| 维度 | Team | Exec | Board | Customer |
|------|------|------|-------|---------|
| 篇幅 | 1 页 | 1-2 页 | 5-10 页 | 3-5 页 |
| 数字密度 | 中 | 高 | 极高 | 中 |
| 技术细节 | 高 | 低 | 极低 | 极低 |
| 策略思考 | 中 | 高 | 极高 | 低 |
| 客户语言 | 内部 | 内部 | 商业 | 客户视角 |
| 决策点 | 协作 | 资源 / 战略 | 重大决策 | 续约 / 扩展 |

---

# 三、周报模板（5+5+5）

```
5 Highlights（亮点）
5 Lowlights / Blockers（挑战 / 阻塞）
5 Next Week（下周聚焦）

+ 关键指标变化
+ 实验进展
+ 需要帮忙
```

**写作要点**：
- 每条 ≤ 1 句
- 用数字而非形容词（✅ "+15%" / ❌ "增长很快"）
- 阻塞要有应对（不只列问题）
- "需要帮忙"必填（让团队帮你）

---

# 四、月报模板（结构化）

```
1. 一句话结论（30 秒读完）
2. 北极星指标 + 输入指标
3. 漏斗健康
4. 关键里程碑（绿/黄/红）
5. 实验复盘
6. 风险与应对
7. 下月计划
8. 需要决策 / 支持
```

**写作要点**：
- 一句话结论是高管唯一会读的部分
- 漏斗用箭头图直观展示
- 风险标"是否升级到您"
- 决策点必有"截止时间"

---

# 五、季度报告模板

```
1. 执行摘要（50 字）
2. OKR 评分（每个 O 的综合分）
3. 北极星 12 周变化曲线
4. 关键交付清单
5. 学习与失败（双列）
6. 下季度规划（O 摘要）
7. 资源诉求
```

**写作要点**：
- 执行摘要必须能独立成立
- OKR 评分用 0.0-1.0
- "学习与失败"是高价值章节，往往被忽略
- 资源诉求要给理由，不给数字

---

# 六、董事会更新模板

董事会关心的"五件事"：

```
1. 增长（北极星 + YoY）
2. 钱（MRR / ARR / Burn / Runway）
3. 用户（留存 / NRR / NPS）
4. 战略（方向是否变）
5. 风险（重大风险 + 应对）
```

**写作要点**：
- 单位经济（LTV / CAC / Payback）必出现
- 战略进展用 3 条主线，不超过 5
- 风险讲"我们做了什么"而非"什么不行"
- 提请决策必明确

---

# 七、客户 Business Review 模板

```
1. 价值履约（按合同/承诺逐条对照）
2. 使用情况（关键模块使用变化）
3. 您的反馈与我们的响应
4. 即将到来（影响客户的路线图）
5. 续约 / 扩展讨论
```

**写作要点**：
- 用客户的视角和语言
- "价值履约"用客户能感知的指标，不是产品视角
- 反馈对照展示"听到 + 已做"
- 续约谈判要在 BR 之前已有铺垫

# 八、坏消息传递

## 8.1 不要

```
❌ 隐瞒到最后一刻
❌ 用模糊语言（"可能" "也许"）
❌ 把问题藏在长篇报告中段
❌ 不给应对方案
```

## 8.2 应该

```
✅ 第一时间私下通知 Stakeholder
✅ 报告中放在显眼位置
✅ 用数字事实
✅ 给出选项 + 推荐方案 + 决策时间
```

## 8.3 模板

```
"风险升级：[问题]

事实：[数字 + 现状]
原因：[根因，不甩锅]
影响：[对用户 / 商业 / 时间表]

我们的选项：
  - A：[方案]，代价 X
  - B：[方案]，代价 Y

我推荐 A，因为 [理由]
需要您 [日期] 前决策"
```

# 九、数字驱动叙事

## 9.1 三层数字结构

```
表层数字：用户能感知的（DAU / 注册 / 转化）
中层数字：业务能感知的（MRR / 留存 / NPS）
底层数字：战略能感知的（LTV / CAC / Payback / Burn Multiple）
```

不同受众看不同层：
- Team → 表层 + 中层
- Exec → 中层 + 底层
- Board → 底层为主

## 9.2 数字四要素

```
1. 当前值
2. 目标值
3. 变化方向（↗️ → ↘️）
4. 同期对比（vs 上周 / 上月 / 同比）
```

不全的数字 = 没数字。
