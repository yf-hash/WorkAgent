# 十六、阶段闸门 Checklist

> 来自 `skills/strategy/gtm-strategy/SKILL.md` 的次要章节，按需 Read。


> 每一阶段必须通过的检查项。AI 输出阶段产物时，末尾必须附上对应阶段的闸门表。
> ✅ = 完成；☐ = 待办。

### 阶段 0 · GTM 准备期闸门

```
□ ICP 客户画像（行业 / 规模 / 角色 / 预算 / 采购路径）≥ 1 个主 ICP
□ 核心场景清单 ≥ 3 个，每个场景有"用前 vs 用后"对比
□ 客户痛点地图（成本 / 风险 / 效率 / 合规 4 类）
□ 竞品对比表（≥ 3 家直接竞品，含功能 / 价格 / 客户 / 差异点）
□ 一句话定位（电梯演讲版，≤ 30 字）
□ 3 个核心卖点（不是 3 个功能，而是 3 个客户价值）
□ 六大核心问题已回答（谁最痛 / 谁有预算 / 谁有采购权 / 谁最容易做样板 / 比竞品强在哪 / 客户为什么现在必须行动）
```

### 阶段 1 · 产品包装期闸门

```
□ 产品官网页（首屏一句话定位 + 3 个核心卖点 + 客户 Logo + CTA）
□ 产品介绍 PPT（10-15 页，按"行业趋势 → 痛点 → 方案 → 架构 → 功能 → 场景 → 价值 → 部署 → 案例 → 商务"）
□ 行业解决方案 PPT（按 ≥ 2 个重点行业各做一版）
□ 技术白皮书（含架构图 / 数据流 / 安全合规 / 部署方案）
□ Demo 视频（3-5 分钟）+ Demo 脚本（销售可独立讲）
□ 客户 FAQ（≥ 20 条，覆盖产品 / 技术 / 商务 / 合规 / 实施）
□ 报价单（SaaS / 私有化 / 订阅 / 项目制 ≥ 2 种形态）
□ 合同模板（法务已评审）
□ 销售独立讲完一次 PPT，得到团队认可
```

### 阶段 2 · 内测样板期闸门

```
□ 种子客户名单 ≥ 5 家（行业 / 规模 / 联系人 / 状态）
□ POC 标准方案（每个 POC 开始前书面化）
□ POC 验收标准（场景 / 数据 / 周期 / 验收人 / 成功标准 / 后续动作 6 项齐全）
□ POC 完成 ≥ 3 家
□ ≥ 1 家客户愿意对外背书（公开 Logo / 案例 / 站台）
□ 客户反馈记录（每家 ≥ 5 条）
□ 销售反对意见库 ≥ 15 条
□ 样板案例初稿（含数据 / 前后对比 / 客户原话）
□ 产品优化清单（从反馈中提炼，已进 Roadmap）
```

### 阶段 3 · 正式发布期闸门

```
□ 8 件最小物料全部上线（长文 / 海报 / 官网页 / Demo 视频 / 销售 PPT / 白皮书 / FAQ / 预约表单）
□ 线索承接机制就位（表单 / CRM 字段 / 责任人 / 跟进时效 ≤ 24h）
□ 销售话术统一（所有销售用同一套 PPT 和讲解逻辑）
□ 渠道伙伴同步转发计划已对齐（合作伙伴 / KOL / 行业群）
□ 高管背书素材就位（创始人寄语 / 专家推荐 / 客户证言）
□ 发布期媒体计划（公众号 / 行业媒体 / 自媒体）
□ 发布数据监测仪表盘（PV / 表单数 / 预约 Demo 数）
```

### 阶段 4 · 销售转化期闸门

```
□ 商机漏斗 A/B/C 分级（每个商机有阶段、金额、责任人、下一步）
□ A 类商机覆盖率 ≥ X%（X 视目标而定）
□ 每个 A 类商机有 Champion + 已见过 Economic Buyer
□ MEDDIC（或 BANT）资格卡填齐
□ 客户决策链图谱（6 角色已识别）
□ 定制方案库（按客户场景模板化）
□ 报价单已发出 ≥ N 份
□ POC 推进有节奏（避免无限试用）
□ 首批合同已签 + 回款已到账
□ 销售周期可预测（含每阶段平均天数）
```

### 阶段 5 · 规模化增长期闸门

```
□ 标准方案包 ≥ 2 个（60% 项目可复用）
□ 行业打法（2-3 个重点行业，含 ICP / 痛点 / 方案 / 案例 / 话术 / 报价）
□ 渠道政策（集成商 / 代理商 / 生态伙伴）+ 渠道贡献占比 ≥ 20%
□ 客户成功 SOP（健康度监测 / 续费提醒 / 扩容机会 / 转介绍）
□ NRR ≥ 110%（净收入留存）
□ 产品 Roadmap（按客户反馈优先级，季度更新）
□ GTM 季度复盘报告（线索 / 商机 / 转化 / 客单价 / 回款 / 留存）
□ 新销售上手时间 ≤ 4 周（培训体系完善）
```
