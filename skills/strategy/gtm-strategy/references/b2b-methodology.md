# 十三、B2B 销售方法论

> 来自 `skills/strategy/gtm-strategy/SKILL.md` 的次要章节，按需 Read。


> 阶段 4 销售转化期的核心是：用结构化方法识别"哪个商机能成、哪个商机假象、哪个还没到时候"。
> 主流方法论：MEDDIC（最严格）、BANT（最经典）、SPIN（最对话化）。

### MEDDIC — 大客户高客单的资格框架

> 适用：客单价 ≥ 50 万、决策链 ≥ 3 人、销售周期 ≥ 3 个月。
> 由 PTC 在 1990s 提出，被 Salesforce、Snowflake、Cohesity 广泛采用。

| 字母 | 含义 | 售前必须问出的事 |
|------|------|----------------|
| **M**etrics | 量化指标 | 客户用什么数字衡量成功？省多少时间/钱/人？提升多少效率/质量？ |
| **E**conomic Buyer | 经济决策人 | 谁最终拍板批预算？这个人见过没？他的关注点是什么？ |
| **D**ecision Criteria | 决策标准 | 客户内部的评分表里有哪些必选项、加分项？谁定的？ |
| **D**ecision Process | 决策流程 | 从 POC → 评估 → 立项 → 招采 → 合同 → 付款，每一步谁参与？多久？ |
| **I**dentify Pain | 痛点确认 | 现在的痛是真的痛还是"听起来很痛"？不解决会怎样？老板知道吗？ |
| **C**hampion | 内部拥护者 | 客户内部有没有人会主动帮我们卖？他为什么愿意帮？他有影响力吗？ |

**MEDDIC 资格卡模板**：每个 A 类商机都建一张，售前 + 销售共同填写、每周更新。
缺任意一项都标黄；缺 EB 或 Champion 直接降级到 B 类。

### MEDDPICC — MEDDIC 的扩展版（加入 P 和 C）

| 新增字母 | 含义 |
|--------|------|
| **P**aper Process | 法务 / 采购 / 合同的具体流程（特别适合央国企招投标） |
| **C**ompetition | 内部还有哪些竞争对手？客户内部有没有自建派？ |

### BANT — 中小客户快速过滤的资格框架

> 适用：客单价 < 50 万、销售周期 < 3 个月、SDR / 销售快速过线索。
> IBM 1950s 提出，至今仍是最广泛使用的资格框架。

| 字母 | 含义 | 销售必须问出的事 |
|------|------|----------------|
| **B**udget | 预算 | 今年 / 这个季度有没有预算？多少？ |
| **A**uthority | 权限 | 你能拍板吗？不能的话谁能？ |
| **N**eed | 需求 | 现在的痛在哪？为什么是现在？ |
| **T**iming | 时机 | 什么时候要落地？什么时候要看到效果？ |

**BANT 应用规则**：
- 4 项齐 → A 类商机，进入 POC 或方案阶段
- 缺 1 项 → B 类，继续教育和挖掘
- 缺 ≥ 2 项 → C 类，进入培育池

### SPIN — 对话式需求挖掘框架

> 适用：高层销售拜访、Discovery Call、客户访谈。
> Neil Rackham 1988 提出，基于 35,000 次销售拜访的研究。

| 字母 | 问题类型 | 示例 |
|------|---------|------|
| **S**ituation | 情境问题 | "你们现在合同审查是用什么方式？多少人在做？" |
| **P**roblem | 难点问题 | "这种方式遇到过什么问题？" |
| **I**mplication | 暗示问题 | "如果合同里漏掉关键条款，会带来什么风险？" |
| **N**eed-payoff | 价值问题 | "如果有一个工具能 5 分钟扫出风险点，对你们意味着什么？" |

**SPIN 应用规则**：S → P → I → N 顺序不能颠倒；I 类问题必须问透（B2B 销售的核心是放大痛点）；N 类问题让客户自己说出价值，而不是销售自说自话。

### 三种框架的选择建议

| 业务场景 | 推荐框架 |
|---------|---------|
| 大客户、复杂决策链、长周期 | MEDDIC / MEDDPICC |
| 央国企、招投标 | MEDDPICC（强调 Paper Process） |
| 中小客户、SaaS、自助试用 | BANT |
| Discovery Call、高层拜访 | SPIN |
| 全公司销售统一 | 主用 MEDDIC，BANT 用于 SDR 过线索，SPIN 用于 Discovery Call |
