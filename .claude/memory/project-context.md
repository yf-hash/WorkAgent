WorkAgent 是面向**产品经理 / 售前工程师 / 市场营销**用户的 AI 工作智能体，以 Claude Code 为执行入口。

**Why**：让前场工作（写 PRD、投标、方案、内容营销、数据分析、竞品调研）在大模型 + harness 联合驱动下实现指数级效率提升。

**How to apply**：接到用户需求时，先判断角色 / 阶段 / 输出物类型，再从 86 commands / 24 agents 中选定入口，不要造轮子。

**核心场景全景**（一句话覆盖）：
- 内容创作：公众号长文 / 访谈稿 / 深度报告 / 文档润色
- 营销推广：9 大文体（软文、小红书、知乎、朋友圈、短视频、落地页、EDM、PR、案例）
- 产品管理：PRD 全光谱（12 种模式）+ 竞品 + 用研 + 数据 + roadmap
- 售前 / 解决方案：拜访 → Gap → SA → BC → RFP → 安全问卷 → Demo → PoC
- 标书编制：七阶段原子命令（analyze → clarify → outline → write → review → check → export）
- 产品资料：16 类原子产品文档
- 数据看板：7 类原子看板
- 演示制作：6 种 PPT 引擎自动路由
- 数据分析：SQL / Python 沙箱
- 视频 / 图表：Remotion / 云架构图 / Visio / Mermaid / PlantUML / Markmap

支持编辑器：Claude Code 完整 > Cursor > OpenAI Codex
