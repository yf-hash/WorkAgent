# /self-evolve

内容自进化命令。两阶段流程：**风格学习**提炼参考文章共性规律生成「风格卡片」，**创作执行**以风格卡片为基准 Writer-Reviewer 迭代创作。

两个阶段可以连续执行，也可以分开使用（保存风格卡片后复用）。

## 用法

```
# 完整流程（风格学习 + 创作）
/self-evolve --learn <url1,url2,...> --title <文章标题> [--framework <框架>]

# 仅风格学习（生成风格卡片，稍后复用）
/self-evolve --learn <url1,url2,...>

# 使用已有风格卡片创作
/self-evolve --style-card <风格卡片路径> --title <文章标题> [--framework <框架>]

# 优化已有文章
/self-evolve --title <文章标题> <文档路径>
```

## 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--learn <urls>` | 1-5 篇优质文章链接，触发阶段一风格学习 | — |
| `--title <标题>` | 要创作的文章标题 | — |
| `--framework <框架>` | 文章框架（可选），如 `"问题引入→分析→方案→行动"` | AI 自动推导 |
| `--style-card <路径>` | 已保存的风格卡片路径（跳过阶段一） | — |
| `--save-card <路径>` | 将生成的风格卡片保存到指定路径 | — |
| `--target-score <分>` | 目标评分，默认 85，范围 60-100 | 85 |
| `--max-rounds <轮>` | 最大迭代轮次，范围 1-5 | 3 |
| `--mode <模式>` | `quality`=内容优先，`humanize`=去AI味优先，`balance`=双向均衡 | `quality` |
| `--show-process` | 显示完整迭代过程 | false |
| `--report` | 生成进化报告 | false |

## 核心流程

```
[阶段一] 风格学习
  1-5篇文章链接
       ↓
  逐篇结构分析
       ↓
  提炼共性规律
       ↓
  生成「风格卡片」
       ↓
  ⏸ 展示给用户确认 ← 用户可修改/确认
       ↓ 确认
  [阶段二] 创作执行
  用户输入：标题 + 框架（可选）
       ↓
  Writer 按风格卡片生成初稿
       ↓
  Reviewer 双维度评分 + 诊断
       ↑_________↓（迭代，最多3轮）
       ↓ 达标/终止
  输出最终文章
```

**迭代终止条件（满足任一即停）：**
- 评分达到目标分数（默认 85/100）
- 已迭代 3 轮（可配置）
- 连续 2 次提升 < 3 分（边际收益递减）

## 执行流程

### 阶段一：风格学习（`--learn` 触发）

**步骤 1：逐篇抓取与解析**

使用 WebFetch 抓取每篇文章全文，提取：标题、段落结构、小标题分布、开头/结尾模式、字数、平均段落长度。

**步骤 2：结构分析**

| 分析维度 | 分析内容 |
|----------|----------|
| 开篇模式 | 如何抓住读者（问题/故事/数据/观点） |
| 论证结构 | 总分总 / 问题-解决 / 时间线 / 对比 |
| 段落节奏 | 长短句比例、段落字数分布 |
| 过渡方式 | 章节间如何衔接 |
| 结尾策略 | 总结/行动号召/开放式提问 |
| 语言风格 | 口语化程度、人称使用、情感浓度 |
| 案例密度 | 每千字案例数量、案例类型 |

**步骤 3：提炼共性规律，生成「风格卡片」**

```markdown
## 风格卡片（提炼自 N 篇优质文章）

**开篇原则**：[共性开篇策略]
**结构原则**：[共性论证结构]
**节奏原则**：[段落节奏规律]
**语言原则**：[语言风格特征]
**案例原则**：[案例使用规律]
**结尾原则**：[结尾策略]
**禁止事项**：[识别出的反模式，如：禁用"此外""值得注意的是"等AI高频词]
```

**步骤 4：⏸ 暂停，展示风格卡片等待用户确认/修改**

### 阶段二：创作执行（风格卡片确认后）

1. 加载风格卡片（来自阶段一或 `--style-card`）
2. 有 `--framework`：按标题 + 框架从零创作；仅有 `--title`：AI 根据风格卡片结构原则自动推导框架；有文档路径：以风格卡片为基准优化已有内容
3. Writer 按风格卡片 + 标题/框架生成初稿
4. Reviewer 双维度评分（内容质量 50 分 + 风格合规 50 分）+ 精准诊断
5. Writer 针对诊断定向修改（最多 `--max-rounds` 轮）
6. 达到目标分或边际收益递减时停止

**终止条件（满足任一即停）：**
- 评分达到目标分数
- 已迭代最大轮次
- 连续 2 次提升 < 3 分

## 质量标准

| 维度 | 满分 | 子维度 |
|------|------|--------|
| 内容质量 | 50 | 深度与完整性/15 + 案例与数据/15 + 逻辑连贯性/10 + 结构完整性/10 |
| 风格合规 | 50 | 自然度/15 + 真实感/15 + 节奏变化/10 + 风格一致性/10 |

## 诊断报告格式

```markdown
## 第 N 轮诊断报告

### 评分结果

| 维度 | 子维度 | 得分 | 上轮得分 | 变化 |
|------|--------|------|----------|------|
| 内容质量 | 深度与完整性 | X/15 | X/15 | +X |
| 内容质量 | 案例与数据 | X/15 | X/15 | +X |
| 内容质量 | 逻辑连贯性 | X/10 | X/10 | +X |
| 内容质量 | 结构完整性 | X/10 | X/10 | +X |
| 风格合规 | 自然度 | X/15 | X/15 | +X |
| 风格合规 | 节奏变化 | X/10 | X/10 | +X |
| 风格合规 | 真实感 | X/15 | X/15 | +X |
| 风格合规 | 风格一致性 | X/10 | X/10 | +X |
| **总分** | | **XX/100** | **XX/100** | **+X** |

### 问题诊断（按优先级排序）

**P1 - 高优先级（必须修复）：**
1. [具体问题] - 影响分数：-X分
   - 位置：[具体段落/章节]
   - 建议：[具体改写方向]

**P2 - 中优先级（建议修复）：**
1. [具体问题] - 影响分数：-X分

- 本轮提升：+X分 | 连续趋势：[上升/停滞/递减]
- **建议**：[继续迭代/已达标准/边际收益递减建议停止]
```

---

**核心原则**：
- 风格卡片优先：所有创作必须以风格卡片为基准，不是凭空发挥
- 用户确认闸门：风格卡片生成后必须暂停，等待用户确认或修改
- 诊断驱动改稿：Writer 每轮改稿必须针对 Reviewer 的具体诊断，不盲目重写
- 边际收益递减时主动停止，避免过度优化
