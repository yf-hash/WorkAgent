# /humanize

AI 文本人性化改写。融合五套方法论，系统性消除 AI 痕迹并注入真实人类声音：

- **[blader/humanizer](https://github.com/blader/humanizer)** — 识别并消除 29 种 AI 写作模式（内容/语言/风格/交流/填充五类）
- **[op7418/Humanizer-zh](https://github.com/op7418/Humanizer-zh)** — 中文高频词列表 + 六大人性原则，目标不是"无菌干净"，而是"有声音、有立场、有灵魂"
- **降AI率微策略** — 7项句式级精细改写（句式调整/主语明确/长句拆分/同义词自然化/标点微调/精简冗余/连贯性检查）
- **学术深度强化** — 30条高级学术去痕指令（认知重构/细节增殖/逻辑跃迁/学术身份/反检测/实证深度/格式反特征化），`academic + max` 时启用
- **垂直领域情绪预设** — 33个垂直赛道情绪状态库（情感/娱乐/热点/军事/个人成长/育儿/养生/历史/体育/职场等），`--domain` 激活

## 用法

```
/humanize [文件路径或直接粘贴文本]
/humanize article.md --tone casual --intensity high
/humanize thesis.pdf --tone academic --intensity max
/humanize report.docx --tone formal --intensity medium
/humanize draft.md --intensity max --voice-sample my-writing.md
/humanize post.md --tone casual --domain 情感 --intensity high
/humanize essay.md --tone academic --intensity max --voice-sample my-papers.md
```

## 参数说明

| 参数 | 选项 | 默认值 | 说明 |
|------|------|--------|------|
| `--tone` | `casual` / `formal` / `technical` / `academic` | `formal` | 语调风格 |
| `--intensity` | `low` / `medium` / `high` / `max` | `medium` | 去痕强度（决定执行哪几轮） |
| `--voice-sample` | 文件路径 | — | 提供 2–3 段自己的文字样本，校准输出声音 |
| `--domain` | 见下方领域列表 | — | 激活垂直领域情绪预设，注入领域专属人味 |

### 强度说明

| 强度 | 执行内容 | 适用场景 |
|------|----------|----------|
| `low` | 第一轮：仅最明显的 29 模式 | 草稿快速润色 |
| `medium` | 第一轮：全量 29 模式 + 中文高频词 + 7项微策略 | 通用文档、博客 |
| `high` | 第一至三轮 + 第四轮灵魂注入（H1–H6）+ 情绪预设（若有 `--domain`） | 重要文档、公众号长文 |
| `max` | 全四轮 + 声音校准 + 情绪预设 + 学术深度强化（`academic` 时）| 顶刊投稿、学位论文、严格检测 |

### 支持的 `--domain` 领域

`情感` / `娱乐八卦` / `社会热点` / `军事` / `个人成长` / `育儿` / `养生` / `历史` / `体育` / `职场` / `科技` / `财经` / `美妆穿搭` / `美食` / `旅行` / `游戏` / `宠物` / `房产` / `汽车` / `教育` / `影视` / `读书` / `心理` / `法律` / `医疗健康` / `环保` / `国际时事` / `农业` / `艺术` / `宗教信仰` / `公益` / `创业` / `设计`

每个领域包含 2 种情绪状态预设（详见 SKILL.md 领域情绪库），激活后将相应的口头禅、句式特征、情绪节奏注入改写。

## 执行流程

加载 `skills/humanizer/SKILL.md` 完整规范执行。

### 第一轮：扫描去痕

全面清除 AI 写作特征：
- 逐句扫描 29 种 AI 写作模式（blader/humanizer）
- 对照中文高频 AI 词汇列表（op7418/Humanizer-zh）逐一消除
- 执行 7 项句式级微策略：句式与关联词调整、主语明确化、长句优化、同义词自然化替换、标点符号微调、精简冗余内容、上下文连贯性检查

### 第二轮：声音校准（有 `--voice-sample` 时执行）

从样本中提取句子节奏、词汇偏好、标点习惯，将改写对齐至用户声音。

### 第三轮：情绪预设注入（有 `--domain` 时执行）

根据指定领域激活对应情绪状态预设，注入该领域博主的口头禅、句式特征和情绪节奏，让文字具备领域专属的"活人感"。

### 第四轮：审计

重读改写稿，对每个句子自问"这句还像 AI 写的吗？"，仍有 AI 感的句子重写。

### 第五轮：灵魂注入（`high` / `max` 强度）

依据 op7418/Humanizer-zh 六大原则（H1–H6）主动注入人性：H1 表明立场 / H2 变换节奏 / H3 承认复杂性 / H4 适当用"我" / H5 允许一些混乱 / H6 感受具体化。

### 第六轮：学术深度强化（`academic` + `max` 强度）

执行 30 条高级学术去痕指令，涵盖：认知重构（认知分层/研究演化轨迹）、细节增殖（方法论指纹/田野实证颗粒）、逻辑跃迁（反事实推理/例外情况讨论）、学术身份具化、反检测算法应对、实证深度强化、格式反特征化、学术伦理规范、终极验证清单。
