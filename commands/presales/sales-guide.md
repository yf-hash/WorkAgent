# /sales-guide — 销售一页禅生成器

加载技能：`skills/presales/sales-guide-writer/SKILL.md`

## 触发条件
需要编写产品销售指南（销售一页禅）、行业化销售剧本、销售常见问题解答（FAQ）、竞争应对话术，或提炼产品销售价值时。适用于软件、硬件、SaaS、消费品、工业品、服务类等各类产品。

## 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `<产品名称>` | 产品全称（必填） | — |
| `--mode` | 生成模式（见下表） | `full` |
| `--industry` | 目标行业（影响场景和案例语气） | — |
| `--scenes` | 销售场景数量 | `3` |

### 生成模式

| `--mode` | 输出内容 | 适用场景 |
|----------|---------|---------|
| `full` | 完整销售一页禅（5大章节） | 新产品上市/销售赋能培训 |
| `scenarios` | 仅销售场景剧本（含故事/需求/解决思路） | 快速出场景库 |
| `faq` | 仅销售常见问题（分类问答） | 更新FAQ文档 |
| `competitive` | 竞争对比表 + 应对话术（A/B/C/D分级） | 竞争项目应对 |
| `value` | 销售价值提炼（4大价值方向） | 销售培训/商务演讲 |

## 行业定制

| `--industry` | 目标客户类型 | 典型场景 | 关键决策关注点 |
|--------------|------------|---------|--------------|
| `fintech` | 银行/保险/证券机构 | 合规审计/风险控制/数据安全 | 监管合规、安全性、稳定性 |
| `gov` | 政府/事业单位 | 政务数字化/数据治理/信息化建设 | 政策符合性、国产化、可控性 |
| `healthcare` | 医院/医疗机构 | 患者数据管理/临床信息化/运营效率 | 数据合规、互联互通、稳定性 |
| `edu` | 高校/教育机构/在线教育 | 学生管理/教学质量/运营降本 | 易用性、扩展性、性价比 |
| `mfg` | 制造业/工业企业 | 生产管理/供应链优化/质量追溯 | 系统集成、工厂部署、ROI |
| `retail` | 零售/电商/连锁品牌 | 用户增长/会员运营/全渠道融合 | 转化率、用户体验、数据洞察 |
| `consumer` | 消费类产品/DTC品牌 | 用户获取/复购提升/口碑传播 | 体验差异化、社交传播、价格敏感度 |
| `saas` | SaaS/互联网/科技公司 | 产品增长/自助服务/API集成 | 功能完整性、集成生态、扩展性 |

## 使用示例

```
/sales-guide 数据安全网关 --mode full --industry fintech
/sales-guide 终端检测响应系统 --mode scenarios --industry gov --scenes 4
/sales-guide 零信任访问控制 --mode faq
/sales-guide API安全防护平台 --mode competitive
/sales-guide 智能运维平台 --mode value --industry mfg
```

## 执行流程

```
Step 1: 产品定位分析
  → 提取产品核心价值主张（一句话定位）
  → 识别主要目标客户角色（决策者/技术负责人/采购负责人）
  → 确认产品形态（软件/硬件/SaaS/混合）和价格范围

Step 2: 场景构建（scenarios模式核心）
  → 每个场景按5要素展开：
    ① 目标客户（职位/部门）
    ② 行业客户的故事（真实案例或原型）
    ③ 案例背后的需求（≥3个核心诉求）
    ④ 我们的解决思路（产品功能映射）
    ⑤ 其他销售机会（延伸/连带销售）

Step 3: 竞争矩阵生成（competitive模式核心）
  → 识别主要竞品（3-5家）
  → 按A/B/C/D四级标注我方优势项
  → 为D级劣势项生成转移焦点话术

Step 4: 销售价值提炼（value模式核心）
  → 发现问题增强黏性（POC价值/敲门砖）
  → 发掘连带商机（问题→解决方案）
  → 销售模式创新（生态联动/合作拓展）
  → 创新课题切入（新技术领域/行业标准）

Step 5: FAQ生成（faq模式核心）
  → 覆盖技术/竞品/部署/授权/服务5类问题
  → 每题附参考答案和答题建议
```
