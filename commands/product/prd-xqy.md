# /prd-xqy — 需求规格说明书（XQY 8 章模板）

加载技能：`skills/prd-xqy/SKILL.md`
模板源文件：`commands/product/需规模板.docx`

## 用途

生成符合企业级"需求规格说明书"标准的强结构化需求文档，特别适用于：

- 银行/金融/保险/证券 后台核心业务系统
- 传统企业 IT 项目（运营商、能源、政府）
- 需提交甲方评审的乙方交付物
- 有强制性章节、字段表、接口报文、批处理时序要求的项目

## 用法

```bash
/prd-xqy 新增对公账户开户业务接口
/prd-xqy 风控规则维护菜单功能 --system 风控管理系统
/prd-xqy 日终对账批处理 --module-type batch
/prd-xqy 客户信息变更（含接口+菜单+批处理） --module-type mixed
```

## 强制表格

以下表格在文档中**必须**出现：

| 位置 | 表格内容 | 列定义 |
|---|---|---|
| 封面 | 修订历史 | 版本 / 章节 / 类型(C/U/D/A) / 日期 / 作者 / 说明 |
| 3.2 | 菜单索引 | 序号 / 一级菜单 / 二级菜单 / 三级菜单 / 四级菜单 / 权限 / 备注 |
| 3.3 接口 | 接口清单 | 序号 / 接口编码 / 接口名称 / 调用方编码 / 调用方名称 / 备注 |
| 3.3 菜单 | 字段说明 | 区域/表单 / 字段/功能名称 / 是否必填 / 是否支持修改 / 选项类型 / 其他规则 |
| 第 8 章 | 变更明细 | 变更序号 / 变更时间 / 变更描述 |

## 输出原则

1. **章节编号锁定**：不得修改章节号、不得跳过空章节（写"无"或"暂无"占位）
2. **三类功能分组**：3.3 节下按 接口 / 菜单功能 / 批处理 三类分别展开
3. **表格优先**：菜单索引/字段说明/接口清单/变更明细必须用表格
4. **业务规则白话化**：接口的请求报文/业务逻辑/返回报文要研发可直接对照实现
5. **批处理三件套**：执行时间 / 执行频率 / 执行 IP:Port + 业务逻辑
6. **缺信息用 `[待补充]` 显式标注**，不得编造
