# /sales-guide — 销售一页禅生成器

加载技能：`skills/sales-guide-writer/SKILL.md`

## 触发条件
需要编写产品销售指南（销售一页禅）、行业化销售剧本、销售常见问题解答（FAQ）、竞争应对话术，或提炼产品销售价值时。

## 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `<产品名称>` | 产品全称（必填） | — |
| `--mode` | 生成模式（见下表） | `full` |
| `--industry` | 目标行业（影响场景和案例） | — |
| `--scenes` | 销售场景数量 | `3` |

### 生成模式

| `--mode` | 输出内容 | 适用场景 |
|----------|---------|---------|
| `full` | 完整销售一页禅（5大章节） | 新产品上市/销售赋能培训 |
| `scenarios` | 仅销售场景剧本（含故事/需求/解决思路） | 快速出场景库 |
| `faq` | 仅销售常见问题（分类问答） | 更新FAQ文档 |
| `competitive` | 竞争对比表 + 应对话术（A/B/C/D分级） | 竞争项目应对 |
| `value` | 销售价值提炼（4大价值方向） | 销售培训/商务演讲 |

## 行业定制

| `--industry` | 目标客户 | 核心场景 | 关键话题 |
|--------------|---------|---------|---------|
| `fintech` | 银行/保险/证券信息安全部门 | 合规检查/风险评估/渗透测试 | 等保2.0/Basel III/DORA |
| `gov` | 政务数据局/网信办/信息中心 | 关基保护/数据安全法合规 | 数安法/网安法/关基条例 |
| `healthcare` | 医院信息安全部/卫生机构 | 数据防泄漏/勒索防护 | 医疗信息安全规范 |
| `edu` | 高校网络信息中心/科研院所 | 学生数据保护/科研系统防护 | 教育信息化相关规范 |
| `mfg` | 制造业/能源/电力信息安全部 | OT/IT融合/工控系统防护 | 工业互联网安全规范 |
| `retail` | 零售/电商数据安全团队 | 用户数据保护/交易安全 | 个保法/PCI-DSS |
| `saas` | SaaS/互联网安全团队 | 多租户隔离/API防护 | ISO 27001/SOC 2 |

## 使用示例

```
/sales-guide 数据安全网关 --mode full --industry fintech
/sales-guide 终端检测响应系统 --mode scenarios --industry gov --scenes 4
/sales-guide 零信任访问控制 --mode faq
/sales-guide API安全防护平台 --mode competitive
/sales-guide 智能运维平台 --mode value --industry mfg
```

## 执行流程

```
Step 1: 产品定位分析
  → 提取产品核心价值主张（一句话定位）
  → 识别主要目标客户角色（决策者/技术负责人/采购负责人）
  → 确认产品形态（软件/硬件/SaaS/混合）和价格范围

Step 2: 场景构建（scenarios模式核心）
  → 每个场景按5要素展开：
    ① 目标客户（职位/部门）
    ② 行业客户的故事（真实案例或原型）
    ③ 案例背后的需求（≥3个核心诉求）
    ④ 我们的解决思路（产品功能映射）
    ⑤ 其他销售机会（延伸/连带销售）

Step 3: 竞争矩阵生成（competitive模式核心）
  → 识别主要竞品（3-5家）
  → 按A/B/C/D四级标注我方优势项
  → 为D级劣势项生成转移焦点话术

Step 4: 销售价值提炼（value模式核心）
  → 发现问题增强黏性（POC价值/敲门砖）
  → 发掘连带商机（问题→解决方案）
  → 销售模式创新（生态联动/合作拓展）
  → 创新课题切入（新技术领域/行业标准）

Step 5: FAQ生成（faq模式核心）
  → 覆盖技术/竞品/部署/授权/服务5类问题
  → 每题附参考答案和答题建议
```
