# /pm-prd-enterprise — 企业级 PRD 严格模板模式

请基于以下需求生成研发可直接评审的 PRD：

$ARGUMENTS

> 与 `/prd-standard` 的边界：本命令使用**企业级严格模板**（多租户/审计/隔离/合规口径默认必填），
> 适合 B 端 SaaS / 私有化项目；`/prd-standard` 适合 C 端 / 通用产品快速生成。
> 输出模板见 `templates/prd-template.md`。

## 必须包含

按 `templates/prd-template.md` 12 章结构输出：

1. 文档信息
2. 背景与目标（业务背景 / 当前问题 / 产品目标 / 不做范围）
3. 用户角色与使用场景
4. 需求总览（编号 + 优先级 + 业务价值 + 版本）
5. 业务流程（主流程 / 异常流程 / 状态流转）
6. 功能详细说明（功能说明 / 字段 / 业务规则 / 权限规则 / 异常处理）
7. 数据与接口需求
8. 非功能需求（性能 / 安全 / 审计 / 兼容性 / 可用性 / 可扩展性 / 私有化 / 运维监控）
9. 埋点与数据指标
10. 验收标准
11. 风险与依赖
12. 附录

## 输出原则

- 用清晰编号
- 表格化表达字段、权限、状态、验收项
- **对研发友好**（流程、规则、字段、状态、异常完整）
- **对测试可验收**（每条规则都能写出用例）
- **对交付可解释**（B 端默认含审计、隔离、私有化部署）
- 不只写功能说明，要写清楚**业务规则**和**实现边界**

## 模板入口

直接基于 `templates/prd-template.md` 填充。如果当前目录无法读取模板，按该模板结构直接生成。
