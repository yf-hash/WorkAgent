# /win-loss — Win/Loss 赢单失单分析

请基于以下输入做 Win/Loss 分析：

$ARGUMENTS

## 工作流程

### 第 1 步：样本设计

至少访谈：
- 5-10 个 Won Deal
- 5-10 个 Lost Deal
- 3-5 个 No Decision（客户最终没决定 — 最被忽视但最关键）

Deal 关闭后 2-6 周内访谈最有效。

### 第 2 步：访谈

**客户访谈**（30 分钟，由独立第三方做最好）：
1. 背景：评估场景 / 决策时间线 / 决策小组
2. 评估过程：评估了哪几家 / 各家 first impression / 评估关键维度
3. 选择 / 不选我们：最关键原因 + 追问 2-3 层
4. 反馈：好的 / 不好的 / 一句话建议

**销售访谈**（20 分钟）：
1. Deal 时间线
2. 客户决策动力 + Champion + 反对者 + 预算
3. 输 / 赢分析 — 官方理由 vs 真实理由

### 第 3 步：根因聚类

聚类到 10 大常见原因：
1. 产品功能不够
2. 价格
3. 集成能力
4. 安全合规
5. 品牌信任
6. 销售体验
7. 演示 / PoC 体验
8. 合同条款
9. 内部决策延迟
10. 时机

> 关键：区分"官方理由（客户说的）"vs"真实理由（推断的）"。

### 第 4 步：ICP 修正

输出：
- 我们在赢哪类客户（特征 + 案例）
- 我们在输哪类客户（该不该追）
- 修正后的 ICP

## 红线（不要做）

- ❌ 销售自己分析（为自己 Deal 辩护）
- ❌ 只看输单不看赢单（不知道为啥赢就不会复制）
- ❌ 只看 CRM 数据不访谈（销售填的数据反映不了真相）
- ❌ "No Decision" 不分析（这是最大金矿）
- ❌ 没有 Action Items（分析变成"汇报"）
- ❌ 不跟踪改进效果
