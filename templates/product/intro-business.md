# 产品介绍-商务版 PPT 写作知识库

> 单一文档类型 | 受众：商务决策层 / 采购委员会 | 密级：可公开 | 篇幅：15-25 页

---

## 核心原则

1. **价值导向**：商务版 PPT 回答"为什么买"，不回答"怎么实现"
2. **ROI 优先**：每个亮点都要连接到客户的业务结果（降本 / 增收 / 合规）
3. **少文字多视觉**：每页正文 ≤30 字，图表 / 截图 / Logo 墙占主导
4. **30-45 分钟节奏**：15-25 页适配 1.5-2 分钟/页的讲解节奏

---

## 标准结构模板

```markdown
# [产品名] 商务介绍

## P1 封面
产品名 + 版本 + 公司 Logo + 日期

## P2 公司介绍
公司背景 / 业务定位 / 核心资质（资质 Logo 墙）

## P3 行业洞察
行业趋势 + 客户共性挑战（数据驱动，引用权威报告）

## P4 产品概述
一句话定位 + 三大核心价值（每个价值连接到业务结果）

## P5-P10 核心功能（每个 1 页）
每页结构：功能名 → 价值描述 → 效果截图
建议 ≤6 个主功能

## P11 部署模式
高层次部署架构图（不含技术细节）

## P12 商业价值（ROI）
| 维度 | 收益 |
| 降本 | 节省 X 万元 / 减少 Y 人力 |
| 增收 | 提升 X% 转化率 |
| 合规 | 通过 XX 认证 |

## P13-P15 典型客户案例
每个案例 1 页：客户 Logo + 行业 + 痛点 + 成果

## P16 客户 Logo 墙
按行业分组排列

## P17 资质与认证
认证 Logo 墙：ISO / 等保 / 国密 / 行业认证

## P18 服务体系
售前 / 实施 / 售后 SLA

## P19 选择我们的理由
3-5 条差异化优势汇总

## P20 联系方式
团队照片 + 联系人 + 二维码
```

---

## 质量要求

| 维度 | 标准 |
|------|------|
| 篇幅 | 15-25 页 |
| 每页字数 | ≤30 字正文 |
| 图表 | 至少 8 张：架构图、ROI 表、客户 Logo 墙、资质墙、案例图 |
| 技术细节 | 禁止：算法描述 / API 接口 / 数据库表结构 |
| 配色 | 符合企业 VI |
