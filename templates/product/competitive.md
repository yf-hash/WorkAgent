# 竞品分析 — 结构模板

> 3-5 家竞品对照，含决策建议

---

# 竞品分析写作知识库

> 单一文档类型 | 受众：销售 / 售前 | 密级：**内部保密** | 形态：PPT

---

## 核心原则

1. **结构化分类**：所有优劣势按 A/B/C/D 四级强制分类，不留模糊
2. **直面 D 级**：未有优势必须正视，每个 D 级配应对话术
3. **对手客观**：用对手公开资料和市场调研，禁止抹黑性描述
4. **可复用**：销售在客户现场可直接调用其中的话术与对比

---

## 竞争优势四级分类体系

| 级别 | 名称 | 定义 | 处理策略 |
|------|------|------|---------|
| **A 级** | 唯一性优势 | 只有我方一家具备（绝对性敌无我有） | 重点突出，作为核心差异化 |
| **B 级** | 核心优势 | ≤3 家厂商具备（相对性我有敌无或少） | 主动强调，证明领先地位 |
| **C 级** | 一般优势 | 多数厂家均具备 | 基础配置，保障覆盖度 |
| **D 级** | 未有优势 | 友商有、我方没有的点 | 提前准备话术，转移焦点 |

## 标准结构模板

```markdown
# [产品名] 竞品分析（内部资料）

## P1 封面
产品名 + 编制日期 + "内部资料 禁止外传"水印

## P2 议程
- 竞品概况
- 功能对比矩阵
- 我方优劣势分析
- 差异化销售策略
- 竞争应对剧本

## P3-P6 竞品概况（每家 1 页）
- 公司背景 / 市场地位
- 主要产品 / 报价区间
- 典型客户 / 主要遭遇场景
- 销售模式 / 渠道

## P7-P10 功能对比矩阵
| 一级模块 | 二级功能 | 我方 | 厂商 A | 厂商 B | 厂商 C | 我方分类 |

| 数据 | 字段加密 | ✅ | ✅ | ✅ | ✗ | C |

## P11 A 级优势汇总（核心差异化）
| 序号 | A 级优势 | 客户价值 | 证据 |
| 1 | 国密双模算法 | 满足金融 / 政府国产化 | 商密二级认证 |
| 2 | ... | ... | ... |

## P12 B 级优势汇总
（同上结构）

## P13 D 级劣势与应对
| D 级劣势 | 客户提及频率 | 应对话术 | 替代方案 |
| 动态脱敏 | 高 | "我方采用静态脱敏 + 字段级权限，覆盖同类风险，且 X" | 推荐功能组合 X+Y |
| ... | ... | ... | ... |

## P14 差异化销售策略
- 攻击对手的薄弱环节（不点名，话术化）

| 场景 | 客户原话 | 推荐应答 |
| 客户拿对手低价压价 | "厂商 A 比你们便宜 30%" | "理解，价格背后是 SLA 与持续投入..." |
| ... | ... | ... |

## P16-P18 销售常见问答
- 客户问"你们和 XX 有什么区别"标准应答
- 客户问"XX 已经在用 YY 了"应答
- 客户问"为什么你们贵"应答

## P19 联系人 / 升级通道
内部技术支持 / 售前升级机制
```

## 质量要求

| 维度 | 标准 |
|------|------|
| 对手数 | 3-5 家 |
| 功能对比项 | ≥20 项 |
| A 级优势 | 至少 1 个，最多 3 个（多了不可信） |
| D 级劣势应对 | 每个 D 级必须配话术，不能空 |
| 数据来源 | 标注：公开资料 / 客户访谈 / 第三方报告 |
