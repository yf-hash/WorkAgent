# 培训材料 — 结构模板

> 销售 / 交付 / 运维培训体系

---

# 产品培训材料写作知识库

> 单一文档类型 | 受众：渠道商 / 客户 / 内部员工 | 密级：可公开 | 形态：三件套（PPT + Word + Word）

---

## 核心原则

1. **三件套必齐**：课件 PPT + 实操指南 + 培训试题，缺一项不能算"培训材料"
2. **按学员路径设计**：先讲产品 → 演示操作 → 学员动手 → 答题验收
3. **实操可复现**：实操指南必须含步骤截图，学员独立完成
4. **试题覆盖核心**：试题必须覆盖课件主要知识点，单选+多选+判断+简答

---

## 课件 PPT 结构

```markdown
# [产品名] 培训课件（[受众]）

## P1 封面
培训主题 + 受众 + 时长 + 讲师 + 日期

## P2 议程
6-8 个学习单元

## P3-P5 单元 1：产品概览
- 行业背景
- 产品定位
- 核心价值

## P6-P10 单元 2：架构与原理
（技术决策层 / 内部员工受众版含更深，渠道商版较浅）

## P11-P20 单元 3-6：核心功能演示（每功能 2-3 页）
每页结构：功能名 → 价值 → 操作演示截图 → 关键提示

## P21-P25 单元 7：典型场景实战
按业务场景串接多个功能

## P26-P28 单元 8：常见问题与故障处理

## P29 培训小结
- 学习要点回顾
- 推荐后续学习路径

## P30 Q&A 入口
```

## 三、任务详解

**任务目标**：[完成后能做什么]
**前置条件**：[已学习的课件章节]

**验收标准**：[如何判断完成]

（实操评分细则）

## 培训试题 Word 结构

```markdown
# [产品名] 培训试题（[受众]）

## 题型分布

| 题型 | 题量 | 分值 |
| 单选 | 20 题 | 40 分 |
| 多选 | 10 题 | 30 分 |
| 判断 | 10 题 | 20 分 |
| 简答 | 3 题 | 10 分 |
| 合计 | 43 题 | 100 分 |

**合格线**：60 分

---

## 一、单选题（每题 2 分，共 40 分）

**1.** [产品名] 的核心定位是？
A. ...
B. ...
C. ...
D. ...

**答案**：A
**解析**：参见课件 P3-P5

...

## 二、多选题（每题 3 分，少选漏选不得分）

**21.** [产品名] 支持以下哪些数据库？（多选）
A. MySQL
B. PostgreSQL
C. 达梦
D. ...

**答案**：ABC

## 三、判断题（每题 2 分）

**31.** [陈述]（）

**答案**：√ / ×

## 四、简答题（每题 3-4 分）

**41.** 简述 [产品名] 高可用部署的关键步骤。

**评分要点**：
- 答出步骤 1 ... 1 分
- 答出步骤 2 ... 1 分
- 答出步骤 3 ... 1 分
```

## 按受众的差异

| 受众 | 课件内容侧重 | 实操内容侧重 | 试题侧重 |
|------|-------------|-------------|---------|
| `channel` 渠道商 | 销售场景 / 案例 / 商务话术 | 模拟客户演示 / 报价工具 | 案例选择 / 销售场景判断 |
| `customer` 客户 | 操作步骤 / 业务场景 | 真实业务操作 / 故障处理 | 操作流程 / 故障识别 |
| `internal` 内部 | 产品全局 / 技术原理 / 实施流程 | 安装 / 配置 / 升级 | 技术原理 / 实施判断 |

---

## 质量要求

| 维度 | 标准 |
|------|------|
| 三件套完整 | PPT + 实操 + 试题缺一不可 |
| 课件页数 | 30-40 页（半天到 1 天培训） |
| 实操任务 | 至少 5 个，覆盖核心功能 |
| 试题数 | 至少 40 题 |
| 答案与解析 | 每题必备，指向课件页码 |
