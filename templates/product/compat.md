---

## 核心原则

1. **实测为准**：只列出实际测试通过的平台与版本，禁止填"应支持"
2. **国产化覆盖**：必须含国产 OS / 国产 DB / 国产 CPU 三大维度
3. **日期追踪**：每条兼容记录必须含最近测试日期
4. **降级说明**：⚠️ 部分支持的需说明限制条件

---

## 标记规范

| 标记 | 含义 |
|------|------|
| ✅ | 通过完整测试，可用于生产 |
| ⚠️ | 部分支持（必须在备注栏写明限制） |
| ✗ | 未测试 / 已知不兼容 |
| 路线图 | 不列入正式表格 |
